# 새 서버 재현 준비 검증 — 2026-09-16

## 검증 대상과 경계

기존 운영 릴리스 `manual-20260916-work-ui-836c517b9251`의 확인된 소스 아카이브를 깨끗한 별도 Git 복제본에 반영했습니다. 원본 개발 폴더의 미완성 전국 농장 지도와 사용자 Excel, 환경파일, 운영 데이터는 포함하지 않았습니다. 출처 해시는 [production-baseline.json](production-baseline.json)에 있습니다.

이 기준 소스에 초기 설정·환경 검사·빌드 도구, 회원등록 서비스의 명시적 설정 입력, 상세 문서, 배포하지 않는 CI 검증을 추가했습니다. 화면에서는 lint가 요구하는 접근성 마크업 세 곳만 정리했으며 업무 저장·집계 동작은 변경하지 않았습니다. 따라서 이 Git 소스 전체가 기존 운영 아카이브와 바이트 단위로 동일하다는 뜻은 아닙니다.

## 수행하지 않은 작업

- 새 Linux VM 생성, root 설치 스크립트 실행, systemd/Caddy 서비스 설치·재시작
- 운영 웹 재배포, Firebase Rules/IAM/Authorized domains 변경
- 계정 생성, 운영 업무 데이터 쓰기, 데이터·Auth 이관
- 새 서버에서의 실사용 로그인 및 실데이터 저장 검증

따라서 이 결과는 **복제 후 설치·빌드 가능한 소스와 절차의 검증**입니다. 새 운영 환경의 개통 검증까지 완료한 것은 아닙니다. Linux 설치 스크립트의 구문 검사는 검증 CI에 포함했으며 실제 인프라 설치는 [새 서버 설치 가이드](server-setup.md)에 따라 별도 승인 후 수행합니다.

Git push로는 데모 검증 CI만 실행됩니다. 기존 운영 배포 workflow는 `main`의 수동 실행 전용을 유지합니다.
