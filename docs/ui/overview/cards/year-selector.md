# 연도별 사업 현황·선택

갱신일: 2026-09-09 · 통합 현황·프로젝트 관리 공통

기본값은 접속 기기의 현재 연도다. 로그인 후 처음 열 때 계산하며 2026년처럼 고정하지 않는다. 선택한 연도는 두 화면 사이에서 유지하고, 해당 연도 사업이 없으면 빈 상태를 표시한다.

통합 현황과 프로젝트 관리 모두 ‘기준 연도’ 선택란을 사용합니다. 여러 연도 버튼을 나열하지 않고 선택한 연도 한 개만 표시합니다. 선택란을 열면 ‘전체 연도’와 삭제되지 않은 프로젝트의 등록연도가 최신순으로 나타납니다. 두 화면은 선택값을 공유합니다.

상단 KPI와 프로젝트 표·카드는 선택한 연도·사업 타입의 교집합으로 집계합니다. 검색·위험 조건은 목록만 추가로 좁힙니다. 선택 타입에 사업이 없으면 KPI는 0건 또는 `-`, 목록은 빈 상태를 표시합니다. ‘전체 연도’를 선택하면 모든 연도를 합칩니다. 삭제한 프로젝트 복구 영역은 집계와 별개로 보존합니다.

연도는 사업의 `year`이며 업무 처리일의 연도가 아닙니다. 상단 KPI는 선택 사업연도의 현재 상태입니다. 과거 연말 상태를 복원한 보고서가 아닙니다. 기준 연도와 사업 타입은 넓은 화면에서 나란히, 좁은 화면에서는 위아래로 배치합니다.
