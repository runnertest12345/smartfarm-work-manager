# 연도별 사업 현황·선택

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

전체 연도와 등록된 사업연도를 최신순으로 표시합니다. 각 카드에는 선택한 사업 타입의 사업 수와 진행·완료·보류 수가 나타납니다. 연도 선택지는 전체 등록연도를 유지하므로 선택 타입에 사업이 없는 연도도 0건으로 표시됩니다. 누르면 통합 현황 및 프로젝트 관리에서 공유하는 사업연도가 변경됩니다. 프로젝트 관리의 연도 선택란과도 동기화합니다.

연도는 사업의 `year`이며 업무 처리일의 연도가 아닙니다. 상단 KPI는 선택 사업연도의 현재 상태입니다. 과거 연말 상태를 복원한 보고서가 아닙니다. 가로 공간이 부족하면 연도 선택 영역을 가로로 스크롤합니다.
