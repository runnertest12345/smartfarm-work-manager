# 확인 필요 · 데이터 점검

‘참여 농가 확인 필요 N건’과 ‘시운전·교육 후속 확인 M개소’를 표시합니다. 두 수치는 별도 집계이며 더하거나 부분집합으로 해석하지 않습니다.

확인 필요는 주소 공백, 농장번호·농가명 중복, 동일 사업·농가 중복 참여, 설치일 누락, 구독기간 또는 만료일 누락 문제입니다. 농가 공통 문제는 선택 연도 참여 농가 ID로 제한하고, 설치·구독·참여 중복 문제는 선택 연도 프로젝트 ID로 제한합니다. 같은 농가의 다른 연도 사업 문제는 합산하지 않습니다. 참여별 문제는 원본 참여 기록 각각에서 찾습니다.

후속 확인은 선택 사업의 중복 제거 대표 참여 중 시운전일 또는 교육일이 없는 수입니다. 검색·상태 조건은 적용하지 않습니다. 클릭하면 데이터 점검으로 이동하되 목적지 필터를 지정하지 않습니다.
