## 목적과 표시값

프로젝트마다 하나의 접이식 카드로 전체 하위 업무 상태를 요약한다.

| 표시                                     | 현재 계산                                                                                                      |
| ---------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 상태·현재 단계·프로젝트명·연도·기관·담당 | 프로젝트 필드와 표시명. 기관이 비면 `기관 미입력`, 담당이 비면 `미지정`                                        |
| 전체 / 접수 / 처리 중 / 대기·막힘 / 완료 | 해당 프로젝트의 모든 참여 기록 ID에 연결된 업무의 전체 수 및 상태별 수                                         |
| 확인 필요 배지                           | 미완료 기한초과 업무 또는 미해결 프로젝트 직접 막힘이 1건 이상일 때. 대기 업무만 있다는 이유로 나타나지는 않음 |
| 하위 업무 완료율                         | `Math.round(완료 업무 / 전체 업무 × 100)`. 업무가 없으면 `업무 없음`, 막대 0%                                  |
| 참여 농가                                | 프로젝트 참여 기록을 `farmId`로 중복 제거한 개수. 중복 기록이 있으면 최근 활동 기록을 대표로 선택              |
| 기한초과                                 | 미완료이면서 마감일이 있고 오늘보다 이전인 업무 수                                                             |
| 7일 내 마감                              | 미완료이면서 오늘부터 7일 후까지 마감인 업무 수(양 끝 포함)                                                    |
| 프로젝트 직접 막힘                       | 프로젝트 업데이트 중 `kind === 'blocker' && !resolvedAt`인 수                                                  |

## 클릭과 필터 범위

요약 행은 펼치기·접기, **프로젝트 상세**는 해당 상세 화면 열기다. 카드 자체는 선택 사업연도·사업 타입·검색·프로젝트 상태 조건에 맞는 프로젝트만 표시한다. 검색으로 일부 업무만 보이더라도 이 카드의 합계와 비율은 해당 프로젝트 전체 기준이다.

프로젝트는 진행 → 보류 → 완료 순서, 같은 상태에서는 위험 수 내림차순 → 최근 활동 내림차순 → 이름순이다. 정렬의 위험 수는 `(대기 또는 미완료 기한초과인 업무 수) + 미해결 프로젝트 직접 막힘 수`이며 같은 업무가 대기·지연을 모두 만족해도 한 번 센다. 최근 활동은 프로젝트 수정, 업무 활동, 농가 이력 발생, 프로젝트 업데이트 발생, 문서 수정 시각 중 최댓값이다.

펼친 업무는 기본 8건이고 [하위 업무 행](child-work-row.md)의 더 보기로 확장한다. 업무가 없으면 등록 안내를 표시한다.
