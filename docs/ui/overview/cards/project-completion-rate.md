# 프로젝트 완료율 KPI

수정일: 2026-09-10

통합 현황·프로젝트 관리의 상단에 항상 표시합니다. 같은 영역에 진행 중 프로젝트 수와 완료 프로젝트 수도 표시합니다.

산식: 완료 프로젝트 수 ÷ 선택 연도·사업 타입의 전체 프로젝트 수 × 100, 정수 반올림.

보류 프로젝트는 전체 분모에 포함하지만 진행 중 수에는 포함하지 않습니다. 대상이 0개이면 `-`입니다. 삭제 프로젝트는 제외합니다. 과거 연말의 스냅샷이 아니라 해당 사업들의 현재 상태를 집계합니다.

‘하위 업무 완료율’은 최하위 실행 업무 기준이므로 별개의 KPI입니다. 검색·목록 상태 필터는 이 지표에 영향을 주지 않습니다.
