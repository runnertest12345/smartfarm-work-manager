# 처리 필요 업무 KPI

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

## 표시·계산

선택 프로젝트 하위 업무 중 완료가 아닌 업무 수입니다. 대기·막힘 수와 기한 지연 수를 함께 표시합니다. 지연은 미완료이면서 마감일이 오늘보다 과거인 경우입니다. 대기와 지연은 겹칠 수 있으므로 두 보조 수치를 더한 값은 아닙니다.

## 범위·동작

통합 현황과 프로젝트 관리에서 같은 카드를 사용합니다. 두 화면의 사업연도·사업 타입 선택을 공유하며, 검색·상태·위험 조건은 아래 목록에만 적용합니다. 카드는 조회용이며 클릭 동작은 없습니다. 건수의 빈 값은 0입니다.

사업별 동일 농가 참여는 최근 활동이 최신인 한 건을 사용하되, 업무는 해당 사업의 모든 참여 기록에서 수집합니다.
