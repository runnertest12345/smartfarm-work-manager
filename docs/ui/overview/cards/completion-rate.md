# 하위 업무 완료율 KPI

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

## 표시·계산

완료 업무 수 ÷ 선택 프로젝트 연결 업무 수 × 100을 정수 반올림합니다. 업무가 없으면 `-`입니다. 프로젝트별 비율의 단순 평균이 아닙니다.

## 범위·동작

통합 현황과 프로젝트 관리에서 같은 카드를 사용합니다. 두 화면의 사업연도 선택을 공유하며, 검색·상태·위험 조건은 아래 목록에만 적용합니다. 카드는 조회용이며 클릭 동작은 없습니다. 건수의 빈 값은 0입니다.

사업별 동일 농가 참여는 최근 활동이 최신인 한 건을 사용하되, 업무는 해당 사업의 모든 참여 기록에서 수집합니다.
