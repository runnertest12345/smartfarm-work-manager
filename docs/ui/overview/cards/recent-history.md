# 최근 업무·처리 히스토리

선택 사업연도·사업 타입 프로젝트의 연결 업무 이력만 모은 뒤 발생 시각 내림차순, 같으면 생성 시각 내림차순으로 최신 6건을 표시합니다. 업무당 한 건으로 묶지 않으므로 한 업무가 여러 카드로 나타날 수 있습니다. 검색·프로젝트 상태 조건은 적용하지 않습니다.

연결 업무의 종류·현재 상태·제목, 농가명·사업명, 이력 발생 시각과 받은 내용·처리 내용을 표시합니다. 업무 상태는 기록 당시가 아니라 현재 상태입니다. 클릭하면 해당 업무 전체 상세를 열고, 전체 보기는 농가 관리대장으로 이동합니다.

선택 범위에 이력이 없으면 첫 업무 등록 안내가 나옵니다. 프로젝트와 연결되지 않는 이력은 최신 6건을 고르기 전에 제외됩니다.
