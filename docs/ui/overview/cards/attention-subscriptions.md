# 확인 필요 · 구독 만료·미등록

‘구독 만료·미등록 / N개소 구독 확인’을 표시합니다. 선택 사업연도·사업 타입의 사업별 대표 참여 기록 중 오늘 유효 구독이 아닌 수입니다. 저장 상태 사용중 + 현재 만료일 오늘 이상만 유효합니다. 만료·미등록 모두 포함하며 고유 농가 수가 아닙니다.

같은 사업·농가 중복은 최신 참여 기록 한 건을 사용하고 다른 사업의 참여는 각각 계산합니다. 검색·상태 조건은 적용하지 않습니다. 클릭하면 구독 관리로 이동하되 목적지 필터를 자동 지정하지 않습니다. 대상이 없으면 0개소입니다.
