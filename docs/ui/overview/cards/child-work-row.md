# 프로젝트 하위 업무 행

작성일: 2026-09-07 · 구현 기준: `141faaa` · [화면 문서](../README.md)

## 목적과 표시값

펼친 프로젝트 안에서 개별 업무의 상태, 담당과 마감을 확인한다. 상태 배지, 업무 종류, 제목, 농가명, 담당자, 마지막 처리 내용, 마감 배지와 날짜를 표시한다. 농가 연결이 없으면 `농가 없음`, 담당이 비면 `미지정`이다.

마지막 처리 내용은 해당 업무 이력을 `occurredAt` 내림차순, 동률이면 `createdAt` 내림차순으로 정렬한 뒤 `actionContent.trim()`이 있는 첫 기록이다. 없으면 `nextAction`, 그것도 없으면 `처리 내용이 없습니다.`를 표시한다.

마감 배지는 완료 업무이면 `완료`, 미완료·날짜 없음이면 `기한 없음`, 지난 날짜이면 `N일 지연`, 오늘이면 `오늘 마감`, 이후이면 `D-N`이다. 날짜가 없으면 날짜 표시도 `미입력`이다. 날짜 차이는 브라우저의 로컬 오늘 자정 기준이다.

## 클릭과 필터 범위

행 전체를 누르면 해당 농가의 업무 전체 상세를 연다. 검색어가 프로젝트명·기관·담당·단계에 일치하면 모든 하위 업무를 표시한다. 그렇지 않으면 제목·담당·다음 행동·막힘 사유·농가명에 일치한 업무만 표시한다.

정렬은 기한초과 우선 → 대기 / 처리 중 / 접수 / 완료 → 마감일 오름차순(미입력은 뒤) → 최근 활동 내림차순이다. 처음 8건을 표시하며 9건 이상일 때 **나머지 N건 더 보기**로 전체를 펼치고 **하위 업무 접기**로 8건으로 줄인다. 빈 상태는 등록 업무 없음과 검색 결과 없음을 구분한다.
