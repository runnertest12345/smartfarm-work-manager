## 2026-09-14 첫 개선 범위

이 절이 현재 첫 화면의 기준이며, 아래 기존 카드 설명은 과거 배치의 참고 자료다. 9월 14일 중복 정리로 두 번째 프로젝트 트리는 제거하고 연도별 핵심 현황 아래 목록 하나만 유지한다. 상태 선택은 상단 카드에서만 하며 같은 필터 버튼을 목록 안에 반복하지 않는다. 최근 이력도 선택 연도·유형에 맞추고 내부 프로젝트에 농가 사업 점검을 섞지 않는다. [화면 중복 정리](../duplication-review.md) 참고.

- 연도·프로젝트 유형 선택 바로 아래에 전체 / 진행 중 / 보류 / 완료 프로젝트, 중복을 제외한 농가·유효 구독 농가 수를 한 영역에 표시한다. 일반·연구·내부 프로젝트를 모두 선택할 수 있다.
- 설치·시운전·교육은 농가 참여 기록별 완료 건수/전체 건수와 완료율을 항상 표시한다. 내부 프로젝트는 농가 지표에서 제외하고, 대상 없음은 `—` 또는 `대상 없음`으로 표시한다. 미완료가 남은 완료율은 빨간색이다.
- 프로젝트 상태 숫자를 누르면 같은 화면의 목록이 바뀐다. 농가/구독/단계 숫자를 누르면 같은 연도·유형의 근거 목록이 나타난다. 단계 목록은 전체/미완료/완료 필터를 제공한다.
- 프로젝트·업무 이름은 화면 중앙의 넓은 모달 팝업을 연다. 프로젝트 상태·담당자·종료 예정일은 한 번 클릭하면 팝업의 해당 입력란으로 이동한다. 프로젝트·업무 안에서 농가나 다른 업무를 열어도 같은 팝업 문맥을 유지한다. 배경은 흐리게 처리하고, 목록·보드·검색·연도·상태 필터·스크롤은 보존한다. 팝업은 최대 1200px 너비/1100px 높이로 화면 크기에 맞추며, 제목·닫기는 고정하고 본문만 스크롤한다. 프로젝트·업무와 무관하게 직접 연 농가는 기존 우측 패널을 유지한다.
- 기본정보는 이름·유형·연도·기관·설치 개소·상태·담당자·현재 단계·시작일·종료일·설명을 한 곳에서 편집하며 정산·계약은 보존한다. 정산은 정산 탭에서만 별도로 편집한다. 기존 권한/완료 검증과 `expectedUpdatedAt` 동시 수정 검증을 그대로 사용한다. 실패하면 초안을 유지하며 저장·취소 전에는 다른 상세/메뉴로 이동하지 않는다.
- `처리 필요` 한 줄은 선택 연도·유형 프로젝트의 최하위 실행 업무 기준 지연/대기·막힘을 표시하고 해당 업무 목록으로 연결한다. 동일 업무가 두 조건에 해당할 수 있다. 프로젝트의 보류 상태와 업무의 대기·막힘 상태는 별개다.
- 업무 처리·내부 업무 전체기간 지표·이력은 `업무 처리·확인 필요·최근 이력 자세히`에 접어 둔다. 업무 목록은 상위와 바로 아래 세부 업무부터 보여주고, 깊은 업무는 필요한 가지를 펼친다. 검색은 깊은 업무와 상위 경로를 드러낸다.
- 프로젝트 작업은 제목 아래에 직접 표시하며 `더보기`와 중복 전체 수정 버튼은 제거했다. 업무 목록의 드문 동작 메뉴와 삭제 확인·기존 권한은 유지한다.

## 목적과 진입

프로젝트 수, 프로젝트에 연결된 하위 업무의 상태, 최근 처리 이력과 확인 대상을 한 화면에서 확인한다. 기본 시작 화면이며 왼쪽 메뉴의 **통합 현황**으로 진입한다. 화면 제목은 **프로젝트·하위 업무 처리 현황**이다.

## 검색과 필터

- [사업 타입 선택](../common/cards/project-type-filter.md)과 연도는 함께 적용하며 프로젝트 관리와 공유한다.
- 상단 연도 카드를 선택하면 KPI·프로젝트 목록·최근 이력·확인 필요가 해당 사업연도로 바뀐다. 프로젝트 관리의 연도 선택과 공유하며, 과거 연말 상태가 아니라 선택 연도 사업의 현재 상태를 보여준다.
- 검색은 앞뒤 공백을 제거하고 소문자로 비교한다. 프로젝트명·기관·담당자·현재 단계의 표시명과 업무 제목·담당자·다음 행동·막힘 사유·농가명을 검색한다.
- 상태 버튼은 전체 / 진행 / 보류 / 완료이다. 버튼의 건수는 검색과 무관한 선택 사업연도·사업 타입 프로젝트 기준이다.
- 검색과 상태는 프로젝트 목록에만 적용된다. 상단 KPI, 최근 이력, 확인 필요 카드의 수치는 바뀌지 않는다.
- 프로젝트 자체가 검색에 일치하면 해당 프로젝트의 모든 업무를 보여준다. 업무 내용만 일치하면 해당 업무만 보여주지만 프로젝트별 상태 합계와 완료율은 해당 프로젝트의 전체 업무 기준이다.

## 내부 프로젝트·업무 KPI

사업 KPI 아래에 별도의 내부 지표 4개를 표시한다: 내부 프로젝트 수, 전체 내부 업무 수(상위·세부), 미완료 실행 업무(대기·막힘·기한 지연), 내부 실행 업무 완료율.

- 내부 업무에는 공통 사업연도가 없으므로 **전체 기간 기준**이다. 상단의 사업연도·타입·검색과 별도로 집계한다고 화면에 명시한다. 이전 연도 부모와 현재 세부 업무도 같은 묶음을 유지한다.
- `scope=internal`인 활성 업무를 프로젝트 연결 여부와 무관하게 집계한다. 삭제된 업무·프로젝트는 각 건수에서 제외한다. 동일 업무 ID는 중복 집계하지 않는다.
- 실행 업무는 최하위 업무로 계산하며 상위를 중복 계산하지 않는다. 업무가 없거나 필요한 자식 자료가 누락된 경우 완료율은 `-`로 표시한다. 실행 업무 100%와 상위 업무의 최종 완료는 별개다.
- 프로젝트 수 클릭은 전체 연도의 내부 프로젝트 관리 목록으로, 업무 지표 클릭은 전체 기간 내부 업무 목록으로 이동한다. 미완료 지표는 최하위 미완료 업무를 선택하며 상위는 맥락을 위해 함께 표시한다.
- 내부 프로젝트는 일반·연구 사업 KPI와 설치·농가·구독·정산 집계에 포함하지 않는다. 내부 프로젝트 필터를 사용한 뒤 통합 현황으로 돌아오면 사업 지표는 전체 사업 타입으로 표시하고 클릭 이동에도 같은 기준을 쓴다.

## 빈 상태

프로젝트가 없으면 **아직 등록된 프로젝트가 없습니다.**, 조건에 맞는 프로젝트가 없으면 **선택한 연도·사업 타입·검색·상태에 맞는 프로젝트가 없습니다.**를 표시한다. 후자의 **필터 초기화**는 검색어·프로젝트 상태·사업연도·사업 타입을 모두 초기화한다. 프로젝트 안에서는 업무가 없거나 검색 결과가 없는 경우를 구분해서 안내한다. 최근 이력이 없으면 농가 상세에서 첫 업무를 등록하도록 안내한다.
