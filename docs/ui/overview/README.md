# 통합 현황

작성일: 2026-09-07 · 구현 기준: 연도·구독 KPI 개선 · 화면 상태: `view === 'overview'`

[전체 목차](../README.md) · [입력창 목차](../forms/README.md)

## 목적과 진입

프로젝트 수, 프로젝트에 연결된 하위 업무의 상태, 최근 처리 이력과 확인 대상을 한 화면에서 확인한다. 기본 시작 화면이며 왼쪽 메뉴의 **통합 현황**으로 진입한다. 화면 제목은 **프로젝트·하위 업무 처리 현황**이다.

## 검색과 필터

- [사업 타입 선택](../common/cards/project-type-filter.md)과 연도는 함께 적용하며 프로젝트 관리와 공유한다.
- 상단 연도 카드를 선택하면 KPI·프로젝트 목록·최근 이력·확인 필요가 해당 사업연도로 바뀐다. 프로젝트 관리의 연도 선택과 공유하며, 과거 연말 상태가 아니라 선택 연도 사업의 현재 상태를 보여준다.
- 검색은 앞뒤 공백을 제거하고 소문자로 비교한다. 프로젝트명·기관·담당자·현재 단계의 표시명과 업무 제목·담당자·다음 행동·막힘 사유·농가명을 검색한다.
- 상태 버튼은 전체 / 진행 / 보류 / 완료이다. 버튼의 건수는 검색과 무관한 선택 사업연도·사업 타입 프로젝트 기준이다.
- 검색과 상태는 프로젝트 목록에만 적용된다. 상단 KPI, 최근 이력, 확인 필요 카드의 수치는 바뀌지 않는다.
- 프로젝트 자체가 검색에 일치하면 해당 프로젝트의 모든 업무를 보여준다. 업무 내용만 일치하면 해당 업무만 보여주지만 프로젝트별 상태 합계와 완료율은 해당 프로젝트의 전체 업무 기준이다.

## 버튼과 동작

| 위치                                | 동작                                                                                            |
| ----------------------------------- | ----------------------------------------------------------------------------------------------- |
| 전체 업무                           | 업무 현황 화면으로 이동                                                                         |
| 프로젝트 등록                       | 프로젝트 등록 창 열기                                                                           |
| 프로젝트 요약 행                    | 아코디언 펼치기·접기                                                                            |
| 프로젝트 상세                       | 해당 프로젝트 상세 열기                                                                         |
| 하위 업무 행, 최근 이력 카드        | 연결된 농가의 업무 전체 상세 열기                                                               |
| 나머지 N건 더 보기 / 하위 업무 접기 | 기본 8건과 전체 검색 결과 전환                                                                  |
| 최근 업무·처리 히스토리의 전체 보기 | 농가 관리대장으로 이동                                                                          |
| 확인 필요의 세 카드                 | 각각 업무 현황 / 구독 관리 / 데이터 점검 화면으로 이동. 목적지 필터를 자동으로 설정하지 않는다. |

## 빈 상태

프로젝트가 없으면 **아직 등록된 프로젝트가 없습니다.**, 조건에 맞는 프로젝트가 없으면 **선택한 연도·사업 타입·검색·상태에 맞는 프로젝트가 없습니다.**를 표시한다. 후자의 **필터 초기화**는 검색어·프로젝트 상태·사업연도·사업 타입을 모두 초기화한다. 프로젝트 안에서는 업무가 없거나 검색 결과가 없는 경우를 구분해서 안내한다. 최근 이력이 없으면 농가 상세에서 첫 업무를 등록하도록 안내한다.
