# 공통 화면 구성과 이동

기준: 2026-09-07 · 소스 커밋 `141faaa`

## 화면 구성

팜로그는 하나의 웹 주소 안에서 메뉴와 상세 화면을 전환한다. 현재 메뉴·선택 농가·선택 프로젝트·업무는 화면 내부 상태로 관리한다. 따라서 주소의 `release` 값은 배포 버전 식별용이며, 특정 농가나 업무를 가리키는 공유 링크가 아니다.

| 메뉴          | 목적                              | 메뉴 옆 숫자의 기준                            |
| ------------- | --------------------------------- | ---------------------------------------------- |
| 통합 현황     | 프로젝트 수와 하위 업무 처리 현황 | 숫자 없음                                      |
| 업무 현황     | 수신·관제·보드·목록·주간 검토     | 전체 업무 중 완료가 아닌 업무 수               |
| 농가 관리대장 | 농가 기준 조회와 사업 참여 정보   | 농가 객체 수                                   |
| 프로젝트 관리 | 사업 진행·막힘·서류·정산          | 전체 프로젝트 수                               |
| 사업 집계     | 사업 타입·연도별 진행률           | 숫자 없음                                      |
| 구독·입금     | 구독 관리와 구독 실적             | 전체 참여 레코드 수 − 현재 유효 구독 레코드 수 |
| A/S 업무      | A/S 대응과 현장 처리              | A/S 유형 중 완료가 아닌 업무 수                |
| 데이터 점검   | 중복·누락 확인                    | 발견된 점검 항목 수. 농가 수가 아님            |

구독·입금의 숫자에는 만료뿐 아니라 미등록도 포함된다. 농가가 여러 사업에 참여하면 해당 숫자에는 여러 번 포함될 수 있다.

## 공통 버튼

공통 카드: [접속 계정](cards/account-summary.md) · [승인 사용자·관리 규모 안내](cards/workspace-notice.md).

| 요소               | 동작                                                            |
| ------------------ | --------------------------------------------------------------- |
| 새로고침           | 데이터 동기화를 다시 확인한다. 처리 중에는 중복 클릭을 막는다   |
| 사업 추가          | 사업 등록 입력창을 연다                                         |
| 농가 등록          | 농가와 첫 사업 참여 정보를 등록한다. 사업이 없으면 비활성화된다 |
| 로그아웃           | 현재 Firebase 로그인 세션을 종료한다                            |
| 모바일 메뉴 선택란 | 데스크톱 왼쪽 메뉴와 같은 화면으로 전환한다                     |

## 상세 화면 이동

프로젝트·농가·업무를 열면 목록 영역 대신 전체 상세 영역을 표시하고 맨 위로 이동한다. 상세 화면에서 다른 상세 화면으로 이동할 때 이전 대상과 스크롤 위치를 기억한다. 화면의 뒤로가기 버튼은 이전 상세 또는 목록의 스크롤 위치로 돌아간다. 이는 브라우저 주소 이력과는 별도의 동작이다.

메뉴 변경 시 열린 상세 화면과 상세 이동 이력을 닫는다. 다른 메뉴의 필터를 모두 초기화하는 동작은 아니다. 필터 적용 범위는 각 화면 문서를 따른다.

## 공통 표시 상태

| 상태             | 화면 표시와 후속 동작                             |
| ---------------- | ------------------------------------------------- |
| 데이터 읽는 중   | 회전 표시와 ‘농가 관리대장을 불러오는 중입니다.’  |
| 데이터 조회 실패 | 오류 안내와 ‘다시 시도’ 버튼                      |
| 데이터 조회 완료 | 승인 사용자 안내, 사업 수·농가 수, 선택 메뉴 내용 |
| 저장 성공        | 성공 알림과 실시간 데이터 갱신                    |
| 입력·저장 실패   | 입력창의 오류 안내. 성공한 것으로 취급하지 않는다 |
