# 접속 계정 카드

- **위치:** 데스크톱 왼쪽 메뉴 하단.
- **목적:** 현재 접속 계정을 확인하고 로그아웃한다.
- **표시:** ‘Firebase 무료 운영’ 안내, 사용자 표시 이름, 이메일, 로그아웃 버튼. 긴 이름·이메일은 한 줄로 줄이며 이메일에 마우스를 올리면 전체 값이 표시된다.
- **동작:** 로그아웃 버튼을 누르면 Firebase 로그인 세션을 종료한다. 모바일에서는 해당 카드 대신 상단 로그아웃 아이콘을 사용한다.
- **범위:** 현재 인증 사용자 기준. 화면 검색·연도·사업 필터와 무관하다.
- **데이터:** `accountName`, `accountEmail`, `onSignOut`. 이름이 없으면 접근 화면에서 ‘사용자’를 전달한다.

코드 근거: [대시보드](../../../../app/farm-ledger-dashboard.tsx)의 왼쪽 메뉴 하단, [인증 화면](../../../../app/firebase-auth-gate.tsx)의 `FarmLedgerDashboard` 호출.
