# 사업 타입 선택

갱신일: 2026-09-07

‘전체 사업 타입 / 일반 사업 / 연구 사업’ 중 선택합니다. 저장된 사업 타입을 기준으로 집계하며 사업명으로 추정하지 않습니다. 선택값과 목록은 한글로 표시합니다.

## 화면별 범위

- 통합 현황·프로젝트 관리: 같은 연도·타입 선택을 공유합니다. 연도와 타입의 교집합으로 KPI, 프로젝트 목록, 상태 수, 최근 이력, 확인 필요를 집계합니다. 연도 카드는 선택 타입의 숫자를 표시하되 전체 등록연도를 유지하므로 빈 연도도 0건으로 선택할 수 있습니다.
- 구독·입금 관리: 타입과 개별 사업을 함께 적용해 현재 회차, 사용중·만료·90일 내 만료, 입금 합계·평균, 월별 입금, 표를 집계합니다. 타입을 바꾸면 개별 사업을 전체 사업으로 초기화하고 페이지를 1로 돌립니다. 개별 사업 선택지에는 해당 타입의 사업만 나타납니다.
- 만료·실적 보고와 사업 집계: 기존 타입 선택을 유지하며 다른 화면의 타입 선택과 독립적입니다.

조회 범위만 바꾸며 실제 농가·사업·입금 데이터는 수정하지 않습니다. 통합 현황의 필터 초기화는 검색·상태·연도·타입 모두 전체로 돌립니다. 구독 관리 검색·상태는 KPI를 줄이지 않고 표만 제한합니다.
