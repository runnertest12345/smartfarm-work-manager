# 승인 사용자·관리 규모 안내 카드

- **위치:** 데이터 조회가 완료된 각 주요 메뉴 상단. 상세 화면을 열면 목록 영역과 함께 숨겨진다.
- **목적:** 승인된 사용자의 관리대장임을 안내하고 전체 관리 규모를 보여준다.
- **표시:** ‘승인된 사용자만 보는 Firebase 관리대장입니다’, 전체 사업 수와 농가 수, 보안 규칙·승인 목록 안내.
- **계산:** 사업 수는 `workspace.projects.length`, 농가 수는 `workspace.farms.length`. 사업 상태나 화면 필터로 축소하지 않는다.
- **동작:** 조회 전용 안내이며 별도의 클릭·저장 동작은 없다.
- **데이터:** 전체 작업공간의 프로젝트·농가 목록. 실제 접근 승인은 [접근 상태 카드](../../auth/cards/access-state.md)에서 설명한다.
