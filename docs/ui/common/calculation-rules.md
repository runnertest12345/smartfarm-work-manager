# 공통 계산 기준과 해석

기준: 2026-09-07 · 기본 소스 `141faaa` 및 연도·구독 KPI 개선. 아래는 현재 구현된 계산식이다.

## 날짜와 빈 값

화면의 오늘·남은 일수·월은 브라우저의 현지 날짜를 사용한다. 한국 업무 운영 시 브라우저 시간대를 한국 시간으로 맞추면 같은 기준으로 볼 수 있다. 날짜가 없으면 ‘미입력’ 또는 ‘기한 없음’으로 표시한다. 대부분의 진행률은 분모가 0이면 `-`로 표시하지만, 농가 관리대장 구독률은 0%로 표시한다.

날짜가 오늘인 구독은 유효 기간에 포함된다. 마감 지연은 완료되지 않은 업무의 마감일이 오늘보다 앞선 경우이다. ‘7일 이내’는 오늘부터 7일 뒤까지 포함한다.

## 구독 상태와 비율

| 항목                 | 현재 계산                                                                |
| -------------------- | ------------------------------------------------------------------------ |
| 참여 정보의 구독 중  | 저장 상태가 사용중이고 현재 만료일이 존재하며 오늘 이상                  |
| 참여 정보의 만료     | 저장 상태가 만료이거나, 만료일이 존재하고 오늘보다 과거                  |
| 참여 정보의 미등록   | 위 두 조건에 해당하지 않음                                               |
| 농가의 구독 중       | 선택 범위 안에 구독 중 참여 정보가 하나 이상                             |
| 농가의 만료          | 구독 중이 없고 만료 참여 정보가 하나 이상                                |
| 농가의 미등록        | 구독 중·만료 참여 정보가 모두 없음                                       |
| 농가 관리대장 구독률 | 구독 중 농가 수 ÷ 전체 농가 수 × 100, 정수 반올림                        |
| 프로젝트 구독률      | 현재 유효 구독 참여 농가 수 ÷ 프로젝트 내 중복 제거한 참여 농가 수 × 100 |
| 구독 만료 임박       | 현재 유효 구독 중 오늘부터 90일 이내 만료                                |

저장 상태가 사용중이어도 만료일이 없으면 현재 유효 구독 수에는 포함되지 않는다. 선택한 사업 범위에 따라 같은 농가의 구독 판정이 달라질 수 있다.

## 구독 실적

집계 기간은 선택 연도 1월부터 종료월 말일까지다. 처음에는 전월의 연도와 월이 선택된다. 사업 범위는 전체 사업 타입·일반 사업·연구 사업 중에서 선택한다.

| 지표                | 계산                                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| 만료 대상           | 기간에 속한 갱신·이탈 이력의 참여 ID+기준 만료일과, 현재 만료일이 기간에 속한 참여 정보의 회차를 합쳐 중복 제거 |
| 갱신·이탈           | 기준 만료일이 집계 기간에 속한 각각의 회차 수                                                                   |
| 재가입              | 처리일이 집계 기간에 속한 재가입 이벤트 수                                                                      |
| 기간 미처리 회차    | 기간 만료 대상 회차 집합에서 갱신·이탈 결과 회차의 합집합을 제외. 오늘 기준 카드와 별도                         |
| 만료 후 결과 미등록 | 오늘 이전 현재 만료일이 있으며 오늘까지 같은 참여·기준 만료일의 갱신·이탈 결과가 없는 수. 사업 타입만 적용      |
| 갱신률              | `갱신 ÷ (갱신 + 이탈) × 100`, 소수 첫째 자리 반올림. 처리 결과가 없으면 `-`                                     |
| 만료 예정           | 현재 시점에서 유효 구독이고 현재 만료일이 오늘 이상인 참여 정보. 오늘 만료 포함, 사업 타입만 적용               |

예를 들어 만료 대상 33개소, 갱신 22개소, 이탈 0개소라면 현재 화면의 갱신률은 100%다. 단순 예시의 기간 미처리 회차는 11개소지만 오늘 기준 만료 후 결과 미등록은 현재 만료일과 처리 이력으로 별도 계산한다. 전체 만료 대상 대비 갱신 비중은 약 66.7%이지만, 현재 갱신률 카드의 분모에는 처리 대기가 포함되지 않는다.

만료 예정은 과거 시점의 상태를 복원한 수치가 아니다. 과거 기간을 골라도 현재 유효 상태를 사용한다. 최근 구독 처리 목록은 사업 타입을 따르지만 집계 연도·종료월과 별개로 최근 처리 8건을 표시한다.

## 상단 사업연도 KPI와 현재 구독 회차

[연도 공통 KPI](annual-kpis.md)는 사업 등록연도와 사업 타입의 교집합으로 선택하며 통합 현황과 프로젝트 관리에서 공유한다. 설치·시운전·교육·구독 비율은 사업별 중복 제거 참여 수를 합산한 가중 비율이고 프로젝트 비율의 단순 평균이 아니다. 하위 업무는 업무 ID로 중복 제거한다.

구독 현재 회차는 [최초 구독·입금 확인](../subscriptions/cards/cycle-initial.md), 1차·2차·3차 이상 연장, 미확인으로 나누며 한 참여는 한 카드에만 포함한다. 최초는 구독 등록 근거와 연장 0회 및 같은 참여의 양수 입금 업무 이력을 요구한다. 입금일 필드만으로는 부족하다. 미래 발생 이력·중복 이력 ID는 입금 근거에서 제외한다. 연장은 등록 갱신횟수 기준이며 과거 입금·갱신 사건 수를 복원하지 않는다. 보고 기간과 독립적이다.

## 프로젝트 진행률

프로젝트의 농가 확정률은 참여 농가 수 ÷ 목표 농가 수이며 최대 100%이다. 목표 농가가 0이면 확정률이 없다. 생산 세팅·설치·시운전·교육률은 해당 날짜가 있는 농가 수 ÷ 프로젝트 참여 농가 수이다. 미래 날짜도 입력되어 있으면 날짜 존재 조건에 포함된다.

종합 진행률은 다음 일곱 값의 산술평균을 정수로 반올림한다. 값이 없으면 0으로 간주한다.

1. 농가 확정률
2. 생산 세팅률
3. 설치율
4. 시운전율
5. 교육율
6. 필수서류 승인율
7. 정산 단계 점수

| 정산 상태 | 진행 점수 |
| --------- | --------: |
| 미착수    |         0 |
| 자료 수집 |        20 |
| 정산 제출 |        50 |
| 보완 중   |        40 |
| 승인      |        75 |
| 입금 완료 |       100 |
| 정산 마감 |       100 |

이 종합 진행률과 하위 업무 완료율은 별개다. 사업 집계의 사업별 진행률은 설치·시운전·교육·구독률 중 값이 있는 항목의 평균이다. 프로젝트 화면의 종합 진행률과 계산 대상이 다르다.

## 서류·입금·최근 기록

필수서류 제출 수는 제출일이 있는 필수서류 수이고, 승인 수는 상태가 승인인 필수서류 수다. 보완·반려 서류, 또는 기한이 지난 미승인 필수서류가 서류 위험에 포함된다.

입금 집계는 업무 유형이 입금이고 이력 금액이 0보다 큰 기록의 합계다. 프로젝트의 계약·청구·승인·정산 입금 금액과는 별도 입력 데이터이다. 평균 입금은 해당 범위 입금 합계 ÷ 입금 이력이 있는 고유 농가 수를 정수로 반올림하며, 대상 농가가 없으면 0이다.

진행 이력은 발생 시각 최신순이며, 같은 시각의 정렬에 생성 시각을 추가로 쓰는 화면도 있다. 프로젝트 최근 활동은 프로젝트 기록과 연결 업무 이력을 합쳐 12건까지 표시한다.

## 응답·업무 위험

| 응답 표시             | 조건                                          |
| --------------------- | --------------------------------------------- |
| 응답 목표 없음        | 목표 시각 없음                                |
| 응답 목표 달성 / 실패 | 최초 응답 시각이 목표 이하 / 초과             |
| 응답 목표 초과        | 응답 전이고 현재 시각이 목표를 지남           |
| 24시간 이내           | 응답 전이고 목표까지 24시간 이하              |
| 응답 주의             | 응답 전이고 목표까지 24시간 초과, 72시간 이하 |
| 응답 여유             | 응답 전이고 목표까지 72시간 초과              |

업무 등록의 기본 응답 목표는 우선순위 높음 24시간, 보통 72시간, 낮음 168시간 뒤다. 업무 보드의 처리 중+대기 업무 권장 한도는 전체 기준 5건이며, 경고 표시이지 저장을 막는 제한은 아니다.
