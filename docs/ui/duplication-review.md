# 화면 중복 정리 · 2026-09-14

## 배치 원칙

같은 화면에 동일한 정보·동작을 반복하지 않는다. 목록의 요약과 상세의 원본 정보, 맥락이 다른 바로가기는 유지한다. 기존 데이터·권한·집계 공식은 변경하지 않는다.

| 영역 | 정보를 관리하는 위치 | 제거·구분한 중복 |
| --- | --- | --- |
| 프로젝트 기본정보 | 상세 팝업의 기본정보 | 일반·내부 프로젝트 공통 편집기 한 개. 아래의 유형·상태·담당자·일정·설명 재출력과 전체 수정 진입점 제거 |
| 프로젝트 정산 | 상세의 정산 탭 | 조회에서 ‘정산 수정’을 누르면 같은 자리에서 정산 필드만 편집. 기본정보를 포함하는 중첩 팝업 제거 |
| 프로젝트 작업 | 제목 아래 작업 영역 | 업무·기록·제출서류 추가와 삭제·복구를 직접 노출. 기록·서류 탭의 같은 추가 버튼 제거. 내부 프로젝트에는 내부 업무 등록과 삭제·복구만 표시 |
| 프로젝트 업무 | 하위 업무 탭 | 직접 업무 등록과 수신함 저장은 다른 기능이므로 후자를 ‘빠른 수신’으로 명확히 구분 |
| 통합 현황 | 연도별 핵심 현황 → 단일 프로젝트 목록 | 아래쪽의 두 번째 프로젝트 트리와 반복 상태 필터·지연 KPI 제거. 선택 상태는 상단 지표에 표시 |
| 최근 처리 이력 | 통합 현황의 펼침 영역 | 상단과 같은 연도·프로젝트 유형 범위 적용. 내부 프로젝트 선택 시 농가 사업 점검을 섞지 않음 |
| 구독·입금 | 현재 관리는 관리 탭, 기간별 실적은 보고 탭 | 현재 갱신 회차 요약은 관리 탭에만 표시 |
| 농가 A/S | 참여 사업 행 또는 A/S 탭 | 동일한 일반 등록 버튼의 중간 반복 제거. 사업을 지정한 등록 바로가기는 유지 |
| 업무 처리 기록 | 이력 머리말 | 발신자와 기록자가 같으면 이름을 한 번만 표시. 서로 다르면 둘 다 보존 |

## 유지한 기능과 보호

- 프로젝트명 클릭 조회, 상태·담당자·기한 클릭 편집, 전체 팝업과 목록 복귀 유지.
- 하위 업무 들여쓰기·접기/펼치기·대기/막힘 표시 유지.
- 완료·삭제 프로젝트 잠금, 정산 이관 금액 및 차수 보존, 기존 버전 충돌 검사 유지.
- 기본정보·정산 미저장 초안이 있으면 상세 닫기·탭·메뉴·브라우저 뒤로가기를 막고 저장/취소를 안내.
- 정산 저장은 정산 필드만 변경하며 같은 요청에 기본정보 변경을 섞지 않음.
- 반대 영역에 미저장 초안이 있으면 저장도 차단. 기본정보의 내부 유형 전환으로 정산 초안이 사라지거나 두 편집기가 서로 덮어쓰지 않도록 먼저 한쪽을 저장/취소하도록 안내.
- 운영 서버 배포와 실제 업무 데이터 수정은 이번 화면 정리 범위에 포함하지 않음.
