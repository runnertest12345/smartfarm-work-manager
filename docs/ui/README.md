## 문서 읽는 방법

화면 문서에는 진입 경로, 필터, 버튼, 카드 목차와 빈 화면 동작을 정리했다. 카드 문서에는 목적, 표시 항목과 계산식, 클릭 동작, 필터 적용 범위, 연결 데이터와 코드 근거를 담았다. 입력창 문서에는 필드, 필수·조건부 항목, 저장 시 변경되는 데이터와 제약을 담았다.

‘현재 구현’은 기본 커밋과 2026-09-07 KPI 개선에서 확인한 동작이다. 카드 문서의 갱신일과 함수 이름을 기준으로 확인하며, 기존 소스 행 번호는 코드 추가에 따라 이동할 수 있다. 요구사항으로 제안했던 기능이나 향후 개선 아이디어를 구현 완료로 간주하지 않는다. 특히 농가 수와 사업 참여 수, 전체 집계와 필터된 목록, 구독률과 갱신률은 분모가 다르므로 관련 계산 설명을 함께 확인한다.

## 유지 관리

화면을 변경하면 해당 화면 문서와 연결된 카드·입력창 문서를 함께 갱신한다. 카드의 이름·계산·동작이 바뀌면 개별 문서를 수정하고, 카드 추가·삭제 시 해당 화면 목차와 카드 전체 목록도 갱신한다. 실제 농가 개인정보, 비밀번호, 인증 토큰은 설명용 예시에 넣지 않는다.
