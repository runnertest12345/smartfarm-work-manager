# A/S 업무 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

A/S 화면의 모든 service 업무에 사용한다. 상태 배지·최종 활동시각·제목·농가명·사업명·담당자, 마지막 받은 내용과 마지막 처리 내용을 각각 표시한다. 각 ‘마지막’은 해당 필드가 비어 있지 않은 최신 이력을 별도로 찾는다.

업무 제목·내용은 상세로 이어지는 요약이며 카드 전체를 누르면 업무 상세를 연다. 받은/처리 내용 없음과 담당자 미지정 등의 대체 문구가 있다. 카드 자체 필터는 없고 화면의 서비스 유형 제한·위험 정렬을 따른다. service 업무가 0건이면 화면 단위 빈 안내가 나타난다.
