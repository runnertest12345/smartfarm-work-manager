# A/S 업무 요약 행

수정일: 2026-09-11

A/S 목록은 접수일, 농가·프로젝트, 업무명, 상태, 최근 처리 내용, 상세 버튼을 한 행에 표시한다. 긴 제목·처리 내용은 두 줄까지만 보여주고 프로젝트명은 말줄임한다. 좁은 화면에서는 표를 가로로 이동할 수 있다.

‘보기’를 누르면 해당 행 아래에 전체 농가·프로젝트명, 담당자, 마지막 받은 내용, 마지막 처리 내용, 업무 상세·처리 이력 버튼을 표시한다. ‘접기’로 되돌릴 수 있고 연도를 바꾸면 모든 상세를 접는다. 각 ‘마지막’은 해당 필드가 비어 있지 않은 최신 이력을 별도로 찾는다. 제목은 해당 업무 전체 상세로 이동한다.
