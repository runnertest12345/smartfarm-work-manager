# A/S 업무 관리

수정일: 2026-09-11

메뉴의 A/S 화면(`view='service'`)은 삭제되지 않은 `workType='service'` 업무를 완료 상태까지 포함해 조회한다. 과거 파모스박스 교체 이력도 유지한다. 큰 카드 대신 [간결한 표와 펼침 상세](cards/service-item.md)를 표시한다.

접수 연도 선택은 한국 시간 기준 현재 연도가 기본이며, 해당 연도만 표시한다. 전체 연도와 접수일 미지정도 선택할 수 있다. 접수일은 최초로 저장된 이력의 발생일(동일 저장 시각이면 유효한 이른 발생일)을 우선하며, 없거나 유효하지 않으면 업무 생성일을 사용한다. 이후 추가한 과거 이력, 최근 처리 시각, 프로젝트 사업연도는 접수 연도를 바꾸지 않는다. 값이 모두 유효하지 않으면 접수일 미지정이다.

상단 ‘A/S 등록’은 농가명·농장번호 검색 → 농가 선택 → 참여 사업 선택 → ‘A/S 내용 작성’ 순으로 기존 등록 창을 연다. 농가 변경 시 사업 선택을 초기화한다. 여러 사업 중 임의 선택은 하지 않는다. 농가 목록은 전체 농가 관리대장에서 가져오며 사업 연도·완료 여부·참여 기록 유무로 숨기지 않는다. 참여 사업에는 미삭제 프로젝트의 기록을 제공하며 완료 사업도 ‘완료’ 표시와 함께 선택할 수 있다. 연결 가능한 참여 사업이 없는 농가는 표시를 유지하고 참여 사업 등록 또는 삭제 사업 복구를 안내한다. 참여 기록 없이 임의의 사업이나 A/S를 생성하지 않는다. 취소 후 뒤로가기 1회, 저장 후 뒤로가기 2회로 출발한 A/S 화면에 돌아올 수 있다.

완료 사업에서도 실제 농가 참여 기록에 연결된 A/S의 신규 등록·처리 기록·체크리스트·현장 방문·완료·재개를 허용한다. 사업의 완료 상태와 구독 정보는 변경하지 않는다. 일반 업무와 농가 참여 기록이 없는 프로젝트 업무에는 이 예외를 적용하지 않으며, 삭제 사업의 신규 A/S는 계속 차단한다. 업무 삭제·복원 정책은 기존대로 유지한다.

정렬은 미완료 우선 → 대응 위험(목표 초과, 24시간 이내, 72시간 이내 주의, 대응 목표 실패, 여유, 목표 없음, 달성) → 두 업무가 모두 대기이면 막힘 시작(없으면 수정시각) 오름차순 → 최근 활동 내림차순이다. 업무 카드에는 대응 위험 배지를 직접 표시하지 않지만 정렬에는 활용한다.

제목이나 ‘업무 상세 · 처리 이력’을 누르면 [업무 전체 상세](../work/detail.md)에서 처리 기록을 이어간다. 선택 연도에 A/S가 없으면 다른 연도 선택 또는 신규 등록 안내를 표시한다.
