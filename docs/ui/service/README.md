# A/S 업무 관리

기준 커밋: `141faaa` · 작성일: 2026-09-07

메뉴의 A/S 화면(`view='service'`)은 `workType='service'` 업무를 완료 상태까지 포함해 모두 조회한다. 검색·유형·상태·사업 필터와 상단 KPI는 없다. 2열 반응형 격자에 [A/S 카드](cards/service-item.md)를 표시한다.

정렬은 미완료 우선 → 대응 위험(목표 초과, 24시간 이내, 72시간 이내 주의, 대응 목표 실패, 여유, 목표 없음, 달성) → 두 업무가 모두 대기이면 막힘 시작(없으면 수정시각) 오름차순 → 최근 활동 내림차순이다. 업무 카드에는 대응 위험 배지를 직접 표시하지 않지만 정렬에는 활용한다.

카드를 누르면 [업무 전체 상세](../work/detail.md)에서 처리 기록을 이어간다. A/S가 없으면 ‘등록된 A/S 업무가 없습니다’를 표시한다.
