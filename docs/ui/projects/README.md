# 프로젝트 통합관리

2026-09-09: [삭제·복구, 넓은 추가 창, 농가 진행상황과 세부 보기](management-update.md)를 적용했다. 아래 이전 설명과 다르면 이 개선 문서를 우선한다.

작성일: 2026-09-07 · 기준: 연도·구독 KPI 개선 · 현재 구현 설명

## 화면 목적·진입

왼쪽 ‘프로젝트 관리’ 메뉴에서 프로젝트별 농가, 설치·시운전·교육·구독률, 막힘, 서류, 정산 상태를 확인합니다. 내부 화면 값은 `view === 'projects'`입니다. 프로젝트 카드 전체를 누르면 [프로젝트 전체 상세](detail.md)를 엽니다.

## 검색·필터

2026-09-07 개편: 기본은 표 보기이며 카드 보기로 전환할 수 있다. 연도 선택은 상단의 작은 버튼 하나로 통합했다. 아래의 ‘연도 카드/기존 선택란’ 설명은 이 단일 선택으로 대체한다. 핵심 4개 KPI와 펼침 지표 8개, 상세 탭 연결은 [개편 기준](../ux-redesign.md)을 따른다.

상단에는 [연도별 사업 현황과 공통 KPI 12개](../common/annual-kpis.md)가 있습니다. 연도 카드를 누르거나 기존 사업연도 선택란을 바꾸면 통합 현황과 같은 연도 선택을 유지합니다. 통합 현황과 공유하는 사업 타입(전체·일반·연구)도 선택할 수 있습니다. 상단 KPI에는 연도·사업 타입을 함께 적용하며 검색·위험 조건은 아래 프로젝트 목록에만 적용합니다. 과거 연말 상태가 아니라 해당 연도 사업의 현재 상태입니다.

검색은 프로젝트명·기관·담당자·연도를 합친 문자열의 부분 일치입니다. 앞뒤 공백을 제거하고 대소문자를 구분하지 않습니다. 사업연도는 전체 또는 등록된 연도를 선택합니다. 별도 사업 상태 선택기는 이 목록에 없습니다.

| 위험 필터     | 포함 조건                                                   |
| ------------- | ----------------------------------------------------------- |
| 모든 프로젝트 | 검색·연도 조건에 맞는 전체                                  |
| 막힘 있음     | 미해결 프로젝트 막힘 또는 대기 업무가 하나 이상             |
| 서류 위험     | 보완 요청·반려 서류 또는 기한이 지난 미승인 필수서류        |
| 구독 위험     | 90일 내 만료, 만료, 사용중이지만 만료일 미입력 중 하나 이상 |
| 정산 위험     | 보완 중 또는 입금 완료·정산 마감이 아니면서 기한초과        |

서류 위험은 카드 ‘막힘’ 배지에는 더해지지만 ‘막힘 있음’ 필터 조건에는 직접 포함하지 않습니다. 필터는 카드의 표시 여부를 결정하며 카드 내부 집계 범위를 추가로 좁히지 않습니다.

정렬은 위험 총수 내림차순, 같으면 프로젝트 수정 시각 내림차순입니다. 위험 총수는 프로젝트 막힘·대기 업무·서류 위험·90일 내 만료·만료·사용중 만료일 미입력의 수와 정산 위험 1점을 더합니다. 같은 농가가 서로 다른 위험 항목에 해당하면 항목별로 더해집니다.

## 버튼

‘프로젝트 추가’는 사업명, 사업 유형, 연도, 기관, 목표 농가 수, 상태, 담당자, 현재 단계, 기간, 설명을 입력하는 창을 엽니다. 기존 사업과 정산 정보는 상세의 ‘사업·정산 수정’에서 편집합니다. 저장 입력창은 [등록·수정 폼 안내](../forms/README.md)를 참조합니다.

## 집계 해석

프로젝트 안에서 같은 농가의 참여 레코드가 여러 개면 마지막 활동이 최신인 한 개로 농가·완료일·구독 비율을 계산합니다. 반면 업무·히스토리는 그 프로젝트의 모든 참여 레코드에 연결된 데이터를 수집합니다.

증빙기반 진행률은 농가 확보율·제작율·설치율·시운전율·교육률·필수서류 승인율·정산 상태 진행값의 7개 평균입니다. 누락 비율은 0으로 포함합니다. 사업 집계의 ‘구축·운영 평균’ 및 구독 실적의 ‘갱신률’과는 다른 지표입니다.

## 빈 상태

프로젝트가 전혀 없으면 ‘아직 등록된 프로젝트가 없습니다.’와 등록 안내를 표시합니다. 프로젝트는 있지만 필터 결과가 없으면 ‘선택한 연도·사업 타입·검색·위험에 맞는 프로젝트가 없습니다.’와 검색·필터 변경 안내를 표시합니다. 상단 프로젝트 추가 버튼은 유지됩니다.
