# 프로젝트 관리 개선 · 2026-09-09

## 프로젝트 중심 재배치 · 2026-09-11

사용자 승인에 따라 프로젝트 첫 화면을 통합 조회 조건 → 프로젝트 요약 4개 → 간결한 목록으로 재배치했다. 상단 공통 업무 KPI와 표/카드 전환, 목록의 설치·교육·구독·서류·정산 반복 지표는 제거하고 상세에서 유지한다. 현재 네 요약은 모두 `filteredProjects`와 같은 연도·타입·검색·확인 항목을 적용한다. 각 요약 클릭은 해당 범위 안에서 전체/진행/완료/확인 필요 프로젝트를 표시하며 업무 화면으로 이동하지 않는다.

상세 진행 요약은 프로젝트 진행률·참여 농가·확인 필요 → 확인 항목 → 농가 진행상황 → 접힌 사업 진행률 산정 근거 순이다. 설치·시운전·교육 KPI와 농가별 아래 펼침은 기존 계산 그대로 한 번만 표시한다. 이전 설치·운영 완료율 중복 카드는 제거했다. 구독·정산 위험은 확인 항목에서 해당 탭으로 이동할 수 있다. 기존 상세 탭, 삭제·복구, 등록·편집 동작과 데이터는 그대로 유지한다. 이 절 이후의 9월 9일 배치 설명은 당시 이력이다.

## 프로젝트 삭제·복구

프로젝트 상세 상단의 ‘프로젝트 삭제’를 누르면 확인 팝업이 열린다. 프로젝트명을 그대로 입력한 뒤 삭제를 확정한다. 프로젝트 관리의 ‘삭제한 프로젝트’를 펼치면 복구할 수 있다.

- 삭제는 복구 가능한 표시(`deletedAt`)이며 프로젝트 목록·연도 KPI·사업 현황·신규 프로젝트 선택에서 제외한다.
- 농가, 참여 기록, 구독, 입금, 업무, 제출서류, 사진과 기존 이력은 삭제하지 않는다. 농가 관리대장과 구독·입금의 원본 기록·사업 참조는 보존한다.
- 보존된 농가의 입금과 기존 업무의 방문·체크리스트 처리는 계속 가능하다. 삭제된 사업에 신규 농가·사업 참여·프로젝트 전용 업무·서류를 추가하려면 먼저 복구해야 한다. 기존 사업 완료 상태의 잠금 정책은 별도로 유지한다.
- 삭제·복구는 최신 프로젝트 버전을 확인하는 트랜잭션과 시스템 이력을 함께 저장한다. 다른 변경이 먼저 저장되면 프로젝트를 다시 확인해야 한다. 중복 요청은 중복 이력을 만들지 않는다.
- 저장 중에는 닫기·중복 실행을 막고 실패하면 확인 입력과 오류를 유지한다. 프로젝트 상세에서 삭제가 끝나면 기존 목록으로 돌아간다.
- 권한은 기존과 같은 활성 회원 기준이다. 별도의 관리자 역할을 추가하지 않는다. 영구 삭제 금지 및 입금·처리 이력 불변 정책은 유지한다.
- 보안 규칙은 삭제 표시 변경과 감사 이력을 함께 확인하므로 오래된 화면에서 전체 문서를 저장해도 삭제 표시를 지울 수 없다.

프로젝트 등록·수정 팝업은 PC에서 최대 1,100px, 화면 높이의 92% 안에서 표시한다. 좁은 화면에서는 화면 너비를 넘지 않으며 내부 스크롤을 사용한다. 기존 공통 팝업의 문자열 스타일이 누락되던 원인도 수정하여 지정한 너비와 높이가 실제로 적용된다.

## 농가 진행상황과 세부 보기

2026-09-09 추가: 프로젝트 목록 표는 설치·시운전·교육 비율만 먼저 보여준다. 각 행의 ‘상세 보기’를 누르면 비율 아래에 완료·미완료 개소가 펼쳐지고 ‘상세 접기’로 숨긴다. 상세 화면의 농가 진행상황과 농가별 표는 기존대로 유지한다.

진행 요약 맨 위에 참여 농가 수와 설치·시운전·교육별 완료율, 완료 개소, 미완료 개소를 표시한다. 프로젝트 관리 표의 비율 아래에도 같은 완료·미완료 개소를 표시한다. 카드 보기 역시 완료 수와 남은 수를 함께 표시한다.

- 집계 단위는 프로젝트 안의 농가별 최신 활동 참여 기록 한 건이다. 서로 다른 사업의 같은 농가는 각각 집계한다.
- 완료율 = 해당 완료일이 입력된 농가 / 참여 농가 × 100, 정수 반올림. 미완료 = 참여 농가 − 완료 농가.
- 목표 농가 수를 분모로 사용하지 않는다. 참여 농가가 없으면 비율은 `-`, 완료·미완료는 0개소다.
- 기존 기준을 유지하므로 날짜 입력 유무로 계산하며 미래 날짜나 제외 대상을 새로 추정하지 않는다.
- ‘세부 보기’를 누르면 카드 바로 아래에 농가명·작목·설치·시운전·교육 표가 펼쳐진다. 완료일이 없으면 미완료로 표시한다. ‘세부 접기’로 다시 접으며 다른 탭으로 이동하지 않는다.

## 통합 현황 연도 선택

2026-09-09 추가: 통합 현황과 프로젝트 관리의 공통 기준 연도는 로그인 후 처음 열 때 접속 기기의 현재 연도로 시작한다. 사용자가 고른 연도는 화면 이동 시 유지하며 ‘전체 연도’도 선택할 수 있다. 현재 연도에 사업이 없어도 전체 연도로 자동 변경하지 않는다.

통합 현황의 여러 연도 버튼을 ‘기준 연도’ 드롭다운으로 교체했다. 선택한 연도·사업 타입의 KPI, 프로젝트, 최근 이력과 확인 필요 항목만 표시한다. ‘전체 연도’는 기존대로 지원한다. 프로젝트 관리의 연도 선택 상태와 공유하며, 검색·위험 조건은 목록만 추가로 좁힌다.

검증: `scripts/test-project-management.mjs`, `scripts/test-project-image-rules.mjs` 및 기존 업무·구독·탐색 회귀 테스트. 규칙 검증은 가상 요청이며 운영 데이터에 테스트 기록을 만들거나 실제 프로젝트를 삭제하지 않는다.
