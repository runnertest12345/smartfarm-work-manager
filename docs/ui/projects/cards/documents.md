# 제출서류 대장

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트의 필수·선택 서류와 책임자·현재 처리자를 관리합니다.

## 표시값·계산식

프로젝트에 연결된 모든 서류를 반복 카드로 표시합니다. 제목, 필수 배지, 분류, 책임자, 현재 처리자, 상태, 기한, 개정 차수입니다. 각 서류마다 별도 문서를 만들지 않고 이 문서가 반복 구조를 설명합니다. 집계값과 개별 서류의 상태·제출일은 [필수 제출서류 KPI](required-documents-kpi.md)를 참조합니다.

## 클릭·버튼

‘추가’와 상세 상단 ‘제출서류 추가’는 새 서류 입력창, 개별 대장 항목은 편집창을 엽니다. 프로젝트 상태가 완료이면 이 추가 버튼들과 대장 항목 버튼은 비활성화됩니다.

입력창은 제목·분류·필수 여부·상태·개정 차수·책임자·현재 처리자·기한·제출일·승인일·원본/참조 링크·메모를 받습니다. 이 대장은 저장한 메타데이터와 링크를 관리하며 여기서 파일 업로드 기능이 구현되어 있다고 해석하지 않습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
