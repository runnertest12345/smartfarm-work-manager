# 협약·계약 단계

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

협약·계약 필수서류의 승인 진행을 확인합니다.

## 표시값·계산식

`category === agreement`이며 `isRequired`인 서류 중 승인 상태 비율을 정수 반올림합니다. 대상 필수서류가 없으면 ‘미설정’입니다. 보조문구는 ‘협약·계약 서류 승인 기준’입니다. 전체 서류 승인율과 달리 협약·계약 분류로 제한합니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
