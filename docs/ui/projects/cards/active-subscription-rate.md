# 유효 구독률·유효 구독 카드

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

오늘 유효한 구독의 비율과 곧 만료될 수를 확인합니다.

## 표시값·계산식

상세 상단의 ‘유효 구독률’, 설치·운영 완료율의 ‘유효 구독’, 목록의 ‘유효 구독’은 같은 비율을 사용합니다. 저장 상태가 `active`이고 현재 만료일이 오늘 이상인 참여 레코드 수/참여 농가 수를 정수 반올림합니다. 참여가 없으면 `-`입니다. 만료일 없는 사용중은 제외합니다.

상단에는 유효 구독 중 0~90일 남은 수와 만료 수를 표시합니다. 만료 수는 저장 상태가 `expired`이거나 현재 만료일이 오늘보다 과거인 수입니다. 설치·운영 카드에는 완료/참여 수, 90일 내 만료 수, 비율 막대를 표시합니다. 구독 실적의 갱신률과는 별개입니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
