# 사업 진행 단계 영역

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

협약부터 마감까지 단계별 근거와 진척을 비교합니다.

## 표시값·계산식

7개의 단계 카드를 표시합니다. 단계별 비율은 각각 다른 근거로 계산하며 ‘현재 단계’ 상태를 바꾸는 버튼이 아닙니다. 비율이 null이면 ‘미설정’과 길이 0인 막대를 표시합니다.

상단 ‘최근 활동’은 프로젝트 수정일, 연결 업무 최근활동, 업무 히스토리 발생일, 프로젝트 기록 발생일, 서류 수정일의 최댓값입니다. 현재 선택 단계만 표시하는 것이 아니라 항상 7개를 함께 보여줍니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
