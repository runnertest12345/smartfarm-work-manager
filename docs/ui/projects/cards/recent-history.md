# 프로젝트 최근 히스토리

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트 연락·결정·막힘과 해당 프로젝트의 농가 업무 기록을 함께 확인합니다.

## 표시값·계산식

프로젝트의 `projectUpdates`와 연결 업무의 `historyEntries`를 합쳐 `occurredAt` 내림차순으로 정렬합니다. 파생 배열은 12건을 보관하지만 실제 이 영역 목록은 상위 8건만 표시합니다.

항목에는 프로젝트 기록 제목 또는 농가·업무명, 프로젝트 기록 유형 배지, 해결된 프로젝트 막힘의 ‘해결 완료’ 배지, 내용 요약, 발생 시각을 표시합니다. 요약은 해결 내용→처리 내용→수신 내용→막힘 사유/빈 기록 안내 순으로 표시합니다. 별도 ‘마지막 받은 내용’과 ‘마지막 처리 내용’은 전체 기록에서 각각 찾으므로 서로 다른 기록일 수 있습니다.

## 클릭·버튼

‘막힘 추가’는 막힘 종류가 선택된 프로젝트 기록 창, ‘기록 추가’는 일반 프로젝트 기록 창을 엽니다. 완료 프로젝트에서 ‘막힘 추가’는 비활성화되지만 ‘기록 추가’ 버튼은 표시·활성화됩니다. 목록 항목 자체에는 상세 이동 클릭이 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
