# 정산·서류 단계

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

필수서류 승인과 정산 상태 진행값을 함께 확인합니다.

## 표시값·계산식

필수서류 승인율과 정산 상태 진행값 중 null이 아닌 값의 평균을 정수 반올림합니다. 정산 상태 값은 미착수 0, 수집 20, 제출 50, 보완 40, 승인 75, 입금 완료·마감 100입니다.

필수서류가 없으면 승인율은 null로 제외되므로 정산 상태 값만 표시합니다. 증빙기반 전체 진행률에서 누락 비율을 0으로 포함하는 방식과 다릅니다. 보조문구는 필수 승인/전체와 정산 상태입니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
