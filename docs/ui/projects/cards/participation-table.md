# 참여 농가·구독 표

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트 참여 농가의 설치 단계와 구독 만료일을 확인합니다.

## 표시값·계산식

열은 농가(작물·제품 보조값), 설치 단계, 구독 상태, 만료일, 남은 기간입니다. 설치 단계는 제작·설치·시운전·교육 4개 날짜 중 입력된 수/4 완료입니다. 만료일이 과거이면 상태를 ‘만료’로 덮어쓰고 그 외에는 저장 상태를 표시합니다. 날짜가 없으면 남은 기간은 `-`, 과거는 N일 지남, 현재·미래는 D-N입니다.

이 표는 관리 탭의 `effectiveRecordSubscriptionStatus`와 달리 만료일 없는 저장 상태 사용중을 사용중으로 표시할 수 있습니다. 그러나 유효 구독률에서는 만료일 미입력 사용중을 제외합니다. 해당 건수는 표 위 ‘만료일 미입력’ 배지로 따로 표시합니다. 참여 농가·날짜·구독 지표는 프로젝트 안에서 같은 `farmId`가 중복되면 `lastActivityAt`이 가장 큰 레코드 1개를 사용합니다. 업무와 히스토리는 중복 제거 전 모든 해당 프로젝트 레코드와 연결해 수집합니다.

## 클릭·버튼

농가명은 농가 상세를 엽니다. 이 표 안에는 만료일 정정·구독 처리 버튼이 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
