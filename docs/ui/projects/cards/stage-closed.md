# 사업 마감 단계

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트의 완료 상태를 단계의 마지막 지표로 확인합니다.

## 표시값·계산식

`project.status === completed`이면 100%, 그 외에는 0%입니다. 완료이면 ‘사업 완료 처리됨’, 아니면 ‘필수서류·정산·막힘 확인 필요’를 표시합니다. 이 카드 계산 자체가 서류·정산·막힘을 다시 평가해 완료 상태를 변경하지는 않습니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
