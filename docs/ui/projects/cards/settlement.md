# 최종 정산

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트별 최종정산 1건의 금액·담당·기한·증빙을 관리합니다.

## 표시값·계산식

정산 상태 배지, 계약금액·청구액·승인액·입금액의 네 금액 카드, 담당자, 정산기한, 입금·마감일, 증빙 링크, 메모를 표시합니다. 모두 프로젝트의 저장 필드이며 여러 정산 건을 합친 값이 아닙니다.

금액 간 차액, 미수금, 계약 대비 비율은 이 영역에서 별도로 계산·표시하지 않습니다. 구독·입금 화면의 업무 히스토리 합계와 자동으로 같은 값이라고 해석하지 않습니다.

## 클릭·버튼

‘정산 정보 수정’ 또는 상세 상단 ‘사업·정산 수정’은 프로젝트·정산 편집창을 엽니다. 증빙 URL이 있을 때 ‘정산 증빙 열기’가 새 탭으로 해당 URL을 엽니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.

## 데이터·소스 근거

[계산 및 상세 화면](../../../../app/farm-ledger-dashboard.tsx) — `projectSnapshot`(1354~~1524행), 프로젝트 상세(8456~~9244행). [데이터 형식](../../../../lib/farm-types.ts) — `FarmProject`, `FarmRecord`, `FarmProjectDocument`, `FarmProjectUpdate`, `FarmWorkItem`.

## 빈 필드

담당자는 ‘미지정’, 기한·입금·마감일은 ‘미입력’, 메모는 ‘정산 메모가 없습니다.’입니다. 증빙 URL이 없으면 링크를 숨깁니다.
