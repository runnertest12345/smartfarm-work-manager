# 회차별 정산

수정일: 2026-09-15

## 받는 대금 기준의 수금 표시

이 정산은 고객·기관에 청구하고 **우리 회사가 입금받는 프로젝트 대금**입니다. 비용 지급이나 송금 기능이 아닙니다. 정산 탭에서는 전체 계약금액·받은 입금액·계약 기준 남은 금액을 먼저 표시하고, 청구 누계·승인 누계·승인 후 미입금은 보조 정보로 표시합니다. 회차 입력의 ‘받은 입금액’은 해당 회차에서 실제 받은 누적 금액입니다.

- 계약 기준 남은 금액 = 계약금액 − 받은 입금액(최소 0). 아직 청구하지 않은 금액을 포함하므로 연체 금액이나 확정 미수금으로 단정하지 않습니다.
- 승인 후 미입금 = 각 회차의 max(승인액 − 받은 입금액, 0) 합계. 한 회차의 초과 입금이 다른 회차의 미입금을 상쇄하지 않습니다.
- 계약금액 0은 미입력과 실제 0원 계약을 구분할 수 없으므로 남은 금액 대신 ‘계약금액 확인 필요’를 표시합니다. 계약금액보다 입금액이 많으면 초과 금액을 별도로 안내합니다.
- 회차가 있으면 회차·미지정 내역을 한 번씩 합산하고 오래된 저장 요약액을 표시 기준으로 쓰지 않습니다. 조회만으로 원본 금액·상태를 수정하지 않습니다.
- 예: 계약 1,000만 원, 승인 및 입금 726만 원이면 계약 기준 남은 금액은 274만 원이고 승인 후 미입금은 0원입니다. 1차 정산이 마감되어도 전체 계약대금을 모두 받았다는 뜻은 아닙니다.
- 기존 정산 기한과 입금·마감일은 각각의 원래 의미를 유지합니다. 이번 표시 개선에서 입금 예정일이나 실제 입금일로 재해석하지 않습니다. 저장·완료 판정 규칙과 농가 구독료 입금은 변경하지 않습니다.

## 조회와 수정

프로젝트 상세의 **정산 탭**에서 조회하고 ‘정산 수정’을 누르면 같은 위치에 정산 필드만 표시합니다. 조회 내역과 편집 필드를 중복 표시하거나 기본정보 전체 수정 팝업을 다시 열지 않습니다. 저장·변경 취소 후 조회로 돌아갑니다. 미저장 변경·저장 중에는 탭·상세·메뉴 이탈을 막고, 다른 사람이 먼저 저장한 경우 초안을 보존하며 최신 내용 확인을 안내합니다.

프로젝트별 정산의 상태, 담당자, 기한, 청구액, 승인액, 입금액, 입금·마감일, 증빙 링크, 메모를 차수별로 관리합니다. 신규 정산은 1차부터 시작하며 ‘차수 추가’로 최대 3차까지 늘릴 수 있습니다. 입력창에서 각 회차를 펼치고 접을 수 있습니다. 저장 검증 한도에 맞춰 최대 차수를 명시합니다.

기존 차수는 자동으로 삭제하지 않습니다. ‘비어 있는 마지막 차수 삭제’를 직접 선택할 때만 완전히 빈 마지막 차수를 제거합니다. 금액뿐 아니라 담당자·기한·증빙·메모가 입력된 차수도 삭제할 수 없으며 1차는 항상 유지합니다.

## 합산과 완료 기준

- 계약금액은 프로젝트 전체 금액으로 한 번만 입력합니다.
- 총 청구·승인·입금액은 각 회차와 회차 미지정 내역의 해당 금액 합계입니다. 미지정 내역을 특정 회차로 옮길 때에는 원래 위치에서 제외하므로 중복 합산하지 않습니다.
- 등록한 차수만 완료 판단에 포함합니다. 1차만 등록했다면 1차 완료로 전체 정산이 완료됩니다. 2차·3차 등을 추가했다면 미지정 원본을 포함한 모든 정산 내역이 입금 완료 또는 정산 마감이어야 합니다.
- 정산 기한 요약은 미완료 내역 중 가장 이른 입력 기한입니다. 전체 마감일은 모든 내역이 완료되고 마감일이 모두 입력됐을 때 가장 늦은 날짜입니다. 미입력 날짜를 만들지 않습니다.
- 프로젝트 정산은 농가 구독료 입금과 별개입니다. 구독 만료일이나 농가 입금 이력을 변경하지 않습니다.

## 기존 내역 보존

기존 단일 정산은 ‘회차 미지정 (기존 정산)’으로 표시하며 조회만으로 데이터를 전환하지 않습니다. 기존 완료 프로젝트도 완료 상태를 유지합니다.

편집창의 ‘기존 내역 보존하고 회차별 관리 시작’으로 전환합니다. 미지정 원본은 직접 변경하지 못하며, 입력이 없는 회차로 명시적으로 지정할 수 있습니다. 지정한 원본을 수정하려면 우선 지정 결과를 저장하고 다시 엽니다. 완료 프로젝트의 정산 근거를 바꾸려면 먼저 진행 중으로 변경해 저장합니다.

회차 변경과 감사 이력을 함께 저장하며 오래된 편집창의 덮어쓰기를 거절합니다. 구버전 화면이 회차 데이터를 삭제하는 저장도 차단합니다.
