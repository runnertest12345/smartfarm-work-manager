# 마지막 처리 내용

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트 전체에서 가장 최근의 비어 있지 않은 처리 내용을 확인합니다.

## 표시값·계산식

프로젝트 기록과 해당 프로젝트 농가 업무 히스토리를 합쳐 발생 시각 내림차순으로 정렬하고 `actionContent.trim()`이 비어 있지 않은 첫 항목을 선택합니다. 화면에는 `localizedProjectActionContent`로 가공한 처리 내용을 표시하며 없으면 ‘처리 내용이 없습니다.’입니다.

마지막 수신 카드와 동일한 기록을 강제로 사용하지 않습니다. 프로젝트 기록의 해결 내용은 최근 목록의 별도 요약 우선순위와 다를 수 있습니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
