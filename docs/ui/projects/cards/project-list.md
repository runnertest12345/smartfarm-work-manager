# 프로젝트 통합 현황 목록 카드

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트를 비교하고 농가·업무·서류·정산을 묶은 전체 상세를 엽니다.

## 표시값·계산식

상단에는 연도·유형·상태, 사업명·기관, 설명을 표시합니다. 설명이 없으면 ‘사업 설명이 없습니다.’입니다. 농가 수, 목표 농가 수(0이면 `-`), 미완료 업무 수, 증빙 진행률과 진행 막대를 표시합니다. 아래에는 설치·시운전·교육·유효 구독 비율 및 완료/참여 수를 표시합니다.

배지는 막힘(프로젝트 미해결 막힘 + 대기 업무 + 서류 위험), 구독(유효/참여), 서류(필수서류 제출일 입력 수/필수서류 수), 정산 상태입니다. 마지막 줄은 저장된 현재 단계입니다. 증빙 진행률 계산은 [증빙기반 진행률](evidence-progress.md)을 따릅니다.

참여 농가·날짜·구독 지표는 프로젝트 안에서 같은 `farmId`가 중복되면 `lastActivityAt`이 가장 큰 레코드 1개를 사용합니다. 업무와 히스토리는 중복 제거 전 모든 해당 프로젝트 레코드와 연결해 수집합니다.

## 클릭·버튼

카드 전체 및 ‘통합 현황 보기 →’를 누르면 해당 프로젝트 전체 상세를 엽니다. 카드 내부 KPI와 배지는 각각 별도 필터 버튼이 아닙니다.

## 필터 적용 범위

목록의 프로젝트명·기관·담당자·연도 검색, 사업연도, 위험 필터를 적용합니다. 통과한 프로젝트의 내부 값은 프로젝트 전체 데이터로 계산합니다. 위험 항목 총수 내림차순 후 프로젝트 `updatedAt` 내림차순으로 정렬합니다.
