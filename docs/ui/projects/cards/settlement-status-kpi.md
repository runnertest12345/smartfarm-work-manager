2026-09-10 변경: 회차별 금액·상태를 표시하고 총액은 1차 + 2차 + 회차 미지정 내역을 한 번씩 합산합니다. 전체 계약금액은 합산하지 않는 공통 금액입니다. 기존 미전환 프로젝트는 원래 값과 완료 상태를 유지합니다. [회차별 정산 기준](settlement.md)이 아래 초기 버전 설명보다 우선합니다.

## 목적

회차별 정산의 현재 상태와 기한을 확인합니다.

## 표시값·계산식

`project.settlementStatus`의 한글 상태를 표시합니다. 상태는 미착수·자료 수집·정산 제출·보완 중·승인·입금 완료·정산 마감입니다. 기한이 있으면 날짜와 남은 기간 표현을 표시하고, 입금 완료 또는 정산 마감이면 기한 표현을 완료로 취급합니다. 기한이 없으면 ‘정산기한 미입력’입니다.

금액으로 자동 추론한 상태가 아니라 저장된 정산 상태입니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
