# 현재 막힌 곳

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트 직접 막힘, 농가 대기 업무, 위험 서류의 원인과 다음 조치 지점을 확인합니다.

## 표시값·계산식

프로젝트 미해결 막힘, 상태가 대기인 농가 업무, 위험 서류를 순서대로 보여줍니다. 직접 막힘에는 제목·사유·해결 주체·경과일·예상 해제일, 농가 업무에는 농가·업무명과 같은 막힘 정보, 서류에는 제목·상태·현재 처리자·기한 표현이 있습니다.

위험 서류는 보완 요청 또는 반려(필수 여부 무관), 혹은 필수이며 승인되지 않았고 기한이 오늘보다 이전인 서류입니다. 경과일은 현재 시각에서 발생/막힘 시각을 뺀 일수의 버림값이며 0 미만은 0입니다.

## 클릭·버튼

프로젝트 막힘의 ‘해결 처리’는 해결 내용·해결 담당자 입력창을 엽니다. 농가 업무 항목을 누르면 해당 농가의 해당 업무 상세를 엽니다. 위험 서류 항목은 해당 서류 편집창을 엽니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
