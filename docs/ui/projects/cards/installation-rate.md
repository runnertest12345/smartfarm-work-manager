# 설치 완료율

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

프로젝트 참여 농가 중 설치 완료일이 입력된 비중을 확인합니다.

## 표시값·계산식

해당 참여 레코드의 `installationDate`가 비어 있지 않은 건수/전체 참여 수를 정수 반올림합니다. 카드에는 비율, 완료/참여 수, 날짜 입력 기준이라는 설명, 비율 막대가 표시됩니다. 분모가 0이면 `-`이며 막대는 0입니다.

입력 날짜가 오늘 이전인지 검사하지 않으므로 미래 날짜도 완료로 계산합니다. 참여 농가·날짜·구독 지표는 프로젝트 안에서 같은 `farmId`가 중복되면 `lastActivityAt`이 가장 큰 레코드 1개를 사용합니다. 업무와 히스토리는 중복 제거 전 모든 해당 프로젝트 레코드와 연결해 수집합니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
