# 참여 농가 KPI

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

등록된 참여 농가 수와 목표 대비 확보 정도를 확인합니다.

## 표시값·계산식

주값은 `snapshot.records.length / project.targetFarmCount`곳이며 목표 0이면 `-`를 표시합니다. 목표가 있으면 `min(100, round(참여 / 목표 × 100))`을 보조문구로 표시합니다. 목표가 없으면 ‘목표 농가 수를 입력해 주세요’입니다.

참여가 목표를 넘으면 주값은 초과 수를 그대로 보이지만 확보율은 100%로 제한합니다. 참여 농가·날짜·구독 지표는 프로젝트 안에서 같은 `farmId`가 중복되면 `lastActivityAt`이 가장 큰 레코드 1개를 사용합니다. 업무와 히스토리는 중복 제거 전 모든 해당 프로젝트 레코드와 연결해 수집합니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
