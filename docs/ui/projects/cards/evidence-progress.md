# 증빙기반 진행률

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

저장된 농가·완료 날짜·필수서류·정산 상태의 종합 진행값을 확인합니다.

## 표시값·계산식

`Math.round((농가 확보율 + 제작율 + 설치율 + 시운전율 + 교육률 + 필수서류 승인율 + 정산 상태 진행값) / 7)`입니다. 각 비율이 null이면 **0으로 포함**합니다.

농가 확보율은 목표 대비 참여 농가 수를 정수 반올림하고 최대 100%로 제한합니다. 네 날짜 비율은 해당 날짜 입력 건수/참여 농가 수입니다. 서류 승인율은 승인 상태 필수서류 수/전체 필수서류 수입니다. 정산 상태 진행값은 미착수 0, 자료 수집 20, 제출 50, 보완 40, 승인 75, 입금 완료 100, 마감 100입니다.

유효 구독률과 현재 단계는 이 평균에 들어가지 않습니다. 모든 단계가 미설정이고 정산이 미착수면 0%입니다. 목표·필수서류 누락을 평균에서 제외하지 않으므로 진행률이 낮아질 수 있습니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
