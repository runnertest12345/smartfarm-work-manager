# 필수 제출서류 KPI

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

필수서류 제출과 승인·위험 건수를 확인합니다.

## 표시값·계산식

주값은 제출일 `submittedAt`가 입력된 필수서류 수/전체 `isRequired` 서류 수입니다. ‘승인’은 필수서류 중 `status === approved`인 수, ‘위험’은 전체 서류 중 보완 요청·반려 또는 기한이 지난 미승인 필수서류 수입니다.

제출 건수는 상태가 아니라 제출일 입력 여부입니다. 제출일 없는 승인 서류는 승인 수에는 포함되지만 제출 수에는 포함되지 않습니다. 위험 수에는 선택 서류의 보완·반려도 포함될 수 있습니다. 서류가 없으면 0/0건입니다.

## 클릭·버튼

조회 전용이며 카드 자체의 클릭 동작은 없습니다.

## 필터 적용 범위

선택한 프로젝트 전체가 대상입니다. 목록의 검색·연도·위험 필터는 어떤 프로젝트를 여는지에만 영향을 주고 상세 내부 데이터를 추가로 줄이지 않습니다. 다른 화면의 필터도 적용하지 않습니다.
