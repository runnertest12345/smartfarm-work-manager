# 로그인·접근 승인 화면

기준: 2026-09-07 · 소스 커밋 `141faaa`

## 목적과 진입

사이트를 열면 먼저 Firebase 연결 설정, 로그인 상태와 사용자 승인을 확인한다. 승인된 사용자만 관리대장을 볼 수 있다.

| 화면 상태           | 표시 내용                                | 카드 문서                                    |
| ------------------- | ---------------------------------------- | -------------------------------------------- |
| 로그아웃 상태       | 공용 비밀번호 입력, 관리자 Google 로그인 | [관리대장 접속 카드](cards/sign-in.md)       |
| 로그인·권한 확인 중 | 접근 권한 확인 안내                      | [권한·연결 상태 카드](cards/access-state.md) |
| 로그인했으나 미승인 | 승인 안내, UID 복사, 다른 계정 로그인    | [권한·연결 상태 카드](cards/access-state.md) |
| Firebase 설정 누락  | 필요한 설정값 이름 안내                  | [권한·연결 상태 카드](cards/access-state.md) |
| 승인 완료           | 통합 현황 진입                           | [공통 화면 이동](../common/navigation.md)    |

## 사용 흐름

공용 비밀번호로 접속하거나 관리자 Google 로그인을 실행한다. Google 로그인은 계정을 고르는 팝업을 사용한다. 로그인 성공만으로 접근이 확정되지는 않으며 승인 문서의 활성 상태를 확인한다. 공용 계정 접속은 동일 로그인 사용자로 감사 정보를 남기므로 각 업무의 기록자 입력도 함께 사용한다.

로그인은 브라우저 세션에 유지된다. 공용 비밀번호의 실제 값은 이 문서에 포함하지 않는다.
