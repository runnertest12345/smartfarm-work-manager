# 권한·연결 상태 카드

- **위치:** [로그인 화면](../README.md).
- **목적:** 접속 준비·승인 상태를 안내하고 다음 동작을 제공한다.

| 상태                 | 표시와 동작                                                                |
| -------------------- | -------------------------------------------------------------------------- |
| 연결 설정 없음       | ‘Firebase 연결이 필요합니다’와 누락된 설정 이름을 보여준다                 |
| 확인 중              | 회전 표시와 ‘접근 권한을 확인하고 있습니다.’를 보여준다                    |
| 승인되지 않음        | ‘관리자 승인이 필요합니다’, 현재 UID, 복사 버튼을 보여준다                 |
| UID 복사             | 현재 로그인 사용자의 UID를 클립보드로 복사하고 잠시 완료 아이콘을 표시한다 |
| 다른 계정으로 로그인 | 로그아웃하여 접속 화면으로 돌아간다                                        |

승인 기준은 `appMembers/{uid}` 문서의 `active === true`이다. 승인 문서를 실시간으로 확인하므로 활성 상태 변경이 화면에 반영된다. 이 화면에서 사용자가 스스로 승인 문서를 만드는 버튼은 없다.

**데이터 원천:** Firebase 설정 여부, 인증 사용자, 사용자 승인 문서. 숫자 집계나 검색 필터 없음.

**코드 근거:** [firebase-auth-gate.tsx](../../../../app/firebase-auth-gate.tsx)의 `onAuthStateChanged`, `onSnapshot`, `copyUid` 및 접근 상태 분기.
