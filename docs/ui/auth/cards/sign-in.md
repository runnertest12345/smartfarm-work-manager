# 관리대장 접속 카드

- **위치:** [로그인 화면](../README.md), 로그아웃 상태.
- **목적:** 승인된 계정으로 관리대장에 접속한다.

| 입력·버튼            | 동작                                                       |
| -------------------- | ---------------------------------------------------------- |
| 공용 비밀번호        | 비밀번호 형식 입력. 필수이며 화면에 원문을 노출하지 않는다 |
| 비밀번호로 접속      | 공용 계정의 Firebase 비밀번호 인증을 실행한다              |
| 관리자 Google 로그인 | Google 계정 선택 팝업을 열어 인증한다                      |

입력값이 없으면 비밀번호 접속 버튼이 비활성화된다. 로그인 처리 중 두 접속 버튼을 잠그고 ‘접속 중...’ 또는 ‘로그인 중...’을 표시한다. 실패 시 잘못된 비밀번호, 과도한 시도, 네트워크 오류 등의 안내를 표시한다. 인증 후에는 별도의 사용자 승인 검사를 거친다.

**데이터 원천:** Firebase Authentication. 프로젝트·농가 데이터 필터와 무관하다.

**코드 근거:** [firebase-auth-gate.tsx](../../../../app/firebase-auth-gate.tsx)의 `accessState === 'signed_out'` 분기.
