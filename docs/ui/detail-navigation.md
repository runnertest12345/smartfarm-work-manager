# 상세 화면 이동과 뒤로가기

갱신일: 2026-09-09.

통합 현황에서 프로젝트를 열면 브라우저 뒤로가기와 화면의 ‘통합 현황으로’ 버튼 모두 출발한 통합 현황으로 돌아간다. 프로젝트 관리·업무 현황·농가 관리대장에서 들어갔다면 각각 해당 목록으로 복귀한다.

프로젝트 → 농가 → 업무처럼 여러 상세를 연 경우 ‘이전 상세로’와 브라우저 뒤로가기는 한 단계씩 복귀한다. 브라우저 앞으로가기로 다시 상세를 열 수 있다. 같은 상세를 다시 선택해도 중복 이동 기록을 만들지 않는다.

- 같은 방문 중 목록의 검색·필터·프로젝트 펼침 상태를 유지한다. 상세 탭과 스크롤 위치도 복원한다.
- 새로고침할 때 현재 상세·탭·이동 경로·스크롤을 복원한다. 목록 검색·필터는 새로고침 후 기본값이다.
- 열린 입력창은 먼저 저장하거나 닫도록 안내한다. 앱 내부의 뒤로가기·앞으로가기로 작성 중인 내용을 잃지 않게 한다. 외부 페이지로 나가기·탭 닫기까지 막는 기능은 아니다.
- 다른 메뉴를 직접 선택하면 그 메뉴가 다음 상세 이동의 출발점이 된다.
- 상세 화면을 열기 전의 앱 시작 위치에서는 브라우저 뒤로가기를 막지 않는다.
- 빠른 연속 뒤로가기 중 이전 렌더가 새 이동 기록을 덮어쓰지 않도록 화면 반영을 확인한 후 저장한다.

이동 기록은 현재 브라우저의 방문 기록에만 저장한다. URL의 배포 식별자와 Next.js의 기존 기록을 유지하며, DOM 요소·입력 초안·업무 데이터는 저장하지 않는다. 실제 업무·입금·구독 데이터와 보드 구성은 변경하지 않는다.

코드: `lib/detail-navigation.ts`, `app/use-detail-navigation.ts`, `app/farm-ledger-dashboard.tsx`.

검증: `scripts/test-detail-navigation.mjs`의 가상 방문 기록 및 훅 이벤트 테스트. 뒤로/앞으로 이동, 다단계 상세, 입력창 보호, 새로고침, 지연 렌더·연속 이동을 확인한다. 실제 운영 데이터에 테스트 기록을 생성하지 않는다.
