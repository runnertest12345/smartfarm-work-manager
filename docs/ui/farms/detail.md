# 농가 전체 상세

작성일: 2026-09-07 · 구현 기준: `141faaa` · [농가 관리대장](README.md)

[전체 목차](../README.md) · [입력창 목차](../forms/README.md)

## 목적과 진입

한 농가의 기본정보, 모든 참여 사업과 설치 정보, 업무, 전체 이력을 모아 확인한다. 농가 관리대장 이름 버튼이나 다른 화면의 농가 상세 링크에서 `openFarm(farmId)`로 연다. 화면 조건은 `selectedFarm`이 있고 `selectedWorkItem`이 없는 상태다. 별도 URL 이동 없이 선택 상태로 내용을 전환한다.

## 구성과 범위

- [상세 정보](cards/farm-information.md): 농장번호·지역·참여 사업 수·진행 업무 수·농가명·연락처·주소와 특이사항.
- [참여 사업·설치 정보](cards/participation.md): 모든 참여 기록을 최근 활동순으로 표시.
- [농가 업무](cards/farm-work.md): 완료 업무를 포함한 농가의 전체 업무.
- [농가 전체 히스토리](cards/farm-history.md): 농가 업무에 연결된 모든 이력.

2026-09-07 개편: 업무 / 사업·설치·구독 / 처리 이력 탭으로 구분한다. 프로젝트에서 진입한 경우 ‘현재 보는 사업’이 해당 프로젝트로 설정되며 참여 기록·업무·이력이 함께 제한된다. ‘전체 참여 사업’ 또는 다른 참여 사업으로 전환할 수 있다. 농가 관리대장에서 직접 진입하면 기본은 전체 참여 사업이다. 중복 사업 검사는 항상 전체 참여 기록을 사용한다. 목록의 구독·작목·지역·검색 조건은 상세 내용을 제한하지 않는다. [개편 기준](../ux-redesign.md).

## 버튼과 이동

| 버튼                                                                     | 동작                                                                                            |
| ------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| 목록으로 / 이전 화면                                                     | 상세 방문 이력의 이전 화면으로 돌아가며 이전 스크롤 위치 복원. 이전 상세가 없으면 목록으로 복귀 |
| 농장 폴더 / 위치도                                                       | 해당 URL이 있을 때만 표시하며 새 탭으로 열기                                                    |
| 기본정보 수정                                                            | 농가 기본정보 수정 창 열기                                                                      |
| 참여 사업 추가                                                           | 아직 참여하지 않은 첫 프로젝트를 기본 선택하여 추가 창 열기. 남은 프로젝트가 없으면 안내 알림   |
| 새 업무 등록 / 업무 등록                                                 | 업무 등록 창 열기. 참여 사업이 하나면 자동 선택, 여러 개면 선택 대기                            |
| 참여 사업 카드의 만료일 입력·정정 / 설치 정보 수정 / 이 사업에 업무 등록 | 해당 참여 기록을 대상으로 각 창 열기                                                            |
| 업무 카드 / 업무 전체 과정 보기                                          | 해당 농가의 업무 전체 상세로 이동                                                               |

상단 **새 업무 등록**은 참여 기록이 없으면 비활성화된다. 농가 업무 영역의 **업무 등록** 버튼은 표시되지만 같은 경우 함수가 바로 반환하므로 창이 열리지 않는다.

## 빈 상태

연락처는 `연락처 미입력`, 주소는 없으면 지역을 표시한다. 폴더·위치도·특이사항은 값이 없으면 숨긴다. 참여 기록이 없으면 참여 사업 영역은 빈 목록이며 별도 안내 문구는 없다. 업무와 이력은 각각 등록 없음 안내를 표시한다.
