# 농가 전체 상세

최종 수정: 2026-09-09 · [농가 관리대장](README.md)

[전체 목차](../README.md) · [입력창 목차](../forms/README.md)

## 목적과 진입

한 농가의 참여 사업·설치·구독 정보, A/S, 처리 이력과 입금내역을 모아 확인한다. 농가 관리대장 이름 버튼이나 다른 화면의 농가 상세 링크에서 `openFarm(farmId)`로 연다. 화면 조건은 `selectedFarm`이 있고 `selectedWorkItem`이 없는 상태다. 상세 방문 이력을 기록하여 뒤로가기를 지원한다.

## 구성과 범위

- 상단 기본정보: 농장번호·지역·참여 사업 수·진행 A/S 수·농가명·연락처·주소와 현재 보는 사업 선택.
- [참여 사업·설치·구독 정보](cards/participation.md): **탭 위에 항상 표시**한다. 프로젝트명, 장비·작물·제품, 설치 단계, 보증·구독 만료일을 확인하고 수정한다. 기본정보 수정·참여 사업 추가·A/S 등록, 선택 링크와 [위치도 사진](../forms/farm-location-images.md)도 이 영역에 있다.
- [A/S](cards/farm-work.md): `workType === 'service'`인 기록만 표시한다. 기본 선택 탭이며 완료된 A/S와 파모스박스 교체 이력도 보존한다.
- [처리 이력](cards/farm-history.md): 일반 업무·설치·A/S·입금 등 **모든 유형의 기존 이력을 유지**한다.
- [입금내역](cards/farm-payments.md): 입금 유형의 실제 양수 금액 기록을 최신순으로 확인하고 등록한다.

프로젝트에서 진입한 경우 ‘현재 보는 사업’이 해당 프로젝트로 설정되며 참여 기록·A/S·처리 이력·입금내역이 함께 제한된다. ‘전체 참여 사업’ 또는 다른 참여 사업으로 전환할 수 있다. 농가 관리대장에서 직접 진입하면 기본은 전체 참여 사업이다. 중복 사업 검사는 항상 전체 참여 기록을 사용한다. 목록의 구독·작목·지역·검색 조건은 상세 내용을 제한하지 않는다. 과거 ‘사업·설치·구독’ 탭 방문 상태는 A/S 탭으로 호환한다.

## 버튼과 이동

| 버튼                                                                    | 동작                                                                                            |
| ----------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------- |
| 목록으로 / 이전 화면                                                    | 상세 방문 이력의 이전 화면으로 돌아가며 이전 스크롤 위치 복원. 이전 상세가 없으면 목록으로 복귀 |
| 농장 폴더 / 위치도                                                      | 해당 URL이 있을 때만 표시하며 새 탭으로 열기                                                    |
| 기본정보 수정                                                           | 농가 기본정보 수정 창 열기                                                                      |
| 참여 사업 추가                                                          | 아직 참여하지 않은 첫 프로젝트를 기본 선택하여 추가 창 열기. 남은 프로젝트가 없으면 안내 알림   |
| A/S 등록                                                                | A/S 유형을 미리 선택한 등록 창. 참여 사업이 하나면 자동 선택, 여러 개면 선택 대기               |
| 참여 사업 카드의 만료일 입력·정정 / 설치 정보 수정 / 이 사업에 A/S 등록 | 해당 참여 기록을 대상으로 각 창 열기                                                            |
| A/S 카드 / 업무 전체 과정 보기 / 입금 상세                              | 해당 기록의 전체 상세로 이동                                                                    |
| 입금 등록                                                               | 입금 유형을 미리 선택한 기존 등록 창. 구독 연장·회차·입금 검증을 재사용                         |

A/S 등록과 입금 등록은 참여 기록이 없으면 비활성화된다. 공통 고정 헤더의 **사업 추가·농가 등록**은 제거하고, 프로젝트 등록은 통합 현황·프로젝트 관리에, 농가 등록은 농가 관리대장에 둔다. 데이터는 삭제하거나 유형을 일괄 변경하지 않는다.

## 빈 상태

연락처는 `연락처 미입력`, 주소는 없으면 지역을 표시한다. 폴더·위치도·특이사항은 값이 없으면 숨긴다. 참여 기록이 없으면 참여 사업 영역은 빈 목록이다. A/S·처리 이력·입금내역은 각각 등록 없음 안내를 표시한다.
