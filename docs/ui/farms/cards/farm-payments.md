# 농가 입금내역

최종 수정: 2026-09-09 · [농가 상세](../detail.md)

농가 상세의 **입금내역** 탭에서 현재 보는 사업에 연결된 입금 이력을 확인한다. 전체 참여 사업 선택 시 해당 농가의 모든 사업을 합친다.

- 대상: 선택 농가·사업의 `workType === 'payment'` 업무에 속한 `amount > 0` 이력. 요약 필드의 마지막 입금일·누적액을 별도 입금으로 중복 생성하지 않는다.
- 정렬: 발생 일시 내림차순, 같으면 생성 일시 내림차순.
- 표시: 입금일, 사업명, 입금액, 처리 내용(없으면 받은 내용), 입금 상세 버튼.
- 상단 건수와 금액은 현재 페이지가 아닌 선택 범위의 전체 입금 기준이다. KPI의 회차별 갱신율 집계와는 별개인 거래 이력이다.
- 20건씩 이전·다음 페이지를 제공한다. 농가·사업이 바뀌면 첫 페이지로 돌아가며 실시간 목록이 줄어도 유효한 페이지를 표시한다.
- 입금 상세는 기존 기록 상세를 연다. 입금 등록은 연결 사업을 선택하는 기존 폼을 재사용하므로 구독 만료일 연장·갱신 회차·입금 검증은 동일하다. 0원 업무 메모는 실제 입금내역에 포함하지 않는다.
- 참여 사업이 없으면 등록을 비활성화한다. 입금이 없으면 등록된 입금내역이 없다는 안내와 총 0원을 표시한다.

구현: `app/farm-payment-history.tsx`, `selectedFarmPayments`. 검증: `scripts/test-farm-detail-ui.mjs`.
