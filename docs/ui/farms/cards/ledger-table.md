# 농가 대장표

작성일: 2026-09-07 · 구현 기준: `141faaa` · [화면 문서](../README.md)

## 목적과 표시값

검색 및 4개 선택 조건을 모두 만족하는 농가를 한 농가당 한 행으로 표시한다.

| 열          | 표시·계산                                                                                                                      |
| ----------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 농가        | 농가명과 농장번호                                                                                                              |
| 사업        | 대표 참여 기록의 프로젝트명(`미연결` 대체)과 해당 농가의 전체 참여 기록 수                                                     |
| 지역·작목   | 농가의 원본 지역, 대표 기록의 작목·장비. 미입력은 `작목 미입력`·`장비 미입력`                                                  |
| 최근 업무   | 농가 전체 업무 중 `lastActivityAt`이 최신인 업무의 제목과 유형. 없으면 `등록된 업무 없음`                                      |
| 업무 상태   | 위 최신 업무의 현재 상태. 업무가 없으면 빈 칸                                                                                  |
| 구독        | 선택 사업 범위 참여 기록들의 유효 농가 구독 상태. 구독 중 우선, 다음 만료, 다음 미등록                                         |
| 구독 만료일 | 선택 사업 범위 기록을 날짜 있는 항목 우선 → 만료일 오름차순 → ID순으로 정렬한 최대 2개. 사업명도 표시하며 날짜 없음은 `미입력` |
| 최근 활동   | 농가 수정 시각·최신 참여 기록 활동·최신 업무 활동의 최댓값                                                                     |

대표 참여 기록은 전체 사업이면 가장 최근 활동 기록, 사업을 선택하면 해당 사업에서 가장 최근 활동 기록이다. 코드에는 해당 사업 기록을 못 찾을 때 전체 최신 기록으로 돌아가는 처리도 있다. 사업 필터를 설정해도 **최근 업무와 최근 활동, 전체 참여 사업 수는 농가 전체 범위**다. 참여 기록 수에는 동일 사업 중복 기록도 포함된다.

## 클릭과 필터 범위

행 전체에는 클릭이 없다. 농가명은 상세를 연다. 만료일 버튼은 해당 참여 기록의 입력·정정 창을 연다. 3개 이상이면 **외 N개 사업 보기**가 상세를 연다. 참여 기록이 없으면 `참여 사업 없음`이다.

검색·사업·구독·작목·지역 조건은 [화면 문서](../README.md)의 정의대로 모두 적용한다. 결과는 최근 활동 내림차순이며 페이지 구분 없이 전체 결과를 렌더링한다. 결과가 없으면 8열에 걸쳐 **검색 조건에 맞는 농가가 없습니다.**를 표시한다. 화면 상단 CSV는 이 표의 필터 결과를 내보내는 기능이 아니다.
