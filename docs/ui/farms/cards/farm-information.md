# 농가 상세 정보

작성일: 2026-09-07 · 구현 기준: `141faaa` · [농가 상세](../detail.md)

## 목적과 표시값

선택 농가의 식별 정보와 연락·현장 접근 정보를 보여준다. 상단 배지는 농장번호, 지역, **참여 사업 N개**, **진행 업무 M건**이다. `N`은 농가에 연결된 모든 참여 기록 수이고 `M`은 해당 농가 업무 중 `status !== 'completed'` 수다. 참여 사업 수는 프로젝트 ID로 중복 제거하지 않는다.

농가명, 전화번호(`연락처 미입력` 대체), 주소(없으면 지역)를 표시한다. 특이사항은 값이 있을 때만 별도 영역에 줄바꿈을 유지해 표시한다. 사업자번호는 이 요약 영역에 직접 표시하지 않지만 기본정보 수정 창에서 편집할 수 있다.

## 동작과 필터 범위

농장 폴더·위치도는 URL이 있을 때 버튼을 표시하고 새 탭을 연다. **기본정보 수정**은 농가 기본정보를 채운 수정 창을 연다. 참여 추가·업무 등록 동작은 [상세 화면](../detail.md)을 따른다. 요약 본문에는 클릭 동작이 없다. 목록 필터와 무관한 선택 농가 전체 범위다.

농장번호·지역은 원본 값 그대로라 비어 있으면 배지도 빈 값이 될 수 있다. 링크와 특이사항은 값이 없을 때 숨긴다.
