# 농가 업무 카드

작성일: 2026-09-07 · 구현 기준: `141faaa` · [농가 상세](../detail.md)

## 목적과 표시값

선택 농가의 업무를 최근 활동순으로 보여주는 공통 `WorkItemCard`의 전체 형태(`compact = false`)다. 업무 종류·상태·우선순위, 응답 위험 배지, 제목, 사업명, 담당, 마지막 활동 시각, 다음 행동, 체크리스트, 다음 방문, 마지막 받은·처리 내용을 표시한다.

| 요소                                | 표시 조건·계산                                                                                                                                                              |
| ----------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 응답 위험                           | 목표 없음이면 배지 없음. 응답했으면 목표 시각 이내는 달성, 이후는 실패. 아직 응답 전이면 남은 시간이 음수는 목표 초과, 24시간 이내는 긴급, 72시간 이내는 주의, 그 밖은 여유 |
| 대기·막힘                           | 상태가 `waiting`일 때만. `max(0, floor((현재 시각 - blockedAt) / 1일))`일, 해제 주체와 막힘 사유. `blockedAt`이 0이면 0일                                                   |
| 다음 행동                           | 완료 업무는 `완료된 업무입니다.`, 미완료는 `nextAction` 또는 `다음 행동을 정해 주세요.`                                                                                     |
| 체크리스트                          | 항목이 있을 때만 완료된 항목 수 / 전체 항목 수                                                                                                                              |
| 다음 현장 방문                      | `scheduled` 방문 중 `scheduledAt`이 가장 빠른 1건의 시각·담당. 과거 예약을 별도로 제외하지 않음                                                                             |
| 마지막 받은 내용 / 마지막 처리 내용 | 업무 이력을 발생 시각 내림차순, 동률은 생성 시각 내림차순으로 정렬한 뒤 각 필드가 공백이 아닌 첫 기록. 두 내용은 서로 다른 이력에서 올 수 있음                              |

사업 연결이 없으면 `사업 미연결`, 담당이 비면 `미지정`, 내용이 없으면 각 영역에 없음 문구를 표시한다. 날짜 마감 배지는 이 카드 형태에는 없다.

## 클릭과 필터 범위

카드 전체를 누르면 업무 전체 상세를 연다. 농가 업무 영역의 **업무 등록**은 등록 창을 연다. 참여 기록이 없으면 함수가 반환해 창이 열리지 않는다. 완료 여부·사업·목록 조건에 관계없이 해당 농가의 전체 업무를 표시한다. 업무가 없으면 **등록된 업무가 없습니다.**와 첫 업무 작성 안내를 표시한다.
