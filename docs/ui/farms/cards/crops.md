# 작목별 농가 카드

작성일: 2026-09-07 · 구현 기준: `141faaa` · [화면 문서](../README.md)

## 목적과 표시값

작목 분포를 보여주며 표의 작목 조건을 선택한다. 각 농가의 전체 참여 기록에서 작목의 앞뒤 공백을 제거하고 연속 공백을 하나로 정리한 뒤, 비어 있지 않은 작목 문자열을 중복 제거한다. 남는 작목이 없으면 `작목 미입력` 한 항목에 넣는다. 하나의 문자열을 쉼표 등으로 분할하지 않는다.

작목마다 고유 농가 ID 수 `N`을 세어 **N곳 · P%**와 막대를 표시한다. `P = Math.round(N / 전체 농가 수 × 100)`이며 농가가 없으면 0이다. 복수 작목 농가는 각 작목에 포함하므로 작목별 개수의 합이 전체 농가 수를 넘을 수 있다. 상단 **M개 작목**은 미입력 항목을 포함한 분류 개수다. 정렬은 농가 수 내림차순, 같으면 한국어 이름순이다.

## 동작과 필터 범위

작목 행을 누르면 그 작목을 선택하고 같은 행을 다시 누르면 모든 작목으로 바꾼다. 다른 조건은 유지된다. 선택된 행은 선택 표시된다. 이 카드의 수치는 전체 농가 기준이고 표의 작목 판정에는 선택 사업 범위의 기록을 사용한다. 목록은 높이 280px를 넘으면 내부 스크롤된다.

등록 농가가 없으면 **등록된 농가가 없습니다.**를 표시한다.
