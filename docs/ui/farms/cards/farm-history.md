# 농가 전체 히스토리 카드

작성일: 2026-09-07 · 구현 기준: `141faaa` · [농가 상세](../detail.md)

## 목적과 표시값

선택 농가의 모든 업무에 연결된 이력을 한 목록으로 모은다. 업무별 이력을 합친 후 발생 시각 내림차순, 동률이면 생성 시각 내림차순으로 정렬하며 건수 제한이나 페이지 구분은 없다.

각 이력 카드는 연결된 프로젝트명(`사업 없음` 대체), 업무 종류, 업무 제목, 발생 시각을 표시한다. 받은 내용과 처리 내용은 값이 있을 때만 두 줄까지 보여준다. 발신자·채널·기록자·첨부 링크는 이 카드 형태에 표시하지 않는다.

## 클릭과 필터 범위

**업무 전체 과정 보기**를 누르면 해당 업무 전체 상세를 연다. 카드 전체에는 클릭 동작이 없다. 선택 농가에 속한 현재 업무들의 이력만 포함하므로 연결 업무가 없는 이력은 들어오지 않는다. 프로젝트 자체 업데이트는 포함하지 않는다. 농가 목록의 검색·사업·구독·작목·지역 조건은 적용하지 않는다.

이력이 없으면 **아직 기록된 히스토리가 없습니다.**를 표시한다. 업무 상세가 열린 상태에서는 이 전체 농가 이력 영역을 숨긴다.
