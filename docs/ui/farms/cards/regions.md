# 지역별 농가 카드

작성일: 2026-09-07 · 구현 기준: `141faaa` · [화면 문서](../README.md)

## 목적과 표시값

농가에 등록된 지역별 분포를 보여준다. `farm.region`의 앞뒤 공백과 연속 공백을 정리하고 비어 있으면 `지역 미입력`으로 분류한다. 주소에서 지역을 추출하지 않는다.

지역마다 고유 농가 ID 수 `N`을 세어 **N곳 · P%** 및 막대를 표시한다. `P = Math.round(N / 전체 농가 수 × 100)`이다. 농가당 한 지역에 속하며 지역별 비율의 합은 반올림 때문에 정확히 100이 아닐 수 있다. 상단 **M개 지역**은 미입력 분류를 포함한 지역 개수다. 정렬은 건수 내림차순, 같으면 한국어 지역명순이다.

## 동작과 필터 범위

지역 행 클릭으로 해당 지역을 선택하고 재클릭하면 모든 지역으로 바꾼다. 다른 조건은 유지한다. 카드 통계는 전체 농가 기준으로 검색·사업·구독·작목·지역 필터와 무관하다. 높이 280px를 넘으면 내부 스크롤된다. 농가가 없으면 **등록된 농가가 없습니다.**를 표시한다.
