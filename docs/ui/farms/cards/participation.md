# 참여 사업·설치 정보 카드

작성일: 2026-09-07 · 구현 기준: `141faaa` · [농가 상세](../detail.md)

## 목적과 표시값

2026-09-09 개편: 농가 상세 **탭 위 상단**에 참여 기록 하나당 카드 하나를 표시하고 해당 기록에 A/S를 연결한다. 프로젝트 연도(연결 없음은 `-`), **저장된 구독 상태** 배지, 프로젝트명(`사업 없음` 대체), 작물·장비·제품, 설치 단계 완료 수, 보증 및 구독 만료일을 표시한다.

**설치 단계 C/4**는 `productionSetupDate`, `installationDate`, `commissioningDate`, `educationDate` 중 값이 있는 필드 수다. 날짜가 미래인지, 순서가 올바른지는 이 계산에서 판단하지 않는다. 보증은 `warrantyExpiresAt`, 구독은 `currentSubscriptionExpiresAt`이며 빈 날짜는 `미입력`이다. 작물·장비·제품이 비면 각각 `작물 미입력`·`장비 미입력`·`제품 미입력`이다.

구독 배지는 `record.subscriptionStatus`를 그대로 표시한다. 만료일을 반영한 유효 구독 상태를 사용하는 농가 대장표·KPI와 값이 다를 수 있다.

## 동작과 필터 범위

- **만료일 입력·정정**: 이 참여 기록의 구독 만료일 변경 창.
- **설치 정보 수정**: 이 참여 기록을 채운 수정 창.
- **이 사업에 A/S 등록**: 이 참여 기록과 A/S 유형을 미리 선택한 등록 창.

프로젝트명을 누르면 해당 프로젝트 상세로 이동한다. ‘현재 보는 사업’에 속한 참여 기록을 `lastActivityAt` 내림차순으로 표시하며 농가 목록 필터는 적용하지 않는다. 전체 참여 사업 선택 시 모두 표시한다. 참여 기록이 없으면 카드 목록만 비고 별도 안내는 없다.
