# 전체 농가 KPI

작성일: 2026-09-07 · 구현 기준: `141faaa` · [화면 문서](../README.md)

## 목적과 표시값

전체 농가 등록 규모를 보여준다. **전체 농가 N곳**에서 `N = workspace.farms.length`이며 보조 문구는 **전체 관리대장 등록 기준**이다. 참여 기록이 없는 농가도 포함한다. 데이터가 없으면 `0곳`이다.

## 동작과 필터 범위

누르면 구독 필터만 `all`로 바꾼다. 검색·사업·작목·지역 필터는 유지된다. 구독 조건이 전체일 때 선택 표시(`aria-pressed`)가 켜진다. 표시 수치는 모든 필터와 무관한 전체 범위다.
