# 농가 관리대장

작성일: 2026-09-07 · 구현 기준: `141faaa` · 화면 상태: `view === 'farms'`

[전체 목차](../README.md) · [입력창 목차](../forms/README.md)

## 목적과 진입

농가별 사업 참여, 최근 업무, 구독 상태와 만료일을 조회하는 화면이다. 왼쪽 **농가 관리대장** 메뉴 또는 통합 현황의 최근 이력 **전체 보기**에서 진입한다. 농가 이름을 누르면 [농가 전체 상세](detail.md)를 연다.

## 검색과 필터

| 조건 | 적용 내용                                                                                                                                                                          |
| ---- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 검색 | 농장번호·이름·연락처·주소·지역·사업자번호, 모든 참여 기록의 작목·장비·제품·업체·사업명, 업무 제목·담당·설명, 이력 받은 내용·처리 내용·발신자. 앞뒤 공백 제거 후 소문자로 부분 비교 |
| 사업 | 선택 사업의 참여 기록이 있는 농가                                                                                                                                                  |
| 구독 | 모든 구독 / 구독 중 / 미구독 전체 / 만료 / 미등록. 선택 사업 범위의 참여 기록으로 농가 유효 구독 상태 판정                                                                         |
| 작목 | 선택 사업 범위 참여 기록의 정규화한 작목 목록에서 선택값과 일치                                                                                                                    |
| 지역 | 농가의 정규화한 지역과 일치                                                                                                                                                        |

조건은 모두 동시에 적용한다. 상단 KPI와 작목·지역 분포 및 선택지 건수는 **전체 농가 기준**으로 유지된다. 검색 대상 내용은 사업 필터로 좁혀지지 않는다. 표 위의 **현재 조건 N곳 / 전체 M곳**으로 결과 수를 확인한다.

## 버튼

- **농가 등록**: 농가 및 첫 참여 사업 등록 창을 연다. 기본 사업은 진행 프로젝트 중 첫 항목, 없으면 첫 프로젝트다.
- **CSV 내보내기**: 전체 `workspace.records`를 참여 기록당 한 행으로 내려받는다. 현재 표 필터를 적용하지 않으며 참여 기록 없는 농가는 포함되지 않는다. 저장 상태의 구독 표시명을 사용한다. 파일명은 `팜로그_관리대장_YYYY-MM-DD.csv`다.
- KPI 카드: 구독 조건을 전체 / 구독 중 / 미구독 전체로 변경한다. 다른 필터는 유지한다.
- 작목·지역 행: 해당 필터를 선택하며 같은 항목을 다시 누르면 그 필터만 전체로 돌린다.
- **전체 조건 초기화**: 검색·사업·구독·작목·지역을 모두 초기화한다.
- 농가명과 **외 N개 사업 보기**: 농가 상세 열기. 만료일: 해당 참여 기록의 **구독 만료일 입력·정정** 창 열기.

## 빈 상태

전체 농가가 없으면 KPI는 0, 작목·지역은 **등록된 농가가 없습니다.**를 표시한다. 표는 등록 농가가 없거나 필터 결과가 없는 경우 모두 **검색 조건에 맞는 농가가 없습니다.**를 표시한다. 필터가 하나라도 설정되어 있으면 전체 조건 초기화 버튼이 나타난다.
