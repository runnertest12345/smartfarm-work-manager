# 연도별 구독 실적

갱신일: 2026-09-07 · 연간 전체 조회 / 입금 순서 기준 / 만료 경과 미갱신

## 화면과 기간

‘구독·입금 → 만료·실적 보고’에서 연도와 사업 타입을 선택합니다. **매년 1월 1일~12월 31일 전체**를 조회하며 종료월 선택은 없습니다. 기본값은 올해입니다.

상단은 **빈 달도 포함한 1~12월별 만료 농가 표**이며 첫·반복·전체 갱신율 카드는 그 아래 보조 지표입니다. 연도별·사업 타입별·사업별로 묶어 볼 수도 있습니다. 월별 ‘농가 보기’에서 농가명·사업·만료일·입금 건수·해당 입금 차수(1차·2차·3차)를 확인하고 상세/결과 등록으로 이동합니다. 그룹은 12개, 상세 농가는 10개 단위이며 전체 필터 결과의 합계를 유지합니다.

## 미갱신과 오늘의 경계

만료일이 오늘보다 이전이고 갱신 완료가 없으면 **미갱신**입니다. 별도 결과를 등록할 필요가 없습니다. 기존 이탈 기록과 결과 없는 회차를 합산하되 원본 이탈 이벤트를 자동 생성하지 않습니다.

오늘 만료는 당일까지 유효하므로 ‘오늘 만료’, 내일부터는 ‘만료 예정’으로 별도 표시합니다. 두 집단은 아직 만료일이 지나지 않아 갱신율 분모·분자에서 제외합니다. 만료 후 입금/갱신이 확인되면 현재 실적은 미갱신에서 갱신으로 바뀝니다.

상충하는 갱신·이탈 기록은 ‘기록 확인’으로 별도 분리하고 분모에는 포함합니다. 자동 입금 갱신이 명시적으로 대체한 이전 이탈은 과거 원본을 유지하면서 새 갱신 결과를 인정합니다. 일반적인 무기록 미갱신에 잠정 배지를 붙이지 않습니다.

## 입금 순서로 정하는 핵심 KPI

| 구분        | 집단                                        | 산식                                                   |
| ----------- | ------------------------------------------- | ------------------------------------------------------ |
| 첫 갱신율   | 첫 번째 입금 대상 · 이전 입금 0회           | 첫 입금 회차의 갱신 완료 / 해당 만료 경과 대상 × 100   |
| 반복 갱신율 | 두 번째 이후 입금 대상 · 이전 입금 1회 이상 | 반복 입금 회차의 갱신 완료 / 해당 만료 경과 대상 × 100 |
| 전체 갱신율 | 과거 입금 연결 필요 건까지 포함             | 전체 갱신 완료 / 전체 만료 경과 대상 × 100             |

**첫 입금이 첫 갱신이며 두 번째 입금은 두 번째 갱신입니다.** 금액을 입금 건수로 바꾸지 않습니다. 132,000원 한 번 입금은 2년 연장·1회 입금입니다. 현재 수기 renewalCount 값으로 첫·반복 KPI를 분류하지 않습니다.

33개소 중 갱신22·미갱신11이면 66.67%입니다. 만료 경과 대상이 있고 갱신이 없으면 0%, 대상 자체가 없으면 -입니다. 재가입은 선택 연도 중 오늘까지 처리한 건을 별도로 집계하고 갱신율에 합산하지 않습니다.

## 입금이 있는데 ‘과거 입금 연결 필요’가 나오는 이유

입금 존재와 특정 과거 만료 회차에 대한 연결은 별개입니다. 실제 입금 건수는 표시하지만, 과거 갱신 이벤트에 연결된 입금 ID가 없고 처리일과 입금일도 다르면 임의로 어느 회차의 결제인지 정하지 않습니다. 같은 날 입금이 여러 건이라 명확하지 않은 경우도 포함합니다. 종전 ‘회차 미확인’이라는 표시는 ‘과거 입금 연결 필요’로 바꿨습니다.

새 자동 갱신은 원본 입금 ID·입금 전 횟수·이번 입금 회차를 함께 저장하므로 이후 입금이 늘어도 과거 집단이 바뀌지 않습니다. 기존 갱신은 명시적 입금 연결이나 같은 날의 유일한 입금으로 판정합니다. 연결을 알 수 없는 갱신도 전체 갱신율에는 포함되지만 첫·반복 비교에서는 제외합니다. 현재 결과 없는 회차는 저장된 실제 입금 수로 다음 입금이 첫 번째인지 반복인지 판정합니다.

## 단위·검증 관계

단위는 농가×사업 참여×만료 회차입니다. 같은 농가의 다른 사업/회차는 별도로 집계되므로 고유 농가 수와 다를 수 있습니다.

- 연간 전체 대상 = 만료 경과 + 오늘 만료 + 만료 예정
- 만료 경과 = 갱신 완료 + 미갱신 + 기록 확인
- 전체 만료 경과 = 첫 대상 + 반복 대상 + 과거 입금 연결 필요 대상

분모는 현재 만료일과 갱신·이탈 이력의 기준 만료일을 참여 ID+날짜로 중복 제거합니다. 최초 만료일·정정 전 날짜로 누락된 과거 회차를 추정하지 않습니다. 과거 연도도 당시 화면 상태를 복원하는 것이 아니라 오늘까지 확인된 결과를 보여 줍니다.

하단 ‘현재 미갱신·전체 만료 예정’은 선택 연도와 독립된 현재 운영 현황입니다. 현재 사용중이며 내일부터 만료되는 참여만 전체 예정 목록에 나옵니다.
