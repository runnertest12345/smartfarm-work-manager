# 구독 실적

작성일: 2026-09-07 · 기준: 연도·구독 KPI 개선 · 현재 구현 설명

## 화면 목적·진입

‘구독·입금’ 화면에서 ‘만료·실적 보고’ 탭을 엽니다. 현재 회차, 오늘 기준 만료 현황, 보고 기간의 만료 대상·갱신·이탈·재가입과 오늘 포함 이후 만료 예정, 최근 처리 이력을 확인하고 보고문을 복사합니다.

## 필터·집계 기간

기준 연도와 집계 종료월은 해당 연도 1월 1일부터 종료월 말일까지입니다. 특정 한 달만 조회하는 필터가 아닙니다. 기본 연도·월은 전월 기준이며 1월에는 전년도 12월입니다. 사업 타입은 전체·일반 사업·연구 사업입니다. 개별 사업 선택은 이 보고 탭에 없으며 관리 탭의 개별 사업·검색·상태와 독립적입니다.

연도 선택지는 현재 선택 연도, 현재 연도, 구독 이벤트의 기준 만료일·처리일 연도, 현재 만료일의 연도를 합쳐 내림차순으로 만듭니다.

| 표시 영역           | 기준 날짜·필터                                                               |
| ------------------- | ---------------------------------------------------------------------------- |
| 만료 대상·갱신·이탈 | 사업 타입 및 기준 만료일의 보고 기간                                         |
| 재가입              | 사업 타입 및 처리일의 보고 기간                                              |
| 갱신률              | 선택 기간의 갱신·이탈에서 파생                                               |
| 현재 구독 회차 5개  | 사업 타입만 적용, 만료 포함 현재 등록 회차                                   |
| 만료 후 결과 미등록 | 사업 타입 + 오늘 이전 현재 만료일 + 오늘까지 같은 회차의 갱신·이탈 결과 없음 |
| 만료일 미입력 경고  | 사업 타입만 적용                                                             |
| 만료 예정           | 사업 타입 + 오늘 포함 이후 만료 + 오늘 사용중 (보고 기간 무관)               |
| 최근 구독 처리 8건  | 사업 타입만 적용, 기간 제한 없음                                             |

## 계산 주의점

갱신률은 **갱신 / (갱신 + 이탈)**이며 결과 미등록은 분모에서 제외합니다. 대상 33개소, 갱신 22개소, 이탈 0개소이면 현재 카드 값은 **100%**입니다. 기간의 미처리 회차와 오늘 기준 만료 후 결과 미등록은 별개입니다. 현재 만료일과 처리 이력을 확인해야 오늘 기준 수를 계산할 수 있습니다. 전체 대상 대비 갱신 비중 **66.7%**는 다른 해석이며 현재 카드에서 자동 표시하지 않습니다.

만료 대상은 레코드 ID와 기준 만료일로 구분하는 구독 주기 수입니다. 갱신·이탈도 같은 키로 각각 중복 제거하며 재가입은 이벤트 ID 수를 셉니다. 화면의 ‘개소’는 고유 농가 수라고 단정할 수 없습니다. 과거 보고 종료일을 골라도 당시 상태를 복원하지 않으며 현재 레코드와 저장 이벤트로 계산합니다.

## 버튼

‘보고문 복사’는 현재 집계값을 클립보드에 복사합니다. ‘구독 처리 등록’ 또는 최근 구독 처리의 ‘등록’은 입력창을 엽니다. 만료 예정의 연도·사업 제목은 펼침/접힘이며 농가명과 최근 처리 항목은 농가 상세로 이동합니다.

처리 입력창은 [등록·수정 폼 안내](../forms/README.md)를 참조합니다.

## 빈 상태

집계 대상이 없으면 건수는 0, 갱신·이탈 결과가 모두 0이면 갱신률은 `-`입니다. 예정이 없으면 ‘오늘 이후 만료 예정 구독이 없습니다.’, 이력이 없으면 ‘아직 등록된 구독 처리 이력이 없습니다.’를 표시합니다. 두 경고값이 모두 0이면 경고 상자를 숨깁니다.
