# 구독 실적

갱신일: 2026-09-07 · 첫 갱신·반복 갱신 비교 적용

## 목적과 화면 순서

‘구독·입금 → 만료·실적 보고’에서 첫 갱신율·반복 갱신율·전체 갱신율을 비교합니다. 상단 KPI → 집계표와 대상 상세 → 집계 기준 → 현재 회차 보조 현황 → 오늘 기준 운영 현황 → 전체 만료 예정·최근 처리 순서입니다. 기존의 회차별 농가 수는 보조 현황이며 갱신 성공률을 대신하지 않습니다.

## 핵심 KPI

| 구분        | 대상 집단                         | 산식                                       |
| ----------- | --------------------------------- | ------------------------------------------ |
| 첫 갱신율   | 해당 만료 회차 이전 갱신 0회      | 첫 갱신 완료 / 첫 만료 도래 대상 × 100     |
| 반복 갱신율 | 해당 만료 회차 이전 갱신 1회 이상 | 추가 갱신 완료 / 반복 만료 도래 대상 × 100 |
| 전체 갱신율 | 회차 미확인까지 포함한 모든 대상  | 전체 갱신 완료 / 전체 만료 도래 대상 × 100 |

결과 미확인·충돌도 분모에 포함합니다. 대상 33, 갱신 22, 미확인 11이면 **66.67% 잠정 실적**입니다. 대상이 있고 갱신이 없으면 0%, 대상 자체가 없으면 -입니다. 표시는 소수 둘째 자리까지입니다. 재가입은 갱신에 합산하지 않습니다.

## 기간과 단위

- 기준 연도 1월 1일부터 집계 종료월 말일까지 선택합니다. 기본값은 전월입니다.
- 만료 도래 대상은 선택 기간 중 **오늘까지(오늘 포함)** 도래한 회차입니다.
- 결과는 **오늘까지 확인된 처리**입니다. 과거 기간 말일 당시의 상태를 복원한 보고가 아닙니다.
- 표의 만료 예정은 **선택 기간 중 내일부터** 도래할 회차이며 현재 갱신율 분모·분자에서 제외합니다. 선갱신된 미래 회차도 예정에 남습니다.
- 하단 ‘오늘 기준 만료 현황·만료 예정’은 보고 기간과 무관한 현재 운영 현황입니다. 사용중이며 현재 만료일이 내일 이후인 참여만 예정으로 셉니다.
- 재가입은 선택 기간 시작일부터 보고 종료일과 오늘 중 이른 날까지의 처리 이벤트 ID를 셉니다.
- 단위는 농가×사업×만료 회차입니다. 같은 농가라도 사업이나 만료 회차가 다르면 여러 개소로 셉니다. 고유 농가 수가 아닙니다.

## 회차 판정과 원자료 한계

처리 이력의 `basisRenewalCount`를 우선합니다. 누락/null은 미확인이고 숫자 0은 첫 갱신입니다. 확인된 이전 갱신의 새 만료일이 이번 기준 만료일로 연결되고 사업·참여기록·처리 순서가 맞으면 반복 갱신 근거가 됩니다. 재가입은 연결 근거로 사용하지 않습니다.

현재 미처리 회차는 관리대장의 현재 등록 갱신 횟수를 처리 전 기준으로 사용합니다. 과거 완료 회차에는 현재 횟수를 대입하거나 1을 빼지 않습니다. 앞으로 현재 회차를 처리하면 저장 거래 안에서 갱신 전 횟수를 자동 보존합니다. 과거 회차 등록은 증빙으로 확인한 횟수를 선택 입력하고, 모르면 비워 둡니다. 기존 이력은 덮어쓰거나 일괄 추정 보정하지 않습니다.

확인 가능한 분모는 현재 만료일과 갱신·이탈 이력의 기준 만료일의 합집합입니다. 키는 `farmRecordId:basisExpiryDate`입니다. 최초 만료일·정정 이전 날짜·계약 기간을 이용해 과거 누락 회차를 만들지 않습니다. 따라서 미보존된 과거 이력이 있으면 실제 전체 계약 이력과 차이가 있을 수 있습니다.

회차 미확인과 결과 미확인은 다릅니다. 회차 미확인 갱신 건은 전체 갱신율의 분자·분모에는 포함되지만 첫·반복 비교에서는 제외됩니다. 같은 회차의 갱신·이탈, 서로 다른 새 만료일, 동일 ID의 모순은 결과 충돌로 두고 확정 분자에서 제외합니다. 사업 귀속 충돌은 전체의 ‘사업 미확인’에 남습니다. 미래 처리일 기록은 현재 결과나 회차 증거로 사용하지 않으며 상세에 처리일을 안내하고 중복 등록 버튼은 숨깁니다.

## 표와 화면 연결

KPI를 누르면 하단 표가 해당 구독 구분으로 바뀝니다. ‘회차 미확인 보기’도 가능합니다. 묶어 보기는 연도·월·사업 타입·개별 사업이며 상단 연도·종료월·사업 타입 필터를 유지합니다. 연도별은 현재 선택 연도를 요약합니다.

표 열: 구분 / 만료 도래 대상 / 갱신 완료 / 이탈 확정 / 결과 미확인 / 결과 충돌 / 갱신율 / 만료 예정 / 상세. 그룹은 12개, 대상 상세는 10개 단위로 페이지 이동합니다. 합계는 전체 필터 결과입니다. ‘대상 보기’에서 농가 상세로 이동하거나 해당 기준 만료일로 결과를 등록합니다.

## 참고 검토

[참고 스프레드시트](https://docs.google.com/spreadsheets/d/1temWavcrQ3806ri132TlW4KbUUbEXq1fTqFyLet2X9k/edit#gid=940158464)의 사용자 제공 검토: 연간 만료 22·갱신 15·재가입 2의 77.27%는 재가입을 합산한 비율입니다. 갱신만은 68.18%지만 미래 만료를 포함한 연간 분모이므로 오늘 기준 갱신율은 아닙니다. 이 예시는 설명에만 사용하며 실제 데이터에 입력하지 않았습니다.

산식 없는 갱신 영향 요인·예상 갱신율은 실적 KPI에 넣지 않습니다. ‘한 번 갱신하면 이후에도 갱신한다’는 가설은 두 집단의 분모와 성공률로 검증해야 합니다. 회차별 입금 연결이 없는 상태에서 입금 완료를 추정하지 않습니다. 원본 스프레드시트는 수정하지 않습니다.
