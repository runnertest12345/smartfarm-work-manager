# 구독·입금 관리

작성일: 2026-09-07 · 기준: 연도·구독 KPI 개선 · 현재 구현 설명

## 화면 목적·진입

왼쪽 ‘구독·입금’ 메뉴를 누르면 `view === 'subscriptions'` 화면이 열립니다. 기본 탭은 ‘구독·입금 관리’이며 현재 구독 만료일과 입금을 처리합니다. ‘만료·실적 보고’ 탭은 [별도 보고 화면 안내](report.md)를 따릅니다. 두 탭은 필터 상태가 독립적입니다.

## 필터 적용 범위

2026-09-07 개편: 현재 회차 현황은 펼침 영역으로 제공한다. 표는 20건 단위 페이지를 유지하고 내부 세로 스크롤을 제거했다. 통합 현황에서 ‘구독 만료·미등록’으로 진입하면 해당 대상 ID 범위가 적용되며 명시적 범위 해제 또는 사업 타입·개별 사업 변경으로 해제한다. 보고 탭에는 이 범위를 적용하지 않는다. [개편 기준](../ux-redesign.md).

| 조작                               | 적용 범위                                                                       |
| ---------------------------------- | ------------------------------------------------------------------------------- |
| 사업 타입·개별 사업                | 관리 탭 기존 KPI 5개와 현재 회차 KPI 5개, 표, 최근 월별 입금, 관리 탭 건수 배지 |
| 농가·사업 검색                     | 관리 표 및 조건에 맞는 구독 건수                                                |
| 구독 상태(전체·사용중·만료·미등록) | 관리 표 및 조건에 맞는 구독 건수                                                |
| 이전·다음                          | 검색·필터 결과를 20건 단위로 표시                                               |
| 만료·실적 보고의 필터              | 관리 탭에는 미적용                                                              |

사업 타입은 전체·일반·연구 중 선택하며 개별 사업은 해당 타입으로 제한합니다. 타입 변경 시 개별 사업을 전체 사업으로 바꾸고 페이지를 1로 돌립니다. 관리 탭 타입 선택은 보고 탭 및 통합 현황의 선택과 독립적입니다.

검색 대상은 농장번호, 농가명, 지역, 사업명, 현재 만료일, 마지막 입금일이며 부분 일치로 찾습니다. 검색·사업·상태 변경과 탭 전환은 관리 목록을 1페이지로 돌립니다. 상단 KPI는 검색 및 구독 상태 필터와 함께 줄어들지 않습니다.

## 버튼·처리 흐름

‘구독 처리 등록’은 농가·사업 구독을 선택해 갱신·이탈·재가입을 기록하는 창을 엽니다. 창에는 처리일, 기준 만료일, 갱신 후 만료일(이탈 제외), 기록자, 메모가 있습니다. 대상 레코드가 없으면 등록 경고를 띄웁니다. 전체 화면 등록 버튼의 초기 대상 선택은 관리 필터로 제한하지 않습니다.

관리 표의 ‘만료일’은 현재 만료일 입력·정정 창입니다. 화면 안내상 정정은 갱신 횟수나 실적을 늘리지 않습니다. ‘구독 처리’는 실적 처리 창, ‘입금’은 해당 농가·사업의 입금 업무 등록 창을 엽니다. 버튼 클릭만으로 입금 또는 갱신이 저장되는 것은 아닙니다.

각 입력창은 [등록·수정 폼 안내](../forms/README.md)를 참조합니다.

## 데이터 해석

현재 구독 회차는 보고 기간의 누적 가입·연장 횟수가 아니라 등록된 현재 회차별 중복 없는 분류이며 만료된 참여도 포함합니다. 최초 구독은 갱신 0회, 구독 등록 근거, 같은 참여의 양수 입금 업무 이력을 모두 요구합니다. 입금일 수기 입력만으로는 인정하지 않습니다. 연장 회차는 등록된 갱신횟수 기준이며 입금 증빙을 보장하지 않습니다. 표의 입금 건수·금액 링크로 실제 업무 이력을 확인합니다.

관리 집계는 원본 농가·사업 참여 레코드 단위입니다. 프로젝트 상세와 사업 집계의 동일 사업·농가 중복 제거와 다릅니다. 사용중은 저장 상태가 사용중이고 현재 만료일이 오늘 이상일 때만 인정합니다. 만료일 없는 사용중은 실제 상태에서 미등록으로 분류합니다.

입금 금액은 입금 업무의 양수 금액 히스토리만 합산합니다. 구독 이벤트와 프로젝트 최종정산 금액은 별개입니다. 마지막 입금일은 참여 레코드의 저장 필드를 보여주며 월별 집계는 입금 히스토리 발생일을 사용합니다.

## 빈 상태

검색 결과가 없으면 표에 ‘검색 조건에 맞는 구독이 없습니다.’가 표시됩니다. 입금 히스토리가 없으면 월별 카드는 ‘입금 기록이 없습니다.’, 금액 KPI는 0원입니다. 농가·사업 참여가 없으면 구독 처리 등록 창 대신 먼저 등록하라는 경고를 표시합니다.
