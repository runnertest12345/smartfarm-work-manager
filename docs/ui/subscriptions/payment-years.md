# 전체 연도 · 입금연도별 갱신 차수

갱신일: 2026-09-07 · 사용자 확인: 실제 입금 연도 기준

‘구독·입금 → 만료·실적 보고 → 기준 연도 → 전체 연도’에서 확인합니다. 행은 실제 입금 연도, 열은 1차·2차·3차 등의 갱신 건수입니다. 전체 기간 총계가 첫 행입니다. 1~~3차는 항상 표시하며 실제 이력에 따라 4~~10차 열을 추가하고 그 이상은 11차 이상으로 묶습니다.

## 집계 기준

- 농가·사업 참여별 전체 양수 입금 업무 이력을 시간순으로 확인한 뒤 연도·사업 타입을 구분합니다. 2025년 첫 입금 후 2026년 추가 입금은 각각 2025년 1차, 2026년 2차입니다.
- 단위는 입금 **건**입니다. 132,000원 한 번 입금은 2년 연장·입금 1건입니다. 같은 농가가 같은 해에 여러 번 입금하면 각각 셉니다.
- 새 입금에 고정 저장한 차수는 그대로 사용합니다. 저장 차수와 시간순 추론이 충돌하거나 이력이 덜 불러와진 경우 과거 입금에 임의로 차수를 부여하지 않습니다.
- 중복 ID, 0원, 음수, 미래 입금, 연결 업무가 없는 이력, 입금 이외 업무는 제외합니다. 수기 갱신·재가입 이벤트만으로 입금 건수를 늘리지 않습니다.
- 사업 타입은 현재 농가·사업 참여의 타입을 따릅니다. 특정 연도의 만료 농가·갱신율 표와 기준이 다릅니다.
- 해당 연도에 기록된 거래만 표시하며 조회 한도 또는 저장 입금 수 대비 누락이 감지되면 불러온 범위라는 경고를 표시합니다. 불명확한 차수는 입금 건수에 포함하되 차수 열에는 임의 배분하지 않습니다.

개별 기준 연도를 선택하면 다시 1~12월 만료 농가 표가 나타납니다. ‘보고문 복사’도 전체 연도/개별 연도 선택을 따라 서로 다른 보고문을 만듭니다.
