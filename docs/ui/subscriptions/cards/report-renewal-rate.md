# 갱신률

선택 보고 기간의 갱신 ÷ (갱신 + 이탈) × 100을 소수 첫째 자리로 반올림합니다. 갱신·이탈 결과가 모두 0이면 `-`입니다. 기간에 속한 기준 만료일의 처리 결과를 사용합니다.

예를 들어 대상 33개소, 갱신 22개소, 이탈 0개소이면 결과가 등록된 22개소 중 갱신은 100%입니다. 전체 대상 대비 66.7%와 다릅니다. 오늘 기준 ‘만료 후 결과 미등록’ 카드는 별도 계산이므로 이 예시에서 자동으로 11개소라고 판단하지 않습니다.

사업 타입·보고 연도·종료월을 적용하며 조회 전용입니다. 관리 탭 필터는 적용하지 않습니다. 이번 연도·구독 KPI 개선에서는 이 기존 갱신률 산식을 변경하지 않았습니다.
