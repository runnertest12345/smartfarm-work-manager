# 전체 갱신율

선택 기간 중 오늘까지 도래한 전체 대상의 갱신 완료 ÷ 만료 도래 대상 × 100입니다. 결과 미확인·충돌 및 회차 미확인도 분모에 포함합니다. 재가입은 분자에서 제외합니다. 소수 둘째 자리까지 표시하며 대상 없음은 -, 대상 있음·갱신 없음은 0%입니다.

33개소 중 갱신 22, 미확인 11이면 66.67% 잠정 실적입니다. 미확인·충돌이 남으면 잠정 표시합니다. 기준 만료일로 기간을 정하고 결과는 오늘까지 확인합니다.

클릭하면 아래 집계표의 구독 구분이 전체로 바뀝니다. 연도·종료월·사업 타입 필터가 적용됩니다.
