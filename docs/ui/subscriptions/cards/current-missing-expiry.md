# 만료일 미입력 KPI

2026-09-08: 이 카드는 구독 실적 화면에서 제거했습니다. 아래는 종전 카드 설명입니다. 실제 업무 데이터와 별도의 만료 예정 목록은 삭제하지 않았습니다.

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

## 표시·계산

저장 상태가 미등록이 아닌데 현재 만료일이 없는 참여 수입니다. 날짜를 알 수 없으므로 미갱신 또는 만료 예정에 임의 배분하지 않습니다.

## 범위·동작

만료·실적 보고의 ‘오늘 기준 만료 현황’에 표시합니다. 사업 타입만 적용하고 보고 연도·종료월로 제한하지 않습니다. 오늘은 브라우저 현지 날짜이며 오늘 만료되는 구독은 그날까지 유효합니다. 카드에 기준일과 개소 수를 명시합니다. 조회 전용이며 빈 값은 0개소입니다.
