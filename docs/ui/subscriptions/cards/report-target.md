# 만료 대상

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

선택한 보고 기간에 만료 기준이 속하는 구독 주기의 수를 확인합니다.

## 표시값·계산식

라벨은 ‘만료 대상 · 기준연도.1~종료월’, 값은 `subscriptionReport.target`개소입니다. 다음 두 집합의 합집합 크기입니다.

- 갱신·이탈 이벤트 중 `basisExpiryDate`가 기간 안에 있는 `farmRecordId:basisExpiryDate` 키.
- 현재 `currentSubscriptionExpiresAt`가 기간 안에 있는 레코드의 `record.id:현재만료일` 키.

같은 키는 한 번 계산합니다. 갱신으로 현재 만료일이 미래로 바뀌어도 과거 이벤트의 기준 만료일이 기간에 속하면 대상이 유지됩니다. 기간 내 현재 만료일을 가진 레코드의 상태를 별도로 제한하지 않습니다. 재가입 이벤트만으로는 대상 키를 추가하지 않습니다. 대상이 없으면 0개소입니다.

## 클릭·버튼

조회 전용입니다.

## 필터 적용 범위

보고 탭의 사업 타입과 기준 연도 1월부터 집계 종료월까지의 기간을 적용합니다. 관리 탭의 개별 사업·검색·상태 필터는 적용하지 않습니다.
