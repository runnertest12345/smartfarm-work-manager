# 만료 도래 대상

선택 연도 1월부터 종료월 말일 사이에 있고 오늘까지 도래한 회차 수입니다. 갱신·이탈의 기준 만료일과 현재 만료일을 `farmRecordId:basisExpiryDate`로 합집합 처리합니다. 오늘 만료를 포함하고 내일부터는 만료 예정으로 분리합니다.

갱신으로 현재 만료일이 바뀌어도 과거 처리의 기준 만료일은 유지됩니다. 최초 만료일이나 이전 newExpiryDate로 누락 회차를 추정하지 않으며 재가입만으로 분모를 추가하지 않습니다. 상태만으로 이탈을 추정하지 않습니다.

농가×사업×만료 회차 단위이므로 고유 농가 수와 다릅니다. 집계표 ‘대상 보기’로 근거를 확인합니다.
