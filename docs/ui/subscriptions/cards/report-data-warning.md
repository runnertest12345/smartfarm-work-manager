# 결과 미등록·만료일 미입력 안내

오늘 기준으로 만료 후 결과 미등록 또는 만료일 미입력이 한 건 이상이면 안내 상자를 표시합니다. 문구에는 기준일, 만료 후 결과 미등록 수, 만료 예정 수와 오늘 만료 수가 들어갑니다. 만료일 미입력은 별도 문장으로 안내합니다.

결과 미등록은 현재 만료일이 오늘 이전이며 같은 참여 ID·기준 만료일의 갱신·이탈 결과가 오늘까지 등록되지 않은 수입니다. 재가입만으로 해결된 것으로 보지 않습니다. 미래 만료는 결과 미등록에 넣지 않고 만료 예정에 넣습니다.

사업 타입만 적용하며 보고 연도·종료월로 제한하지 않습니다. 따라서 선택 기간 만료 대상에서 갱신·이탈을 뺀 값과 다를 수 있습니다. 날짜 미입력은 저장 상태가 미등록이 아니면서 현재 만료일이 없는 수입니다.

조회 전용이며 수정하려면 관리 표의 만료일 또는 구독 처리를 사용합니다. 두 경고 수가 모두 0이면 상자를 숨기지만 상단 오늘 기준 KPI는 계속 표시합니다.
