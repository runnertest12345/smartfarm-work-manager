# 결과 미확인·데이터 품질 안내

성과 비교 패널에는 선택 기간의 도래 대상·갱신·이탈·결과 미확인·충돌·예정·재가입을 안내합니다. 회차 미확인은 전체에만 포함되며 첫·반복 비교에 제외됨을 알리고 해당 표로 연결합니다. 전체 원자료의 날짜·연결 오류는 제외 건수를 안내합니다.

하단 운영 경고는 오늘 이전 현재 만료일에 결과가 없거나 만료일이 미입력인 경우 표시합니다. 오늘 기준 미등록 수와 내일부터의 전체 현재 만료 예정 수를 안내하며 보고 기간과 무관합니다. 운영 경고는 성과표의 미확인·충돌 계산과 범위가 다릅니다.

원자료를 임의로 이탈·첫 갱신으로 보정하지 않습니다. 관리대장 상세와 처리 이력에서 확인하세요.
