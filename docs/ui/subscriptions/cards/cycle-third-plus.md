# 3차 이상 연장

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

## 표시·계산

등록된 갱신횟수가 3 이상인 참여 수입니다. 관리 표에서는 실제 등록 횟수를 표시합니다. 이 KPI는 연장 누적 도달 수가 아니라 현재 회차별 분류입니다.

## 범위·동작

구독·입금 관리와 만료·실적 보고 탭의 ‘현재 구독 회차’에 표시합니다. 관리 탭은 선택 사업 타입과 개별 사업의 교집합, 보고 탭은 선택 사업 타입의 전체 참여를 기준으로 하며 만료 상태도 포함합니다. 보고 연도·종료월, 검색·구독 상태 필터는 이 카드에 적용하지 않습니다.

농가×사업 참여 레코드 단위로 한 개의 회차에만 분류합니다. 5개 회차 카드의 합은 범위 내 전체 참여 수입니다. 현재 회차는 등록값이므로 역사적 가입·갱신 거래 횟수와 다릅니다. 조회 전용이며 대상이 없으면 0개소입니다.
