# 반복 갱신율

이전 갱신 경험이 1회 이상인 만료 회차의 추가 갱신 완료 / 만료 도래 대상 × 100입니다. 저장된 처리 전 횟수나 확인된 이전 갱신의 새 만료일 연결을 근거로 판정합니다. 재가입 자체는 반복 갱신 근거로 사용하지 않습니다.

기간·오늘 상한·잠정 표시·0%와 - 기준은 [전체 갱신율](report-renewal-rate.md)과 같습니다. 클릭하면 집계표가 반복 갱신 집단으로 바뀝니다. 첫 갱신율보다 높다는 결론을 미리 가정하지 않습니다.
