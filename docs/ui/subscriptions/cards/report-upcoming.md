# 만료 예정

선택 사업 타입에서 오늘 유효한 구독 중 현재 만료일이 오늘 이상인 참여를 연도→월→사업 순으로 묶어 개소 수를 표시합니다. 오늘 만료도 포함하며 보고 연도·종료월과 독립적입니다. 미래 연도도 함께 표시하고, 날짜 미입력·이미 만료된 구독은 제외합니다.

연도와 월은 오름차순, 사업은 건수 내림차순 후 이름순, 농가는 이름순입니다. 제목 옆 건수는 전체 예정 대상 합입니다. 연도·사업 제목을 눌러 펼치거나 접고 농가명을 눌러 농가 상세로 이동합니다.

현재 상태를 사용하는 운영 현황이며 과거 시점을 복원한 보고서가 아닙니다. 예정이 없으면 ‘오늘 이후 만료 예정 구독이 없습니다.’가 표시됩니다. 관리 탭 필터는 적용하지 않습니다.
