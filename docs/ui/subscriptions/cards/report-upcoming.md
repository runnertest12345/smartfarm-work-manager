# 전체 만료 예정 목록

선택 사업 타입에서 오늘 사용중이며 현재 만료일이 오늘보다 큰 참여를 연도→월→사업으로 묶습니다. 오늘 만료는 제외하고 내일부터 표시합니다. 보고 연도·종료월과 독립적인 전체 현재 운영 현황입니다. 상단 성과표의 선택 기간 만료 예정과 범위가 다릅니다.

연도·월은 오름차순, 사업은 수 내림차순·이름순, 농가는 이름순입니다. 제목을 눌러 펼치고 농가명을 누르면 상세로 이동합니다. 예정이 없으면 빈 상태를 표시합니다.
