# 최근 월별 입금

작성일: 2026-09-07 · 최종 수정: 2026-09-14

## 목적

입금 히스토리가 있는 최근 월의 건수와 금액을 확인합니다.

## 표시값·계산식

선택 범위의 양수 입금 히스토리를 `occurredAt`의 로컬 날짜에서 얻은 YYYY-MM별로 묶습니다. 월별 히스토리 수와 금액 합계를 표시하며 월 내림차순 상위 6개만 노출합니다.

연속 6개월 차트가 아니라 기록이 존재하는 최근 6개 월입니다. 기록이 없는 달을 0원으로 채우지 않습니다. 월별 건수는 고유 농가 수가 아닙니다.

## 클릭·버튼

기본으로 접혀 있으며 구독 목록 위에 ‘최근 월별 입금 · 펼치기’ 한 줄만 표시합니다. 제목을 클릭하거나 키보드 Enter/Space로 펼치고 다시 접을 수 있습니다. 펼치면 월별 건수·금액을 화면 너비에 맞춘 카드로 표시합니다. 별도 우측 칼럼을 차지하지 않아 구독 목록은 전체 너비를 사용합니다.

조회 전용으로 월 클릭이나 저장 동작은 없습니다. 집계·필터 범위는 기존과 동일합니다.

## 필터 적용 범위

관리 탭의 ‘사업 타입’과 ‘개별 사업’을 함께 적용합니다. 검색어·구독 상태·현재 페이지는 이 카드에 적용하지 않습니다. 보고 탭의 연도·종료월·사업 타입도 적용하지 않습니다.
