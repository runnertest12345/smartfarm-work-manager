# 최근 구독 처리

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

최근 갱신·이탈·재가입 처리 이력을 확인합니다.

## 표시값·계산식

선택 사업 타입의 모든 구독 이벤트를 처리일 내림차순, 같은 처리일이면 `createdAt` 내림차순으로 정렬해 최근 8건을 표시합니다. 이벤트 유형, 처리일, 연결 농가명, 사업명을 표시합니다. KPI처럼 기준 만료일로 중복 제거하지 않습니다.

## 클릭·버튼

항목을 누르면 연결 레코드가 존재할 때 농가 상세를 엽니다. ‘등록’은 구독 처리 등록 창을 엽니다. 연결 레코드가 없으면 항목 클릭으로 이동하지 않습니다.

## 필터 적용 범위

사업 타입만 적용합니다. 보고 기준 연도·종료월로 이력 목록을 제한하지 않으므로 KPI 기간 밖의 이벤트가 보일 수 있습니다. 관리 필터는 적용하지 않습니다.
