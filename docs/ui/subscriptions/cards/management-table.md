# 농가별 구독 만료일과 입금 표

작성일: 2026-09-07 · 기준: 연도·구독 KPI 개선 · 현재 구현 설명

## 목적

농가·사업별 구독 만료일, 마지막 입금일, 현재 구독 회차와 입금 근거를 확인하고 처리 창을 엽니다.

## 표시값·계산식

각 행은 원본 `FarmRecord` 1개입니다. 농가, 사업, 구독 만료일, 마지막 입금일(`lastPaymentDate`), 구독 회차·입금 근거(현재 회차 분류, 유효 입금 건수·금액), 실제 구독 상태, 처리 버튼을 표시합니다. 만료일 오름차순(미입력은 마지막), 같은 날짜는 농가명 한글순입니다. 한 페이지 20건이며 헤더는 표 안에서 고정됩니다.

구독 회차는 최초 구독·입금 확인, 1차 연장, 2차 연장, 3차 이상, 최초 입금·회차 미확인 중 하나입니다. 3차 이상은 실제 등록 횟수도 표시합니다. 입금이 없으면 ‘입금 업무 이력 없음’으로 안내합니다. [최초 입금 인정 기준](cycle-initial.md)을 따릅니다.

상태는 만료일과 저장 상태를 함께 판정합니다. 만료일 옆 D-day 배지는 날짜가 오늘~90일 뒤이면 표시하며 배지 조건 자체에는 사용중 여부가 없습니다.

## 클릭·버튼

농가명을 누르면 농가 상세를 엽니다. 입금 건수·금액 링크는 최근 유효 입금 이력이 있는 업무 전체 상세를 엽니다. ‘만료일’은 만료일 입력·정정 창, ‘구독 처리’는 해당 레코드가 선택된 갱신·이탈·재가입 창을 엽니다. ‘입금’은 해당 사업과 연결된 ‘구독료 입금’ 업무 등록 창을 열며 그 클릭만으로 입금이 저장되지는 않습니다. 이전·다음으로 페이지를 이동하고 양끝 버튼은 비활성화합니다.

## 필터 적용 범위

개별 사업·검색·구독 상태를 모두 적용합니다. 검색은 농장번호, 농가명, 지역, 사업명, 현재 만료일, 마지막 입금일을 소문자로 합쳐 부분 일치로 찾습니다. 필터 변경 및 탭 전환 시 1페이지로 돌아갑니다. 보고 탭의 필터는 적용하지 않습니다.

## 빈 상태·처리 구분

결과가 없으면 ‘검색 조건에 맞는 구독이 없습니다.’와 0/0건, 페이지 1/1을 표시합니다. 만료일 정정은 화면 안내상 갱신 횟수와 실적을 늘리지 않고 변경 이력을 남깁니다. 실제 갱신 실적 등록은 ‘구독 처리’를 사용합니다.
