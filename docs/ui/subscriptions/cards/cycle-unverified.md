# 최초 입금·회차 미확인

갱신일: 2026-09-07 · 연도·구독 KPI 개선 기준

## 표시·계산

최초 입금 인정 조건을 충족하지 못한 0회 참여 또는 갱신횟수가 음수·비정수 등 유효하지 않은 참여 수입니다. 미등록 참여도 포함할 수 있습니다. 실제 미입금 확정 수가 아니라 현재 기록만으로 확인하지 못한 수입니다.

## 범위·동작

구독·입금 관리와 만료·실적 보고 탭의 ‘현재 구독 회차’에 표시합니다. 관리 탭은 선택 개별 사업, 보고 탭은 선택 사업 타입의 전체 참여를 기준으로 하며 만료 상태도 포함합니다. 보고 연도·종료월, 검색·구독 상태 필터는 이 카드에 적용하지 않습니다.

농가×사업 참여 레코드 단위로 한 개의 회차에만 분류합니다. 5개 회차 카드의 합은 범위 내 전체 참여 수입니다. 현재 회차는 등록값이므로 역사적 가입·갱신 거래 횟수와 다릅니다. 조회 전용이며 대상이 없으면 0개소입니다.
