# 보고문 복사

보고 탭 상단 버튼으로 현재 집계를 클립보드에 복사합니다. 성공 또는 권한 실패 알림을 표시하며 외부 전송이나 파일 저장은 하지 않습니다.

내용은 제목, 사업 타입, 선택 기간의 만료 대상·갱신·이탈·재가입, 오늘 기준 만료 후 결과 미등록, 만료 예정 총계(오늘 만료 포함), 예정의 연도·월·사업별 수입니다. 예정이 없으면 ‘없음’이 들어갑니다.

기간 실적에는 선택 연도·종료월을 적용하지만 오늘 기준 미등록·예정은 기간과 무관합니다. 사업 타입은 모두에 적용합니다. 갱신률·만료일 미입력·최근 처리 목록·농가명 목록·현재 회차 KPI는 보고문에 넣지 않습니다.
