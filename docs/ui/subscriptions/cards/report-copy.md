# 보고문 복사

현재 집계를 클립보드에 복사합니다. 성공 또는 권한 실패 알림을 표시하며 외부 전송이나 파일 저장은 하지 않습니다.

제목·사업 타입·선택 기간 도래 대상·갱신·이탈·재가입, 첫·반복·전체 갱신율과 각각의 분자·분모, 결과 미확인·충돌과 잠정 표시, 회차 미확인, 선택 기간 만료 예정의 분모 제외 안내, 집계 기준을 포함합니다.

추가로 오늘 이전 만료 후 미등록과 내일부터 만료되는 현재 사용중 전체 예정 총계·연도·월·사업별 수를 포함합니다. 이 운영 현황은 보고 기간과 무관합니다. 농가명 목록·현재 회차 구성·입금 내역은 복사하지 않습니다.
