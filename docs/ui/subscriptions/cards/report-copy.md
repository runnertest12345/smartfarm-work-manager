# 연간 보고문 복사

기준 연도 ‘전체 연도’에서는 [입금연도별 갱신 차수](../payment-years.md) 보고문을 복사합니다. 개별 연도일 때만 아래 만료 보고문을 사용합니다.

선택 연도1~12월 전체 대상·만료 경과·갱신·미갱신·기록 확인, 첫·반복·전체 갱신율의 분자/분모, 재가입과 오늘/미래 예정 제외 기준을 복사합니다.

월별1~12월 행과 각 실적도 포함합니다. 추가로 전체 연도의 현재 미갱신·내일부터 사용중 만료 예정 및 연도·월·사업별 예정 목록을 포함합니다. 클립보드 복사만 하며 외부 전송은 하지 않습니다.
