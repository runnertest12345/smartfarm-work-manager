# 첫 갱신율

해당 만료 회차 이전 갱신 횟수가 0인 집단의 갱신 완료 / 만료 도래 대상 × 100입니다. 등록된 현재 계약의 개수나 최초 입금 농가 수와는 다른 성과 지표입니다.

기간·오늘 상한·잠정 표시·0%와 - 기준은 [전체 갱신율](report-renewal-rate.md)과 같습니다. 과거 회차의 현재 횟수 역산은 금지하며 근거가 없으면 회차 미확인으로 남깁니다. 클릭하면 집계표가 첫 갱신 집단으로 바뀝니다.
