# 이탈 확정

선택 기간 중 오늘까지 도래한 회차에서 오늘까지 처리된 이탈 확정 건입니다. 날짜가 지났다는 이유로 이탈을 만들지 않습니다. 미처리는 결과 미확인이고 상충 결과는 충돌로 분리합니다.

회차 키는 `farmRecordId:basisExpiryDate`이며 중복은 한 번 셉니다. 미래 만료·미래 처리일은 현재 확정 실적에서 제외합니다. 재가입은 과거 이탈을 갱신으로 바꾸지 않습니다.
