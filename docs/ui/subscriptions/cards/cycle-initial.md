# 입금 기록 없음

갱신일: 2026-09-07 · 입금 기준 차수

확인된 양수 구독 입금이 0건인 참여 수입니다. 실제 미입금을 확정하는 수가 아니며, 수기 입금일이나 갱신 횟수만으로 입금을 인정하지 않습니다.

농가·사업 참여별 양수 입금 업무 이력을 사용합니다. 중복 ID, 0원, 음수, 미래 이력, 다른 업무 유형은 제외합니다. 화면 이력이 늦게 도착할 때는 서버가 확인해 저장한 입금 횟수도 사용합니다. 수기 `renewalCount`는 분류 근거가 아닙니다.

관리 탭은 사업 타입·개별 사업, 보고 탭은 사업 타입 범위입니다. 현재 현황이므로 보고 연도·검색·상태 필터와는 별개이며 만료 참여도 포함합니다. 0·1·2·3건 이상 네 카드 합은 범위 내 전체 참여 수입니다. 각 참여는 한 카드에만 포함됩니다.
