# 만료 예정 KPI

오늘 사용중이며 현재 만료일이 오늘보다 큰 참여 수입니다. 내일부터 만료되는 구독이며 오늘 만료·날짜 미입력·이미 만료된 구독은 제외합니다. 오늘까지 유효한 사용중 판정과 이 예정 상한은 별개입니다.

보고 탭의 오늘 기준 운영 현황에 표시하며 사업 타입만 적용하고 보고 기간으로 제한하지 않습니다. 기준일은 브라우저 현지 날짜입니다. 조회 전용이고 빈 값은 0개소입니다. 선택 기간 성과표의 예정 수와 범위가 다릅니다.
