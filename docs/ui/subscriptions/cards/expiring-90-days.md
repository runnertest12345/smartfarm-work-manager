# 90일 이내 만료

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

곧 만료되어 확인할 유효 구독 규모를 파악합니다.

## 표시값·계산식

현재 유효한 사용중 구독 중 현재 만료일까지 남은 날짜가 0~90일(양 끝 포함)인 레코드 수입니다. 이미 만료되었거나 만료일이 없는 레코드는 제외합니다. 대상이 없으면 0곳입니다.

## 클릭·버튼

조회 전용이며 누르면 목록이 좁혀지는 동작은 없습니다.

## 필터 적용 범위

관리 탭의 ‘개별 사업’만 적용합니다. 검색어·구독 상태·현재 페이지는 이 카드에 적용하지 않습니다. 보고 탭의 연도·종료월·사업 타입도 적용하지 않습니다.
