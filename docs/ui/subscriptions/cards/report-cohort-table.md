# 회차별 갱신 집계표와 대상 상세

구독 구분은 전체·첫 갱신·반복 갱신·회차 미확인입니다. 묶어 보기는 연도·월·사업 타입·사업이며 보고 필터 안에서 집계합니다.

열은 구분 / 만료 도래 대상 / 갱신 완료 / 이탈 확정 / 결과 미확인 / 결과 충돌 / 갱신율 / 만료 예정 / 상세입니다. 대상은 오늘까지, 예정은 내일부터입니다. 개소는 농가×사업×만료 회차 단위입니다.

회차 미확인 갱신은 전체에는 포함하고 첫·반복에는 넣지 않습니다. 미확인·충돌이 있는 비율은 잠정입니다. 사업 귀속 충돌은 전체 조회의 사업 미확인 그룹에 남습니다. 날짜·연결 오류는 제외 건수를 안내합니다.

‘대상 보기’에서 농가명·사업·기준 만료일·회차·결과를 확인합니다. 농가명은 사업 맥락을 유지한 상세로 연결하며 미처리 결과 등록은 해당 기준 만료일로 창을 엽니다. 이미 미래 처리 기록이 있는 회차는 날짜를 안내하고 중복 등록은 제공하지 않습니다. 그룹 12개, 상세 10개 단위 페이지이며 합계는 전체 필터 결과입니다.
