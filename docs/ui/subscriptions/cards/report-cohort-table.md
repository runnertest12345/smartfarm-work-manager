# 연간 월별 만료 농가 표

연간 제목 바로 아래에 선택 연도 1~12월의 12행을 먼저 보여주며 빈 월도 0건으로 표시합니다. 갱신율 카드는 표 아래에 배치합니다. 연도·사업 타입·사업별 묶음도 제공합니다. 구독 구분은 전체·1차 갱신·반복 갱신(2차 이상)·과거 입금 연결 필요입니다.

첫 행은 ‘26년 총계’처럼 선택 연도의 총계이며 표 아래 합계 행은 없습니다. 열: 구분 / 만료 농가 / 만료 경과 / 갱신 완료 / 미갱신 / 갱신율 / 만료 예정 / 농가. 만료 예정에는 오늘 만료도 포함하며 갱신율에서는 제외합니다.

‘농가 보기’를 누르면 해당 행 바로 아래에 이름·사업·만료일·실제 입금 건수·해당 입금 차수·결과가 펼쳐지고 버튼이 ‘농가 접기’로 바뀝니다. 다시 누르면 상세 행을 제거합니다. 한 번에 한 그룹을 펼칩니다. 다른 월·필터로 바꾸면 상세 페이지를 초기화합니다. 농가 상세와 미처리 결과 등록으로 연결하며 이미 미래 처리 기록이 있는 건은 중복 등록을 제공하지 않습니다. 빈 월의 상세 버튼은 비활성화합니다. 그룹 12개·상세 10개 단위입니다.
