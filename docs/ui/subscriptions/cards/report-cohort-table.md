# 연간 월별 만료 농가 표

연간 제목 바로 아래에 선택 연도 1~12월의 12행을 먼저 보여주며 빈 월도 0건으로 표시합니다. 갱신율 카드는 표 아래에 배치합니다. 연도·사업 타입·사업별 묶음도 제공합니다. 구독 구분은 전체·1차 갱신·반복 갱신(2차 이상)·과거 입금 연결 필요입니다.

열: 구분 / 만료 농가 / 만료 경과 / 갱신 완료 / 미갱신 / 기록 확인 / 갱신율 / 오늘 만료 / 만료 예정 / 농가.

‘농가 보기’에서 이름·사업·만료일·실제 입금 건수·해당 입금 회차·결과를 확인합니다. 입금은 있지만 과거 만료 건과 연결되지 않은 상태를 입금 없음으로 표시하지 않습니다. 농가 상세와 미처리 결과 등록으로 연결하며 이미 미래 처리 기록이 있는 건은 중복 등록을 제공하지 않습니다. 빈 월의 상세 버튼은 비활성화합니다. 그룹12개·상세10개 단위입니다.
