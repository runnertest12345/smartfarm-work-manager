# 사업별 설치 진행

작성일: 2026-09-07 · 기준 커밋: `141faaa` · 현재 구현 설명

## 목적

사업마다 설치 과정과 현재 운영 현황을 비교합니다.

## 표시값·계산식

열은 사업(이름·연도·유형), 참여, 제작, 설치, 시운전, 교육, 유효 구독, 구축·운영 평균입니다. 제작은 `productionSetupDate` 입력 건수입니다. 설치·시운전·교육은 각 날짜 입력 건수와 참여 대비 비율, 유효 구독은 오늘 유효한 건수와 비율입니다.

‘구축·운영 평균’은 설치율·시운전율·교육률·유효 구독률 중 null이 아닌 비율의 산술평균을 반올림합니다. 유효 비율이 없으면 0%입니다. 제작율·서류·정산·목표 농가율은 이 평균에 포함하지 않습니다. 프로젝트 상세의 증빙기반 진행률과 다른 계산입니다.

## 클릭·버튼

행이나 사업명에 상세 이동 클릭 동작은 없습니다.

## 필터 적용 범위

사업 집계의 사업연도와 사업 유형을 모두 적용합니다. 프로젝트 관리 및 구독 화면의 검색·필터는 적용하지 않습니다.
