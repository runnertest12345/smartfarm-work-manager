# 업무 전체 상세

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 보드·목록·관제·주간 검토·A/S·농가 업무·프로젝트 하위 업무에서 선택한 업무를 연다. 선택 농가와 업무의 농가 ID가 일치할 때 본문을 표시한다. 검색 필터가 아니라 선택한 업무 ID로 이력·방문·체크리스트·막힘을 조회한다.

상단에는 농가 정보와 ‘이전 화면’, 업무 헤더에는 유형·상태·사업·우선순위·제목·담당자·기한·선택적 설명이 있다. ‘진행 기록 추가’는 [진행 기록 폼](../forms/history.md)을 연다. 기존 이력 자체의 수정/삭제 버튼은 없다.

| 카드/영역                                    | 표시 조건 및 동작                         |
| -------------------------------------------- | ----------------------------------------- |
| [완료 기준](cards/expected-outcome.md)       | 항상 표시                                 |
| [다음 행동](cards/next-action.md)            | 항상 표시, 미완료에는 다시 볼 날짜        |
| [최초 대응 관리](cards/response-detail.md)   | 목표시각이 있을 때                        |
| [진행 차단 요인](cards/blocker-detail.md)    | 현재 대기일 때                            |
| [막힘 이력](cards/blocker-episode.md)        | 이력이 1건 이상일 때                      |
| [현장 방문](cards/visit-detail.md)           | 항상 표시, 미완료 업무만 추가 가능        |
| [현장 체크리스트](cards/checklist.md)        | 항목이 1개 이상일 때, 확인자 입력 후 토글 |
| [전체 진행 히스토리](cards/history-entry.md) | 선택 업무의 전체 이력                     |

방문이 없으면 일정 등록 안내, 완료 기준/다음 행동이 없으면 입력 안내를 표시한다. 체크리스트와 막힘 이력은 비어 있으면 영역을 숨긴다. 히스토리는 별도 빈 안내가 없다. 완료 업무의 방문과 체크리스트는 잠겨 있으며 다시 열기는 진행 기록 폼과 사업 상태 제약을 따른다. 뒤로 가기는 이전 상세 또는 원래 목록과 스크롤을 복원한다.
