# 업무 현황

기준 커밋: `141faaa` · 작성일: 2026-09-07

수신부터 업무 전환, 진행·대기, 현장 방문, 완료까지 관리하는 화면이다. 메뉴에서 업무 현황을 선택하면 `view='work'`로 진입하며 초기 하위 모드는 업무 보드이다. 상단 ‘빠른 수신’은 [수신 폼](../forms/inbox.md)을 연다.

| 하위 화면                 | 목적                       | 탭 배지                                   |
| ------------------------- | -------------------------- | ----------------------------------------- |
| [수신함](inbox.md)        | 원문 수집·분류             | 정리 전 항목 수                           |
| [서비스 관제](control.md) | 대응 목표·막힘·방문 확인   | 응답 목표 초과와 대기 업무 ID의 합집합 수 |
| [업무 보드](board.md)     | 상태별 업무 흐름           | 없음                                      |
| [목록](list.md)           | 표로 검색·비교             | 없음                                      |
| [주간 검토](review.md)    | 놓친 다음 행동과 약속 점검 | 검토 대상 중복 제거 수                    |

배지는 0이면 숨긴다. 업무 검색·유형·상태 조건은 보드/목록의 업무에만 적용된다. KPI, 수신함, 관제, 검토는 전체 작업공간 기준이며 농가 관리대장·사업의 필터와 별개다. 보드 탭을 누르면 상태 필터만 ‘전체’로 초기화하고 검색·유형은 유지한다.

업무 카드를 누르면 [업무 전체 상세](detail.md)를 연다. 리스트와 상세를 오갈 때 선택 경로와 스크롤 위치를 보관한다. 하위모드별 빈 상태는 각 문서를 참조한다.
