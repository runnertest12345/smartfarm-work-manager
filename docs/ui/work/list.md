# 업무 목록

기준 커밋: `141faaa` · 작성일: 2026-09-07

[업무 현황](README.md) → ‘목록’. 상단의 전체 기준 KPI 3개는 [보드](board.md)와 공유한다. 검색·업무 유형에 상태 필터를 추가해 `filteredWorkItems`를 표로 표시한다. 완료 업무의 최근 7일 제한과 페이지 나누기는 없다.

표 열은 업무·농가(제목/농가/다음 행동), 사업, 마지막 받은 내용, 마지막 처리 내용, 담당자, 처리 기한(상대 배지+날짜), 상태(상태/우선순위/체크 완료 수)이다. 받은 내용과 처리 내용은 해당 필드가 비어 있지 않은 최신 이력을 각각 찾아 서로 다른 이력이 선택될 수 있다.

제목/농가 버튼으로 업무 상세를 연다. 검색 범위와 정렬은 [보드](board.md)와 같다. 비어 있는 다음 행동은 ‘미지정’, 수신/처리는 ‘받은 내용 없음’/‘처리 내용 없음’, 담당자는 ‘미지정’으로 표시한다. 결과가 없으면 7열에 걸쳐 ‘조건에 맞는 업무가 없습니다’를 표시한다.
