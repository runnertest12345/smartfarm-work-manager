# 수신함

기준 커밋: `141faaa` · 작성일: 2026-09-07

[업무 현황](README.md)의 ‘수신함’ 탭. 농가·사업을 확정하기 전 연락 원문을 모으고 분류한다. 모든 수신 항목을 상태별로 나누며 업무 검색 필터는 적용하지 않는다.

- 정리 전: [수신 카드](cards/inbox-item.md) 전체 표시. ‘업무로 정리’ → [농가·사업 연결](../forms/inbox-route.md) → [업무 등록](../forms/work-item.md). ‘참고 보관’과 ‘처리 제외’는 즉시 상태 저장한다.
- 참고 보관: [접이식 보관 목록](cards/inbox-reference.md). 원문·시각·전달자·참고 링크를 조회한다.
- 업무 전환 완료: [연결 업무 목록](cards/inbox-converted.md). 연결 업무 상세로 이동한다.
- 처리 제외: 건수만 표시하고 카드 본문은 표시하지 않는다. 삭제가 아니다. 이 화면에 복원·재분류 버튼은 없다.

정리 전 항목이 없으면 ‘정리할 수신 내용이 없습니다’와 빠른 수신 안내를 표시한다. 보관/전환 목록은 해당 상태가 1건 이상일 때만 나타난다. 참고·제외 상태 변경과 전환은 정리 전 항목에만 허용된다.
