# 서비스 관제

기준 커밋: `141faaa` · 작성일: 2026-09-07

[업무 현황](README.md) → ‘서비스 관제’. 모든 유형의 업무를 대상으로 최초 대응, 대기, 방문 위험을 확인한다. A/S 유형 전용 화면과는 범위가 다르다. 검색·업무 유형·상태·사업 필터를 적용하지 않는다.

| 영역                | 표시 범위                              | 카드 문서                          |
| ------------------- | -------------------------------------- | ---------------------------------- |
| 응답 목표 초과      | 최초 대응 전 미완료 중 목표시각 경과   | [지표](cards/response-breached.md) |
| 72시간 이내 대응    | 목표까지 0~72시간 남은 미응답 미완료   | [지표](cards/response-soon.md)     |
| 막힘·대기           | waiting 상태 전체                      | [지표](cards/blocked-count.md)     |
| 오늘 현장 방문      | 오늘 예정 방문                         | [지표](cards/today-visits.md)      |
| 서비스 목표 큐      | 미응답 목표 업무 8건, 목표 미설정 5건  | [큐](cards/response-queue.md)      |
| 막힘·대기 큐        | 오래 막힌 순 8건                       | [큐](cards/blocked-queue.md)       |
| 현장 방문 일정      | 지난 미완료와 오늘부터 7일 뒤까지 10건 | [일정](cards/visit-queue.md)       |
| 담당자 업무 신호    | 담당자별 미완료 집계 상위 10명         | [담당자](cards/owner-load.md)      |
| 사업 자동 위험 신호 | 진행 중 사업 전체                      | [사업](cards/project-health.md)    |

큐의 숫자 배지는 제한 전 전체 건수다. 업무·방문 카드는 업무 상세로 이동하지만 담당자·사업 신호 행과 지표는 클릭 동작이 없다. 대응 위험 계산용 현재 시각은 60초마다 갱신한다. 각 큐에는 개별 빈 상태가 있으며 담당자·사업 영역은 비어도 별도 안내가 없다.
