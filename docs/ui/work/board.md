# 업무 보드

갱신일: 2026-09-15. [업무 계층·빠른 수정](task-hierarchy.md)의 보드 동작을 확장한다.

[업무 현황](README.md)의 기본 모드. **최상위 업무당 카드 한 장**을 접수·처리 중·대기/막힘·완료의 4열에 표시한다. 세부 업무와 손자 업무는 부모 카드 안의 간결한 목록으로 표시하며 별도 카드로 중복 표시하지 않는다. 자식 없는 기존 농가 업무는 독립 카드로 유지한다.

## 카드에 표시하는 내용

카드에는 기본 요약을 표시하고 하위 업무 목록은 모두 접힌 상태로 시작한다. **하위 업무 N개** 헤더를 누르면 해당 카드 목록만 펼치거나 다시 접는다. 새로 도착한 카드도 접힌 상태이며, 직접 펼친 카드의 선택은 같은 보드 안에서 열 이동·실시간 갱신·검색 조건 변경 후에도 유지한다. 보드를 새로 열거나 페이지를 새로고침하면 다시 모두 접힌다. 완료율·막힘 요약은 접혀 있어도 유지한다. 업무명을 누르면 화면 중앙의 넓은 팝업이 열린다. 카드 안에 긴 이력이나 여러 수정 버튼은 반복하지 않는다.

- 프로젝트·농가 또는 내부 부서 문맥, 상위 업무명, 이동 손잡이, 담당자·기한.
- 하위 실행 업무의 완료 건수/전체 건수와 완료율. 실행 업무는 더 작은 자식이 없는 최하위 업무이며 중간 부모를 중복 집계하지 않는다. 연결 누락 시 완료율을 확정하지 않는다.
- 하위 대기·막힘 건수와 상위 업무의 실제 상태를 구분해 표시한다. 열 위치는 저장된 상위 상태와 다를 수 있다.
- 최우선 지시, 최종 완료 확인 필요, 연결 확인 필요, 검색된 하위 업무 수는 해당할 때만 표시한다.
- 카드 아래 하위 업무명·상태를 부모→자식 순서로 표시한다. 한 단계마다 16px 들여쓰고 형제는 같은 위치에 정렬한다. 들여쓰기는 최대 64px로 제한하며 깊은 업무에는 실제 단계와 바로 위 상위 업무명을 표시한다. 대기·막힘 업무의 사유와 확인 대상은 노란색 영역에 표시하며, 비어 있으면 미입력·미지정을 안내한다. 대기 업무를 부모보다 앞으로 옮겨 계층을 끊지 않는다.
- 목록을 접어도 상단 대기·막힘 건수와 막힌 업무명 최대 2개·나머지 개수는 유지한다. 접기·펼치기는 조회 상태만 바꾸며 업무 팝업을 열거나 카드를 이동·저장하지 않는다. 마우스와 키보드로 조작할 수 있고 숨긴 하위 업무는 탭 이동 대상에서 제외한다.
- 하위 목록의 높이는 256px로 제한하고 목록 안에서 스크롤한다. 개수가 많다는 이유로 조회된 하위 업무를 생략하지 않는다. 하위 업무명을 누르면 해당 업무의 전체 팝업을 바로 열며, 이 클릭으로 상위 카드를 이동하거나 상태를 저장하지 않는다.

최근 수신·처리 이력, 긴 대기 사유의 전문, 다음 행동, 전체 계층은 팝업에서 확인한다. 팝업 상단에는 처리 기록·상태 변경과 세부 업무 등록 버튼을 제공한다. 팝업 안의 하위 업무명은 해당 하위 상세를 열며 이전 상세로 돌아올 수 있다. 본문만 스크롤하고 제목·닫기 버튼은 고정한다. 닫으면 보드의 조회 조건과 스크롤 위치를 유지한다.

## 자동 배치와 최종 완료

| 업무 상태 | 카드 위치 |
| --- | --- |
| 하위·손자·중간 부모 중 하나라도 대기 | 대기/막힘 우선 표시 |
| 하위 대기가 없고 상위가 접수·처리 중·대기 | 상위 업무의 저장된 상태 |
| 하위 업무 모두 완료, 상위 확인 전 | 상위가 선택한 열 유지 · 상세에서 최종 확인 안내 |
| 상위 업무까지 최종 완료 확인 | 완료 |
| 연결 누락·순환·모순된 완료 기록 | 확인 필요. 완료율 확정 및 완료 표시 제한 |

하위 대기의 우선 표시는 저장된 부모 상태·대기 사유·이력을 자동으로 덮어쓰지 않는다. 하위의 대기가 모두 해제되면 상위가 마지막으로 직접 선택한 상태의 열에 돌아간다. 모두 완료하면 전체 팝업의 ‘처리 기록·상태 변경’에서 상위 완료를 적용하거나, 완료 열로 드롭한 뒤 열리는 확인 창에서 확정한다. 손자 실행 업무가 끝나도 중간 부모의 확인이 남으면 중간 부모부터 완료해야 한다. 실제 저장 시 기존 미완료 자식·체크리스트·예정 방문·동시 수정 검증을 유지한다.

## 확인과 수정

- 업무명을 한 번 누르면 전체 상세 팝업을 연다. 독립 업무·내부 업무·프로젝트 하위 업무에 같은 진입 방식을 사용한다.
- 팝업 안의 하위 업무 상태·담당자·기한과 ‘빠른 수정’은 선택한 한 업무의 편집창을 연다. 상태·처리 내용을 확인하고 적용하면 닫힌다. 대기 진입 시 사유·확인 대상, 대기 해제 시 처리 내용을 받는다.
- 상세 상단 ‘세부 업무 등록’으로 바로 아래 업무를 추가한다. 하위 목록의 더보기에서도 다음 단계 등록을 제공한다. 깊은 단계는 상위 업무명과 단계 표시를 유지하며 들여쓰기 너비를 제한한다.
- 카드의 제목·여백 또는 손잡이를 잡아 원하는 상태 열에 드롭한다. 상위 카드는 **상위 업무 하나만** 변경한다. 하위·형제 업무의 상태를 일괄 변경하지 않는다. 세부 업무 선택창은 열지 않는다.
- 이동 대상의 실제 저장 상태와 같은 상태로 드롭하면 저장하지 않는다. 하위 대기로 인해 표시 열이 다를 수 있으므로 열 위치만으로 같은 상태인지 판단하지 않는다. 하위 대기가 남아 있으면 상위 상태 변경 후에도 대기·막힘 열을 유지하며 이유를 알린다. 이동 대상 자신의 대기 진입·해제는 기존 사유·처리 내용 입력창을 거친다.
- 미완료 하위 업무가 있으면 상위 카드의 완료 이동을 막고 안내하며 어떤 상태도 변경하지 않는다. 모두 완료된 세부 업무의 상위 카드를 완료 열에 옮겨도 최종 완료 확인을 거친다. 완료된 상위 카드를 다른 열에 옮기면 선택한 상태로 다시 여는 수정창이 열린다. 연결 누락·실시간 변경·삭제는 안내 후 이동을 중단한다. 중간 부모의 상태는 팝업의 하위 목록에서 변경한다. 드래그 직후 클릭으로 업무 상세가 중복해서 열리지 않는다.
- 팝업은 이동하는 열 밖에 유지하고 배경 화면을 스크롤시키지 않는다. 열이 바뀌거나 저장에 실패해도 초안을 보존한다. 바깥 클릭은 닫지 않으며, 변경 후 취소·닫기·Esc를 누르면 초안 취소 여부를 확인한다. 저장·이미지 처리 중에는 닫을 수 없다. 팝업이 열려 있으면 기존 뒤로가기 보호를 적용하고 닫을 때 시작 버튼으로 초점을 돌린다.
- 완료된 부모 아래에서 상태 재개는 막되, 완료 상태를 유지한 후속 처리 내용·캡처 추가는 허용한다.

## 검색과 집계

보드·목록 상단의 업무 구분에서 **내부 업무 / 프로젝트 업무 / 농가 업무**를 각각 선택한다. ‘전체 업무’는 세 구분을 함께 보는 필터다. 내부 업무는 내부 부서에 연결된 업무, 프로젝트 업무는 특정 농가 없이 프로젝트에 직접 연결된 업무, 농가 업무는 농가의 사업 참여 내역에 연결된 업무다. 프로젝트 ID가 있는 농가 업무도 프로젝트 업무에 중복 포함하지 않는다. 기존 데이터의 구분 필드를 일괄 수정하지 않는다.

검색·업무 유형·KPI에서 넘어온 범위에 일치하는 구성원이 하나라도 있으면 상위 묶음 전체를 표시한다. 카드에는 일치한 하위 업무 수를 알리고, 제목으로 전체 상세를 연다. 검색을 이유로 긴 카드가 자동으로 펼쳐지지 않는다. 부모만 일치해도 자손 전체 상태는 유지하며 무관한 다른 묶음은 제외한다. 가장 긴급한 일치 업무 순서로 카드를 정렬한다. 목록 전용 상태 필터는 보드에 적용하지 않는다.

각 열 숫자는 **표시 카드 수**이며 세부 업무 수와 다르다. 완료 카드의 임의 최근 7일 제한이나 5개 제한은 없다. 상단 미완료·기한 KPI는 선택한 업무 구분과 담당 범위의 최하위 실행 업무를 집계한다. 검색·업무 유형·목록 상태 조건은 KPI가 아닌 목록에만 적용한다. 구독 입금·이관 교체 이력의 제외 정책은 유지한다. 좁은 화면은 열을 가로 스크롤한다.
