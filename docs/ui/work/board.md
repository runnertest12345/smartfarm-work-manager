# 업무 보드

기준 커밋: `141faaa` · 작성일: 2026-09-07

[업무 현황](README.md)의 기본 모드. 접수·처리 중·대기/막힘·완료의 4열에 [공통 업무 카드](cards/work-item.md)를 배치한다. 드래그 이동이나 열에서 바로 상태를 바꾸는 동작은 없으며 업무 상세의 진행 기록으로 상태를 갱신한다.

상단 [미완료](cards/open-count.md), [마감 지연](cards/overdue-count.md), [7일 이내 마감](cards/due-soon-count.md)은 전체 업무 집계다. 검색과 유형 조건은 열에 표시되는 업무에만 적용한다. 검색은 제목·담당자·설명·완료 기준·다음 행동·막힘 사유/주체·농가명·사업명·이력의 전달자/수신/처리 내용에 포함 검색한다. 미완료 기한 오름차순, 그 다음 최근 활동 내림차순이다. 기한 없음과 완료는 정렬상 뒤로 간다.

완료 열은 `status='completed' && lastActivityAt >= 오늘 0시-7일`이다. 열 설명은 ‘최근 7일 내 완료’지만 실제 필드는 최종 활동 시각이다. 주간 검토의 최근 완료 배지는 완료 시각을 사용하므로 수가 다를 수 있다.

처리 중 열 배지는 검색 결과 수가 아니라 전체 처리 중+대기 수 / 5다. 5건을 초과하면 안내를 표시하지만 저장을 막지는 않는다. 다른 열 배지는 해당 열 표시 건수다. 각 열이 비면 ‘업무 없음’을 표시한다. 좁은 화면은 가로 스크롤한다.
