# 업무 보드

갱신일: 2026-09-09. [업무 계층·빠른 수정](task-hierarchy.md)의 보드 동작을 확장한다.

[업무 현황](README.md)의 기본 모드. **최상위 업무당 카드 한 장**을 접수·처리 중·대기/막힘·완료의 4열에 표시한다. 세부 업무와 손자 업무는 같은 카드 안에만 표시하며 별도 카드로 중복 표시하지 않는다. 자식 없는 기존 농가 업무는 독립 카드로 유지한다.

## 카드에 표시하는 내용

- 프로젝트·농가 문맥, 상위 업무명, 총괄 담당자, 마감일.
- 세부 실행 업무의 접수·처리 중·대기·완료 개수와 완료 건수 비율. 실행 업무는 더 작은 자식이 없는 최하위 업무이며 중간 부모를 중복 집계하지 않는다.
- 현재 처리 중인 실행 업무명·담당자, 대기 업무의 사유·확인 대상·담당자·확인 예정일. 확인일이 없으면 미지정으로 표시한다.
- 최근 수신·처리 내용과 다음 행동. 세부 업무의 기록은 ‘처리 내용 함께 보기’로 펼친다.

## 자동 배치와 최종 완료

| 세부 업무 상태                    | 카드 위치                                |
| --------------------------------- | ---------------------------------------- |
| 처리 중인 실행 업무가 있음        | 처리 중. 대기 사유도 함께 강조           |
| 남은 실행 업무가 모두 대기        | 대기/막힘                                |
| 실행 업무 모두 완료, 상위 확인 전 | 처리 중 · 최종 확인 필요                 |
| 상위 업무까지 최종 완료 확인      | 완료                                     |
| 처리 중이 없고 시작할 업무가 남음 | 접수                                     |
| 연결 누락·순환·모순된 완료 기록   | 확인 필요. 완료율 확정 및 완료 표시 제한 |

카드 위치는 조회용 집계이며 저장된 부모 상태를 자동으로 덮어쓰지 않는다. 모두 완료하면 ‘상위 업무 완료 확인’으로 해당 업무의 빠른 수정창을 열고 **적용**하여 확정한다. 손자 실행 업무가 끝나도 중간 부모의 확인이 남으면 중간 부모부터 완료해야 한다. 실제 저장 시 기존 미완료 자식·체크리스트·예정 방문·동시 수정 검증을 유지한다.

## 확인과 수정

- ‘세부 업무 펼치기/접기’는 같은 카드 아래의 목록만 열고 닫는다. 세부 업무명은 해당 업무 상세로 이동한다.
- 세부 업무의 상태 선택과 ‘빠른 수정’은 선택한 한 업무의 수정창을 연다. 상태·처리 내용을 확인하고 적용한다. 대기 진입 시 사유·확인 대상, 대기 해제 시 처리 내용을 받는다.
- 각 세부 업무의 ‘세부 업무’ 버튼으로 손자 업무를 추가할 수 있다. 깊은 단계는 상위 업무명과 단계 표시를 유지하며 들여쓰기 너비를 제한한다.
- 손잡이는 자식 없는 개별 실행 업무에만 표시한다. 드롭하면 해당 한 업무만 변경하며 자손 일괄 변경은 하지 않는다. 부모 묶음은 세부 상태에 따라 자동 배치되므로 직접 드래그하지 않는다.
- 편집기는 이동하는 열 밖에 유지하고 열이 바뀌어도 초안을 보존한다. 완료된 부모 아래에서 상태 재개는 막되, 완료 상태를 유지한 후속 처리 내용·캡처 추가는 허용한다.

## 검색과 집계

검색·업무 유형·KPI에서 넘어온 범위에 일치하는 구성원이 하나라도 있으면 상위 묶음 전체를 표시한다. 일치하는 세부 업무는 강조하고 펼친다. 부모만 일치해도 자손 전체 상태는 유지하며 무관한 다른 묶음은 제외한다. 가장 긴급한 일치 업무 순서로 카드를 정렬한다. 목록 전용 상태 필터는 보드에 적용하지 않는다.

각 열 숫자는 **표시 카드 수**이며 세부 업무 수와 다르다. 완료 카드의 임의 최근 7일 제한이나 5개 제한은 없다. 상단 미완료·기한 KPI의 기존 집계 기준과 구독 입금·이관 교체 이력의 제외 정책은 유지한다. 좁은 화면은 열을 가로 스크롤한다.
