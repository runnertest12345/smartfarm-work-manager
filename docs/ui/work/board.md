# 업무 보드

갱신일: 2026-09-11. [업무 계층·빠른 수정](task-hierarchy.md)의 보드 동작을 확장한다.

[업무 현황](README.md)의 기본 모드. **최상위 업무당 카드 한 장**을 접수·처리 중·대기/막힘·완료의 4열에 표시한다. 세부 업무와 손자 업무는 같은 카드 안에만 표시하며 별도 카드로 중복 표시하지 않는다. 자식 없는 기존 농가 업무는 독립 카드로 유지한다.

## 카드에 표시하는 내용

기본은 접힌 카드이며 **프로젝트명·업무명·이동 손잡이·상세 보기**를 표시한다. 농가 업무는 프로젝트명 옆에 농가명도 표시하고, 내부 업무는 ‘내부 업무 · 부서명’을 표시한다. 상태·총괄·마감일·진행 요약·빠른 수정·세부 업무 추가는 상세 안에 둔다. 상태는 카드가 놓인 열 제목으로 구분한다. 부서장 지시가 남아 있는 묶음은 같은 열에서 먼저 정렬하며 주황색 왼쪽 선을 표시한다. 명시적인 최우선 표시와 사유·최종 완료 확인도 상세 안에서 확인한다.

‘상세 보기’를 누르면 다음 내용이 같은 카드 아래에 펼쳐지고 ‘상세 접기’로 다시 접는다. 독립 업무도 동일하다. 펼침 상태는 업무 ID별로 유지되어 열을 옮겨도 사라지지 않는다.

- 프로젝트·농가 문맥, 상위 업무명, 총괄 담당자, 마감일.
- 세부 실행 업무의 접수·처리 중·대기·완료 개수와 완료 건수 비율. 실행 업무는 더 작은 자식이 없는 최하위 업무이며 중간 부모를 중복 집계하지 않는다.
- 현재 처리 중인 실행 업무명·담당자, 대기 업무의 사유·확인 대상·담당자·확인 예정일. 확인일이 없으면 미지정으로 표시한다.
- 최근 수신·처리 내용과 다음 행동. 세부 업무의 기록은 ‘처리 내용 함께 보기’로 펼친다.

## 자동 배치와 최종 완료

| 세부 업무 상태                    | 카드 위치                                |
| --------------------------------- | ---------------------------------------- |
| 처리 중인 실행 업무가 있음        | 처리 중. 대기 사유도 함께 강조           |
| 남은 실행 업무가 모두 대기        | 대기/막힘                                |
| 실행 업무 모두 완료, 상위 확인 전 | 처리 중 · 최종 확인 필요                 |
| 상위 업무까지 최종 완료 확인      | 완료                                     |
| 처리 중이 없고 시작할 업무가 남음 | 접수                                     |
| 연결 누락·순환·모순된 완료 기록   | 확인 필요. 완료율 확정 및 완료 표시 제한 |

카드 위치는 조회용 집계이며 저장된 부모 상태를 자동으로 덮어쓰지 않는다. 모두 완료하면 ‘상위 업무 완료 확인’으로 해당 업무의 빠른 수정창을 열고 **적용**하여 확정한다. 손자 실행 업무가 끝나도 중간 부모의 확인이 남으면 중간 부모부터 완료해야 한다. 실제 저장 시 기존 미완료 자식·체크리스트·예정 방문·동시 수정 검증을 유지한다.

## 확인과 수정

- ‘상세 보기/접기’는 같은 카드 아래의 처리 이력·대기 사유·세부 업무 목록을 열고 닫는다. 세부 업무명은 해당 업무 상세로 이동한다.
- 세부 업무의 상태 선택과 ‘빠른 수정’은 선택한 한 업무의 **중앙 팝업**을 연다. 상태·처리 내용을 확인하고 적용하면 닫힌다. 대기 진입 시 사유·확인 대상, 대기 해제 시 처리 내용을 받는다.
- 각 세부 업무의 ‘세부 업무’ 버튼으로 손자 업무를 추가할 수 있다. 깊은 단계는 상위 업무명과 단계 표시를 유지하며 들여쓰기 너비를 제한한다.
- 접힌 카드의 제목·여백 또는 손잡이를 잡아 원하는 상태 열에 드롭한다. 자식 없는 실행 업무는 해당 업무만 변경한다. 대기 진입·해제는 사유 입력창을 거친다. 같은 열에 드롭하면 저장하지 않는다.
- 세부 업무가 있는 상위 카드를 드롭하면 **이동할 세부 업무 선택** 창이 열린다. 선택한 한 업무의 빠른 수정창에서 적용하며, 부모·형제를 일괄 변경하지 않는다. 카드 위치는 변경 후 세부 상태에 따라 계산하므로 다른 처리 중 업무가 남으면 처리 중 열을 유지할 수 있다. 선택창 취소는 데이터를 변경하지 않는다.
- 모두 완료된 세부 업무의 상위 카드를 완료 열에 옮겨도 최종 완료 확인을 거친다. 완료된 상위 카드를 옮기려면 먼저 다시 열어야 한다. 연결 누락·실시간 변경·삭제는 안내 후 이동을 중단한다. 중간 부모의 손잡이는 숨기고 상태 선택을 유지한다. 드래그 직후 클릭으로 업무 상세가 중복해서 열리지 않는다.
- 팝업은 이동하는 열 밖에 유지하고 배경 화면을 스크롤시키지 않는다. 열이 바뀌거나 저장에 실패해도 초안을 보존한다. 바깥 클릭은 닫지 않으며, 변경 후 취소·닫기·Esc를 누르면 초안 취소 여부를 확인한다. 저장·이미지 처리 중에는 닫을 수 없다. 팝업이 열려 있으면 기존 뒤로가기 보호를 적용하고 닫을 때 시작 버튼으로 초점을 돌린다.
- 완료된 부모 아래에서 상태 재개는 막되, 완료 상태를 유지한 후속 처리 내용·캡처 추가는 허용한다.

## 검색과 집계

보드·목록 상단의 업무 구분에서 **내부 업무 / 프로젝트 업무 / 농가 업무**를 각각 선택한다. ‘전체 업무’는 세 구분을 함께 보는 필터다. 내부 업무는 내부 부서에 연결된 업무, 프로젝트 업무는 특정 농가 없이 프로젝트에 직접 연결된 업무, 농가 업무는 농가의 사업 참여 내역에 연결된 업무다. 프로젝트 ID가 있는 농가 업무도 프로젝트 업무에 중복 포함하지 않는다. 기존 데이터의 구분 필드를 일괄 수정하지 않는다.

검색·업무 유형·KPI에서 넘어온 범위에 일치하는 구성원이 하나라도 있으면 상위 묶음 전체를 표시한다. 접힌 카드에는 일치한 세부 업무 수를 알리고, 상세를 펼치면 일치 업무를 강조한다. 검색 중에도 강제로 펼치거나 접기 버튼을 잠그지 않는다. 부모만 일치해도 자손 전체 상태는 유지하며 무관한 다른 묶음은 제외한다. 가장 긴급한 일치 업무 순서로 카드를 정렬한다. 목록 전용 상태 필터는 보드에 적용하지 않는다.

각 열 숫자는 **표시 카드 수**이며 세부 업무 수와 다르다. 완료 카드의 임의 최근 7일 제한이나 5개 제한은 없다. 상단 미완료·기한 KPI는 선택한 업무 구분과 담당 범위의 최하위 실행 업무를 집계한다. 검색·업무 유형·목록 상태 조건은 KPI가 아닌 목록에만 적용한다. 구독 입금·이관 교체 이력의 제외 정책은 유지한다. 좁은 화면은 열을 가로 스크롤한다.
