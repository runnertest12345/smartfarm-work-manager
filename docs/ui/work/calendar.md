# 업무 달력

## 접근 및 정보 배치

- 업무 현황의 `달력` 보기에서 기존 업무와 방문 정보를 재사용합니다. 별도의 업무 저장소나 중복 일정은 만들지 않습니다.
- 기본은 월요일~일요일 주간 보기입니다. 날짜 제목을 누르면 해당 일간 보기로 전환합니다.
- `월간 · 주간 · 일간`으로 전환할 수 있습니다. 월간은 해당 월 1일이 포함된 월요일부터 고정 6주(42일)를 표시하고, 앞뒤 달의 날짜는 구분해 보여줍니다. 월간 상단 건수는 선택한 달만 집계하며 앞뒤 달 일정은 제외합니다.
- 월간의 이전/다음 이동은 월 단위이며 선택 일자가 다음 달에 없으면 말일로 조정합니다(예: 1월 31일 → 2월 28일, 윤년에는 29일).
- 월간·주간 날짜 칸은 **같은 날짜의 같은 상위 업무**를 한 묶음으로 표시합니다. 상위·하위·세부 업무를 한 줄에 요약하며 처음 3묶음까지만 보여줍니다. 예를 들어 한 상위의 하위 업무 10개는 1묶음, 서로 무관한 업무 10개는 3묶음과 `+7묶음 더보기`로 표시됩니다.
- 묶음을 누르면 그 날짜·묶음의 업무를 큰 중앙 조회 팝업에서 확인합니다. `더보기`는 그 날짜의 전체 묶음을 같은 조회 팝업에 표시합니다. 일간 보기로 강제 전환하지 않으며 담당자·프로젝트·완료 필터와 원래 달력 날짜를 유지합니다.
- 월간 날짜의 `막힘 N` 표시는 3개 미리보기 밖의 대기·막힘도 포함합니다. 같은 업무의 마감과 방문이 겹쳐도 막힘 업무는 한 건으로 집계합니다.
- 주간 묶음은 최소 읽기 폭을 유지합니다. 중간 크기 화면에서는 달력 안에서 좌우로 스크롤하고, 휴대폰에서는 날짜별 세로 목록으로 표시합니다.
- 주간 날짜별 요약은 기존 마감·방문 건수 줄 대신 `처리 중 · 완료 · 막힘` 업무 건수만 표시합니다. 기간 전체의 마감·방문 합계와 개별 일정은 그대로 유지합니다. 상태는 날짜·담당자·프로젝트·완료 포함 조건을 적용한 실제 업무 기준이며, 같은 업무의 마감과 복수 방문은 한 번만 집계합니다. 방문 완료와 업무 완료는 구분하고, 완료 업무 수는 `완료 포함`을 켜면 집계됩니다. 이 요약은 조회용이며 상태를 변경하는 버튼이 아닙니다.
- 월간·주간 묶음은 상위 업무명·업무 수·막힘 건수를 간결하게 표시합니다. 일간 카드의 제목·상위 업무 경로·막힘 사유는 최대 두 줄, 프로젝트·농가 문맥은 한 줄로 요약합니다. 전체 내용은 조회 팝업 또는 기존 상세 팝업에서 확인합니다.
- 일간은 `마감 · 종일` 영역과 예약된 방문의 `시간순` 목록으로 구분합니다.
- 모든 날짜와 시각은 대한민국 `Asia/Seoul` 기준입니다. 마감일은 저장된 날짜 그대로이며, 마감일에 임의의 작업 시간을 부여하지 않습니다.
- 날짜 제목과 접근성 이름은 `9월 23일 (수)`처럼 명시적인 한국식 표기를 사용합니다. 브라우저의 지역화 라이브러리에 따른 `9. 23.` 등 표기 차이가 생기지 않습니다.
- 방문은 `scheduledAt`에 저장된 시각으로 표시합니다. 예정 종료 시각 데이터가 없으므로 30분/1시간 등 작업 길이를 임의 생성하지 않습니다. 실제 작업 시작·종료 기록은 기존 업무 상세에 보관하며 이 달력을 예정 시간 블록으로 오인시키지 않습니다.

## 조회 규칙

- 삭제된 업무, 결제·구독 기록, 기존 `isOperationalWork`가 제외하는 자동 관리대장 기록은 달력에서도 제외합니다. 감사성 기록 판단을 위해 `historyEntries`를 함께 전달합니다.
- 취소된 방문은 항상 제외합니다. 기본은 미완료 업무와 미완료 방문만 표시하며 `완료 포함`을 켜면 완료 항목도 볼 수 있습니다.
- 하나의 업무에 마감과 방문이 모두 있다면 종류를 구분하여 각각 표시합니다. `마감 건수`와 `방문 건수`를 합쳐 업무 수라고 표현하지 않습니다.
- 업무 담당과 방문 담당이 다를 수 있습니다. 담당자 필터는 마감 항목에는 업무 담당자, 방문 항목에는 실제 방문 담당자(미지정일 때 업무 담당자)를 적용합니다.
- 프로젝트는 직접 연결된 `projectId` 또는 농가 참여의 `projectId`로 조회합니다. 내부 업무와 내부 프로젝트도 포함됩니다. 완료/보류 프로젝트의 후속 A/S는 프로젝트 상태만으로 숨기지 않습니다.
- 상위 업무 경로는 필터 적용 전 전체 허용 업무 목록에서 계산합니다. 달력 표시 여부와 무관하게 하위 업무의 소속이 유지됩니다. 순환/누락 링크는 무한 탐색하지 않으며 확인 문구로 표시합니다.
- 조회 팝업은 상위→하위→세부를 들여쓰기로 구분합니다. 필터/날짜에 포함되지 않은 조상은 `상위 참고 · 구조 안내`로만 표시하고 업무·마감·방문·막힘 건수에 더하지 않습니다. 다른 프로젝트·농가 참여·부서 문맥을 가로지르는 잘못된 부모 연결은 합치지 않습니다.
- 한 업무의 같은 날 마감과 방문은 같은 업무 행에 표시하되 마감·방문 일정은 구분합니다. 업무 수와 막힘 수는 업무 ID 기준으로 중복 집계하지 않습니다.
- `기한 지연`과 `일정 미지정`은 기본 접힘입니다. 선택 월/주/일 밖의 항목도 빠짐없이 접근하도록 **전체 기간**에 담당자·프로젝트·완료 조건을 적용합니다. 기한 지연은 완료 항목을 포함하지 않습니다.
- 유효한 마감일과 예약 상태 방문이 모두 없으면 일정 미지정입니다. 취소/완료 방문만 있는 미완료 업무도 미지정에 포함됩니다. 유효하지 않은 저장 날짜를 다른 날짜로 자동 변환하지 않습니다.

## 상호작용 및 범위

- 월간·주간은 묶음 조회 팝업을 먼저 엽니다. 조회 팝업에는 수정 폼이 없으며 업무명을 누르면 **조회 팝업 닫힘 완료 후** 기존 업무 조회·수정 전체 팝업으로 전환합니다. 두 팝업을 동시에 띄우지 않습니다.
- 전환 전에 원래 달력 묶음/더보기 버튼으로 초점을 돌려 기존 상세의 초점 반환 대상을 보존합니다. 닫힘 완료 콜백이 반복되더라도 수정 화면은 한 번만 열며, 선택 후 닫는 동안 삭제된 업무는 열지 않습니다.
- 조회 팝업 상태에는 날짜·묶음 ID만 보관합니다. 내용은 최신 업무와 현재 필터에서 다시 계산하므로 실시간 수정·삭제·날짜 변경이 반영됩니다. 표시할 항목이 없어지면 명시적인 빈 상태를 보여줍니다.
- 일간의 시간순 방문·종일 마감, 전체 기간의 기한 지연·일정 미지정은 기존 업무 상세로 바로 연결합니다.
- 상세 팝업을 연 동안 달력 컴포넌트를 유지하면 보기 방식·날짜·필터·접힘 상태가 유지됩니다.
- 조회 팝업은 임시 읽기 전용 상태로 별도 브라우저 방문기록을 추가하지 않습니다. 뒤로/앞으로 이동 시 조회 팝업을 닫고 기존 앱의 이동 정책을 따릅니다(조회 팝업이 브라우저 뒤로가기 한 단계를 별도로 차지하지 않습니다). 수정 화면의 기존 초안 보호는 변경하지 않습니다.
- 일정 이동/생성, 센서 위치 등록, 외부 캘린더 연동은 이번 범위에 포함하지 않습니다.
- 새 종속 패키지·외부 API·권한 변경·데이터 쓰기 없이 기존 React UI와 순수 날짜 변환으로 동작합니다.
- 지도 초안은 이번 달력 도입에 포함하지 않으며 농가 화면에 미완성 지도 메뉴를 노출하지 않습니다.

## 검증

`node scripts/test-work-calendar.mjs`

`node scripts/test-work-calendar-groups.mjs`

대한민국 자정·월/연도 경계·윤년·월 이동 시 말일 조정, 고정 6주 월간과 주간 시작일, 취소/완료/삭제/감사 기록 제외, 방문 담당 필터, 상위 경로, 종일 마감과 방문 분리, 미지정·지연 조건을 검증합니다. 추가로 동일 상위의 자식 10개 묶기, 독립 10개 중 3묶음 요약과 전체 조회, 상위 참고 제외 집계, 일간 직접 열기, 필터·날짜 유지, 닫힘 완료 후 단일 수정 팝업 전환, 취소·중복 콜백, 실시간 수정·삭제 대응을 검증합니다. UI 단위 테스트의 Dialog는 모형이므로 실제 브라우저의 모달 중첩·초점 이동·애니메이션·뒤로가기는 별도 화면 검증 대상입니다.
