# 현장 방문 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세에서 항상 표시한다. 각 방문의 상태·예정시각·담당자, 선택적 준비 메모·결과·기록자·후속 방문 등록 당시 시각을 표시한다. 완료 방문은 실제 작업 시작/끝, 취소 방문은 결과를 취소 사유로 표시한다. 선택 업무의 방문만 예정시각 내림차순으로 표시하며 필터는 없다.

미완료 업무의 ‘방문 추가’와 예정 방문의 ‘수정’으로 방문 폼을 연다. 완료 업무에서는 추가가 비활성화되고 수정 요청도 거절한다. 완료/취소 방문은 증빙 잠금 배지로 표시한다. 비면 ‘등록된 현장 방문이 없습니다’와 일정 등록 안내를 표시한다.
