# 현장 방문 일정 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

서비스 관제. 예정 상태이며 scheduledAt < 오늘 0시+8일인 방문을 시각 오름차순 최대 10건 표시한다. 하한은 없어 지난 미완료 방문을 모두 후보로 포함한다. 오늘보다 이전 예정이면 ‘방문 지연’ 배지를 붙인다.

업무 제목·농가·방문 담당자·예정시각을 표시하고 클릭하면 업무 상세를 연다. 연결 업무가 없으면 확인 안내를 표시하고 비활성화한다. 업무 필터는 적용하지 않는다. 비면 ‘7일 이내 현장 방문이 없습니다’를 표시한다.
