# 다음 행동 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세. 미완료이면 다음 행동과 다시 볼 날짜를 표시하고 행동이 비어 있으면 미지정 안내를 쓴다. 완료이면 ‘완료된 업무입니다’를 표시하고 검토일은 숨긴다. 진행 기록 저장 시 완료 업무의 nextAction/reviewDate는 빈 값으로 정리된다. 필터·카드 클릭은 없다.
