# 사업 자동 위험 신호 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

서비스 관제. 진행 중(active) 사업만 대상으로 연결 참여정보의 미완료 업무 수와 정상/주의/위험을 표시한다.

- 위험: 하나라도 응답 목표 초과, 높은 우선순위이며 기한 지연, 또는 대기이면서 막힌 기간 5일 이상.
- 주의: 위험이 아니면서 72시간 이내 대응, 기한 지연, 대기가 하나 이상.
- 정상: 위 조건 없음. 업무가 없는 진행 사업도 정상이다.

위험→주의→정상, 같은 등급은 미완료 수 내림차순이다. 공식 사업 상태나 직접 등록한 프로젝트 막힘·서류 상태를 반영하는 판정은 아니다. 필터·행 클릭이 없고 진행 사업이 없으면 별도 빈 안내 없이 제목만 남는다.
