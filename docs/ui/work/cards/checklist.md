# 현장 체크리스트 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세에서 항목이 있을 때만 표시한다. sortOrder 순 항목과 완료 수/전체 수를 보여주고 완료 항목에는 확인자·시각과 취소선을 표시한다. 확인 담당자를 입력한 후 항목 버튼을 눌러 완료/확인 취소를 저장한다. 필터는 없다.

확인 담당자가 비어 있으면 오류 알림을 표시한다. 체크리스트 저장 처리 중이거나 업무가 완료 상태이면 토글을 막는다. 저장은 체크 상태·완료자·완료시각을 변경하고 시스템 히스토리와 업무/참여 활동시각을 갱신한다. 확인 취소 시 완료자·완료시각을 비운다. 항목의 추가/문구 편집/삭제 UI는 없다.
