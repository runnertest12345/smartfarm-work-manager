# 서비스 목표 큐 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

서비스 관제. 미완료·responseDueAt>0·respondedAt=0인 전체 업무를 목표시각 오름차순으로 정렬해 최대 8개 공통 업무 카드로 표시한다. 상단 ‘대기’는 제한 전 전체 수이다. 비면 ‘최초 대응을 기다리는 업무가 없습니다’를 표시한다.

목표 미설정은 미완료·responseDueAt=0이며 하나 이상의 수신 내용 이력이 있는 업무다. 최근 활동 오름차순으로 최대 5개를 별도 안내 안에 표시하며 수가 0이면 하위 영역을 숨긴다. 이 계산은 respondedAt 조건을 검사하지 않는다. 업무 필터는 적용하지 않는다. 각 업무를 누르면 상세로 이동한다.
