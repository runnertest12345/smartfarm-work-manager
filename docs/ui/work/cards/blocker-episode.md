# 막힘 이력 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세에 막힘 이력이 있을 때만 표시한다. 기간별로 해결됨 또는 경과일, 시작~종료/현재, 사유, 해제에 필요한 사람·기관, 예상일과 선택적 해결 결과를 보여준다. 선택 업무의 이력만 사용하며 시작시각 내림차순으로 정렬한다.

카드에서 수정/삭제하지 않는다. 진행 기록의 대기 진입은 이력을 만들고 대기 유지 시 열린 이력을 갱신하며 대기 해제 시 종료시각·해결 내용을 남긴다. 데이터가 없으면 영역을 숨긴다.
