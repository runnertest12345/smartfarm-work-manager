# 진행 차단 요인 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세의 현재 상태가 waiting일 때만 표시한다. 막힌 일수, 사유, 해제 책임자, 예상 해제일을 표시한다. 일수는 현재시각에서 blockedAt을 뺀 24시간 단위 내림이며 0시 기준이 아니다. 시각이 0이면 0일, 사유/주체 누락은 안내문으로 대체한다.

필터나 자체 클릭은 없다. 진행 기록으로 대기 정보를 수정하거나 해제하며 대기 해제 시 해결 내용을 요구한다.
