# 막힘·대기 큐 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

서비스 관제. 모든 waiting 업무를 blockedAt(0이면 updatedAt) 오름차순으로 정렬해 최대 8개 공통 업무 카드로 표시한다. 오래 막힌 원인과 다음 조치를 확인하기 위한 영역이다. 검색·유형·상태 필터는 적용하지 않는다. 카드 클릭은 업무 상세, 비어 있으면 ‘현재 막힌 업무가 없습니다’이다.
