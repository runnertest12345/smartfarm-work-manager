# 전체 진행 히스토리 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세. 선택 업무의 이력을 발생시각 내림차순으로 표시한다. 경로·전달자(있을 때)·발생시각·기록자, 값이 있는 수신 내용/처리 내용, 0보다 큰 금액, 참고 링크를 표시한다. 본문 줄바꿈을 보존한다.

자체 필터나 수정/삭제 버튼은 없다. 참고 링크는 새 탭으로 연다. 값이 없는 내용·금액·링크는 해당 부분만 숨기며 전체 이력이 없을 때 별도 안내는 없다. 진행 기록·방문·체크리스트 및 시스템 감사 기록이 함께 나타날 수 있다.
