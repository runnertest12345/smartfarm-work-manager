# 최초 대응 관리 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

업무 상세에서 responseDueAt>0일 때만 표시한다. 목표시각, 목표 위험/달성/실패 배지, 실제 최초 대응시각 또는 미기록 안내를 보여준다. 응답한 경우 목표 이내이면 달성, 초과이면 실패이다. 미응답은 남은 시간 기준으로 판정한다.

필터·자체 클릭은 없다. 진행 기록 폼에서 최초 대응 완료를 기록하며 이후 기존 대응 목표와 최초 대응시각을 보존한다. 목표가 없으면 카드가 없다.
