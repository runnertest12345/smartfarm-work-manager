# 공통 업무 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

보드·관제·검토에서는 compact, 농가 업무 목록에서는 기본형으로 사용한다. 업무 유형·상태·우선순위·응답 위험 배지, 제목, 사업명, 담당자, 최종 활동시각을 표시한다. 농가명과 기한은 이 카드의 별도 표시 항목이 아니다.

대기이면 막힌 일수·해제 주체·사유를 덧붙인다. 다음 행동은 미설정 안내 또는 완료 안내를 표시한다. 체크리스트가 있으면 완료/전체 수, 예정 방문이 있으면 예정시각이 가장 빠른 방문과 담당자를 표시한다. 지난 예정 방문도 선택될 수 있다. 기본형만 최신 수신·처리 내용을 각기 찾아 표시하며 없으면 안내문을 쓴다.

카드 전체 클릭은 업무 상세로 이동한다. 자체 필터나 저장 동작은 없고 부모가 전달한 업무만 표시한다. 보드만 검색·유형 조건을 적용하며 관제·검토는 전체 집계에서 대상을 선정한다. 목표 위험은 미설정/여유/72시간 주의/24시간 이내/초과/달성/실패로 나누고, 목표가 없으면 배지를 숨긴다. 현재 선택된 업무는 강조한다.
