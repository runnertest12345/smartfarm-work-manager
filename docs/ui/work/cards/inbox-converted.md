# 업무 전환 완료 목록 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

수신함의 converted 항목이 있을 때 접이식 영역과 건수를 표시한다. 원문을 두 줄로 줄여 보여주고 연결 업무 제목을 덧붙인다. 클릭하면 연결 업무 상세를 연다. 업무를 찾지 못하면 ‘연결 업무 확인 필요’로 표시하고 버튼을 비활성화한다. 업무 검색 필터와 무관하고 0건이면 영역을 숨긴다.
