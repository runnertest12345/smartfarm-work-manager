# 정리 전 수신 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

수신함의 unprocessed 항목마다 원문 전체, 경로·상태 배지, 받은 시각, 선택적 전달자, 기록자와 참고 링크를 보여준다. ‘업무로 정리’는 농가·사업 연결 폼을 연다. ‘참고 보관’/‘처리 제외’는 각각 reference/discarded로 저장하며 요청 중 비활성화한다. 본문에는 편집 기능이 없다. 참고 링크는 새 탭으로 연다.

업무 검색 필터를 적용하지 않는다. 정리 전이 0건이면 카드 대신 수신함 빈 안내가 나타난다. 이미 정리한 항목에 대한 상태 변경/전환은 저장 단계에서 거절된다.
