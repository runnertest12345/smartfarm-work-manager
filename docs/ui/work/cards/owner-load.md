# 담당자 업무 신호 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

서비스 관제. 전체 미완료 업무를 owner 문자열로 묶어 총수·높은 우선순위·기한 지연·대기 건수를 표시한다. 지연 수 내림차순 → 높음 수 내림차순 → 미완료 수 내림차순으로 정렬해 최대 10명이다. 다른 필터를 적용하지 않는다.

단순 건수와 위험 신호이며 소요시간·가용량 산정은 아니다. 담당자 행과 숫자에는 클릭 동작이 없다. 데이터가 없으면 제목/설명만 남고 별도 빈 상태 문구는 없다.
