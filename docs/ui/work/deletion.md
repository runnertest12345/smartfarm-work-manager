# 업무 삭제·복원

업무 현황의 카드 `상세 보기` → `삭제`, 또는 업무 상세 화면에서 삭제한다. 삭제 확인창에서 업무명을 확인한 뒤 적용한다. 카드의 접힌 상태는 업무명만 유지한다.

- 승인된 개인 관리자 또는 해당 업무 등록자(UID 기준)만 삭제·복원할 수 있다. 담당자 이름이나 부서장 직책만으로 권한이 부여되지는 않는다.
- 삭제는 보드·목록·업무 KPI에서 제외하는 방식이다. 상태·처리 이력·첨부·방문 기록은 원본으로 보존한다. 입금·구독 업무는 삭제 대상이 아니다.
- 세부 업무가 남아 있으면 완료된 세부 업무도 먼저 삭제한다. 상위 업무를 지워도 세부 업무가 한꺼번에 지워지지 않는다.
- 업무 현황의 `삭제된 업무`에서 복원한다. 상위 업무부터 복원하며, 미완료 업무를 완료된 상위 업무 아래로 복원하려면 상위 업무를 먼저 다시 연다.
- 삭제·복원 이력은 같은 저장 단위에서 남긴다. 오래된 화면의 저장·중복 요청·타인의 직접 요청도 저장 규칙에서 검사한다.

예정 상태 추가나 통합 현황의 내부 업무 표시는 이번 변경에 포함하지 않는다.
