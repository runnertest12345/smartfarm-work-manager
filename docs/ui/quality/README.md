# 데이터 점검

기준 커밋: `141faaa` · 작성일: 2026-09-07

메뉴의 데이터 점검(`view='quality'`) 또는 전체 현황의 데이터 점검 바로가기. 전체 농가와 사업 참여 정보를 자동 검사한다. 검색·사업·구독·업무 필터가 없고 다른 화면 필터도 적용하지 않는다.

| 카드                                          | 계산                           |
| --------------------------------------------- | ------------------------------ |
| [전체 확인 항목](cards/total.md)              | 생성된 이슈 총수               |
| [중복 가능성](cards/duplicates.md)            | duplicate 이슈 수              |
| [기본·설치 누락](cards/basic-installation.md) | contact + installation 이슈 수 |
| [구독 기준 누락](cards/subscription.md)       | subscription 이슈 수           |

[점검 이슈 카드](cards/issue.md)는 우선 확인(high)을 먼저, 동일 심각도에서는 제목의 한국어 정렬순으로 배치한다. 같은 농가가 여러 이슈에 포함될 수 있어 항목 수는 농가 수와 다르다. 클릭하면 해당 농가 상세를 열며 자동 수정은 하지 않는다. 문제가 없으면 ‘현재 확인할 데이터 문제가 없습니다’와 새 정보 추가 시 자동 재점검 안내를 표시한다.

검사는 주소 누락, 농장번호/농가명 중복, 동일 농가·사업 중복 연결, 설치일 누락, 구독기간 또는 현재 만료일 누락이다. 다른 필드의 누락·서류·방문·대응 시간은 검사 대상에 포함되지 않는다.
