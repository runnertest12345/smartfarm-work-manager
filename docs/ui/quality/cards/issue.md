# 데이터 점검 이슈 카드

기준 커밋: `141faaa` · 작성일: 2026-09-07

데이터 점검의 각 이슈마다 분류(중복/기본정보/설치정보/구독정보), 우선 확인 또는 확인 필요, 제목과 해당 농가·사업의 설명을 표시한다. 클릭하면 농가 상세를 열며 관련 참여정보 편집 폼을 자동으로 여는 동작은 없다.

농장번호와 농가명은 trim+한국어 소문자 변환 후 빈 값을 제외해 같은 값 2건 이상을 중복으로 본다. 중복은 high, 주소/설치일/구독기준 누락은 medium이다. high를 먼저, 같은 심각도에서는 제목 한국어 정렬순이다. 필터는 없으며 문제가 0건이면 카드 대신 화면 빈 안내가 나타난다.
