# 구독 기준 누락 KPI

기준 커밋: `141faaa` · 작성일: 2026-09-07

데이터 점검 상단. 참여정보의 subscriptionYears<=0 또는 현재 만료일이 없는 경우 생성되는 subscription 이슈 수이다. 두 조건이 동시에 맞아도 한 참여정보에 1개만 생성한다. 구독 상태가 미등록인지 여부는 별도 조건이 아니다. 필터·클릭 동작은 없고 0건도 표시한다.
