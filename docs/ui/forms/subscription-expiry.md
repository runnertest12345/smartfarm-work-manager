# 구독 만료일 입력·정정

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `subscription_expiry`

열리는 경로: 농가 관리대장·구독 관리목록·농가 상세 참여 사업 카드의 만료일 입력/수정 버튼. 대상 농가·사업·현재 만료일은 읽기 정보다. 기록자는 사업 담당자(‘미지정’ 포함 값은 제외), 없으면 현재 계정 표시명으로 초기화한다.

필드: 변경할 만료일(date, required), 변경 담당자(required, 최대 100자), 변경 메모(선택, 최대 1,000자). 만료일 입력 시 오늘 이상은 사용중, 과거는 만료로 저장 후 상태를 미리 표시한다.

저장: subscription_expiry_correction PATCH. 현재 만료일을 바꾸고 날짜 기준 구독 상태를 함께 갱신한다. 최초 만료일이 없으면 같은 날짜로 채운다. 완료된 구독 업무와 전후 날짜·메모 시스템 이력을 생성하고 농가·사업 활동을 갱신한다. 갱신횟수나 갱신/이탈/재가입 이벤트는 늘리지 않는다.

현재와 같은 날짜, 유효하지 않은 날짜, 담당자 누락을 거절한다. 폼을 열 때의 현재 만료일과 updatedAt을 대조해 다른 사용자의 변경을 감지한다. 실패 시 최신 내용을 확인한 뒤 다시 열어야 한다.
