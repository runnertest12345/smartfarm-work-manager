# 수신 내용의 농가·사업 연결

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `inbox_route`

열리는 경로: 업무 현황 수신함 정리 전 카드의 ‘업무로 정리’. 수신 원문을 읽기 표시한다. 농가 검색, 농가 선택, 참여 사업 선택이 있으며 농가와 그 농가의 실제 참여정보를 모두 선택해야 다음 단계로 간다.

농가 검색은 농가명·농장번호·경영체번호·지역·주소의 포함 검색이다. 참여정보가 1개 이상인 농가만 후보로 표시한다. 선택 농가의 참여가 하나면 자동 선택하고 여러 개면 사업 선택을 비운다. 후보가 없으면 ‘검색 조건에 맞는 참여 농가가 없습니다’를 표시한다. 다른 화면 필터는 적용하지 않는다.

‘다음: 업무 계획 작성’은 저장하지 않고 해당 농가 상세와 업무 등록 폼을 준비한다. 제목은 원문 공백 정리 후 70자까지, 수신 원문·경로·전달자·일시·기록자·링크는 수신함에서 복사한다. 설명/완료 기준은 기본 문구, 대응 목표는 원 수신시각+72시간으로 설정한다. 취소하면 수신함 상태를 변경하지 않는다. 실제 converted 변경은 다음 업무 등록 성공 시에만 일어난다.
