# 프로젝트 기록 추가

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `project_update`

열리는 경로: 사업 상세의 수신·연락, 결정·변경, 프로젝트 막힘 기록 버튼. 기본 기록자는 사업 담당자, 일시는 현재이며 결정·변경으로 열면 수신 경로를 회의, 그 외에는 메일로 초기화한다.

필드: 기록 구분(수신·연락/결정·변경/프로젝트 막힘), 발생 일시, 제목, 수신 경로, 전달자·기관, 받은 내용, 처리 내용, 기록 담당자, 참고 링크. 막힘 구분일 때 막힘 사유·해결해 줄 사람/기관·예상 해제일을 추가 표시한다.

저장 필수는 제목과 기록 담당자, 막힘이면 사유와 해제 주체이다. 프로젝트 기록에는 받은 내용 또는 처리 내용 중 하나가 반드시 있어야 한다는 제출 검사는 없다. 참고 링크는 URL 입력이다.

저장: project_update POST로 프로젝트 직접 기록을 추가하고 프로젝트 수정시각을 갱신한다. 막힘 외 유형은 막힘 관련 값을 비워 저장하며 미해결 정보는 resolvedAt=0으로 시작한다. 시스템 기록은 직접 등록할 수 없다. 완료 프로젝트의 새 막힘은 거절하지만 수신·결정 기록은 이 저장 함수에서 금지하지 않는다. 이 폼에는 기존 기록 편집 기능이 없다.
