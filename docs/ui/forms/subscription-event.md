# 구독 처리 등록

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `subscription_event`

열리는 경로: 구독 화면의 구독 처리 등록/개별 구독 처리. 특정 참여정보를 받지 않으면 현재 만료일이 가장 빠른 참여정보, 없으면 첫 참여정보를 고른다. 참여정보가 전혀 없으면 안내 알림 후 열지 않는다.

필드: 농가·사업 구독(참여정보 선택), 처리 구분(갱신/이탈/재가입), 처리일, 기준 만료일, 새 만료일(이탈일 때 숨김), 기록 담당자, 처리 메모. 기본 구분은 갱신, 처리일은 오늘, 기준 만료일은 현재 만료일, 새 만료일은 기준일에 1년을 더한 뒤 하루를 뺀 날짜(addYears), 기록자는 사업 담당자이다. 대상 변경은 해당 초기값과 동시 수정 확인값을 다시 채운다. 기준일 변경은 새 만료일을 기준일에 1년을 더한 뒤 하루를 뺀 날짜로 다시 채우고 이탈 선택은 새 만료일을 비운다.

저장 필수: 대상·기준 만료일·처리일·기록자, 갱신/재가입은 유효한 새 만료일이 필요하고 기준일보다 뒤여야 한다. 이탈은 새 만료일이 없어야 한다. 동일 참여정보·기준 만료일에 이미 이벤트가 있으면 유형과 관계없이 거절한다. 현재 만료일/수정시각을 열 때 값과 대조해 동시 변경을 감지한다. 갱신/이탈 기준일은 현재 만료일보다 늦을 수 없고 재가입은 저장 상태가 만료이거나 이탈 이력이 필요하다.

저장: subscription_event POST로 실적 이벤트와 완료된 구독 업무/시스템 이력을 만든다. 갱신·재가입의 새 만료일이 기존 현재 만료일보다 늦을 때 현재 만료일과 사용중 상태를 갱신하며 갱신 유형만 갱신횟수를 1 늘린다. 이탈은 현재 만료일이 없거나 기준일이 현재 만료일 이상일 때 만료 상태로 바꾼다. 오래된 회차 이벤트는 저장되어도 현재 구독 값에 영향이 없을 수 있다. 입금일·입금액을 입력하는 폼은 아니다.
