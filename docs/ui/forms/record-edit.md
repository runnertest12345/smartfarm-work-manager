# 사업 참여정보 수정

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `record_edit`

열리는 경로: 농가 상세 참여 사업 카드의 수정. 선택 참여정보 값으로 초기화하고 다른 참여정보가 이미 사용하는 사업은 선택 목록에서 제외한다.

필드는 [사업 참여 추가](record-add.md)와 같지만 구독 상태·현재 구독 만료일·갱신횟수 입력은 숨긴다. 대신 현재 만료일을 읽기 안내로 표시한다. 최초 구독 만료일·구독기간·마지막 입금일과 등록자는 계속 입력할 수 있다. 필수는 참여 사업과 등록자이며 기간 입력 범위/보증 자동계산은 추가 폼과 같다.

저장: record PATCH로 참여정보를 변경하고 변경 필드 요약을 담은 완료된 관리 메모 업무와 시스템 이력을 만든다. 농가와 관련 프로젝트 수정시각도 갱신한다. 동일 농가·사업 중복을 거절한다. 이전 또는 새 사업이 완료이면 프로젝트 연결을 변경할 수 없지만 같은 완료 사업의 일반 참여정보 변경을 이 함수가 전부 금지하는 것은 아니다.

현재 만료일·상태·갱신횟수가 기존 값과 다르면 전용 구독 관리 안내로 거절한다. 저장 중 다른 사용자가 구독 값을 바꾼 경우도 감지한다. 실제 만료일 정정은 [전용 폼](subscription-expiry.md), 실적 처리는 [구독 처리](subscription-event.md)를 사용한다.
