# 현장 방문 추가·수정

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `visit`

열리는 경로: 업무 상세 현장 방문의 ‘방문 추가’ 또는 예정 방문 ‘수정’. 완료 업무에서는 추가/수정을 거절하고 완료·취소 방문도 수정할 수 없다. 신규 기본 예정시각은 현재+1일, 담당자·기록자는 업무 담당자, 상태는 예정이다.

| 필드                                | 필수·조건                              |
| ----------------------------------- | -------------------------------------- |
| 방문 예정 일시, 방문 담당자, 기록자 | 화면 required, 담당자·기록자 저장 필수 |
| 방문 상태                           | 예정/완료/취소                         |
| 방문 준비 메모                      | 선택                                   |
| 실제 시작/완료 일시                 | 완료일 때 표시 및 required             |
| 조치 결과/취소 사유                 | 완료/취소일 때 표시 및 required        |
| 후속 방문 일시                      | 완료/취소일 때만 표시, 선택            |

완료 상태로 바꾸면 비어 있는 실제 시작은 현재-1시간, 완료는 현재로 채운다. 상태를 바꾸면 결과를 비우며 예정으로 돌리면 실제 시각과 후속 방문 시각을 비운다. 신규 폼도 완료/취소로 소급 기록할 수 있고 저장 후 잠긴다는 안내가 있다.

저장: visit POST이며 id 유무로 새 일정/기존 예정 수정이 나뉜다. 방문과 시스템 진행 이력을 함께 저장하고 업무·참여·농가·사업 활동을 갱신한다. 완료/취소에 후속 방문시각을 넣으면 같은 담당자의 별도 예정 방문을 자동 생성한다. 방문 완료만으로 업무 전체를 완료하거나 최초 대응 완료로 표시하지 않는다. 완료/취소 증빙은 저장 후 수정이 금지된다. 이 저장 함수에는 실제 종료≥시작 또는 후속일시의 선후 관계를 검사하는 별도 코드가 없다.
