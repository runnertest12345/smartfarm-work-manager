# 빠른 수신

기준: 2026-09-08

DialogKind: `inbox`

열리는 경로: 업무 현황 상단 ‘빠른 수신’, 프로젝트 상세 ‘하위 업무 추가’. 프로젝트를 지정하거나 미지정으로 원문을 보관한다. 기본 경로는 카톡, 받은 일시는 현재, 기록자는 로그인한 사용자이다.

필드: 프로젝트, 하위 업무명(프로젝트 지정 시), 수신 경로(메일/카톡/전화/구두/회의/기타), 받은 일시, 전달자·기관, 기록자, 받은 내용·첨부 이미지, 참고 링크(URL). 받은 내용 또는 이미지와 기록자는 필수이다. 미래 수신 시각은 허용하지 않는다. 이미지는 Ctrl+V 붙여넣기나 파일 선택으로 최대 3장 첨부한다.

저장: 프로젝트 미지정 시 unprocessed 수신만 생성한다. 지정 시 converted 수신, 농가 연결 없는 프로젝트 업무, 최초 히스토리를 원자적으로 생성한다. 원문·이미지·원 수신시각·경로를 보존한다. 최초 업무 담당자는 기록자이다. 완료 프로젝트에는 등록하지 않는다. 저장 재시도 시 같은 수신 ID를 사용해 중복을 막는다.
