# 빠른 수신

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `inbox`

열리는 경로: 업무 현황 상단 ‘빠른 수신’. 농가/사업 지정 없이 원문을 먼저 보관한다. 기본 경로는 카톡, 받은 일시는 현재이다.

필드: 수신 경로(메일/카톡/전화/구두/회의/기타), 받은 일시, 전달자·기관, 기록자, 받은 내용, 참고 링크(URL). 저장 필수는 받은 내용과 기록자이다. 일시는 datetime-local을 타임스탬프로 바꿔 전달한다.

저장: inbox POST로 unprocessed 수신 항목을 생성한다. 업무·농가·사업·히스토리는 이 단계에서 생성하지 않는다. 성공 시 업무 현황 수신함 모드로 이동하고 폼을 닫는다. 원문은 이후 업무로 전환할 때 원 수신시각·경로와 함께 보존된다.
