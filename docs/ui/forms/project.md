# 사업 등록·수정

2026-09-09: PC 팝업을 최대 1,100px로 넓히고 기존 너비·높이 스타일 누락을 수정했다. [프로젝트 관리 개선](../projects/management-update.md).

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `project`

열리는 경로: 공통 상단/전체 현황/사업 화면의 사업 등록, 사업 상세의 정보 수정·정산 수정. 신규 기본값은 일반 사업·올해·진행 중·협약/계약·목표 0, 시작 오늘·종료 +180일·정산 기한 +210일, 정산 미착수·금액 0이다. 수정은 저장값을 채운다.

| 필드                                                | 필수·조건                           |
| --------------------------------------------------- | ----------------------------------- |
| 사업명, 주관기관, 사업 담당자                       | 저장 검사 필수                      |
| 사업 유형, 기준 연도, 사업 상태, 현재 사업 단계     | enum 선택, 연도 2000~2100           |
| 목표 참여 농가 수                                   | 0 이상                              |
| 사업 시작일/종료일, 설명                            | 입력 가능                           |
| 정산 상태, 정산 담당자, 정산 제출 기한, 정산 완료일 | 선택/입력                           |
| 계약금액, 청구금액, 승인금액, 입금금액              | 화면 min 0, 입금액≤승인액 저장 검사 |
| 정산 증빙 링크, 정산 메모                           | 입력 가능                           |

상태 완료 선택은 단계를 사업 마감으로, 사업 마감 단계 선택은 상태를 완료로 바꾼다. 완료에서 다른 상태로 바꾸면 마감 단계는 정산으로, 마감에서 다른 단계로 바꾸면 완료 상태는 진행 중으로 바뀐다.

저장: 신규는 project POST, 수정은 project PATCH. 신규 프로젝트와 시스템 기록, 필수서류 5개(협약·계약, 농가명단, 설치·시운전, 검수·교육, 정산증빙)를 함께 생성한다. 수정은 변경 요약 시스템 기록을 추가한다. 성공하면 해당 사업 상세를 연다.

제약: 신규 완료 사업은 거절된다. 사업 완료는 필수서류가 존재하고 모두 승인, 정산 paid/closed, 미해결 프로젝트 막힘·미완료 업무 없음, 목표 농가 수 충족을 요구한다. 상태 완료와 단계 closed는 일치해야 한다. 완료 상태를 유지하면서 목표·기간·정산 완료 근거 필드를 바꾸려면 먼저 사업을 다시 열어야 한다.
