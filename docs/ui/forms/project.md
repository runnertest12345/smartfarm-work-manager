2026-09-14: **설치 개소**(기존 목표 농가 수)를 입력해 새 일반·연구 프로젝트를 저장하면, 해당 수만큼 `미입력 농가 001` 형식의 임시 농가와 프로젝트 참여 기록을 자동 생성합니다. 생성은 입력 중이 아니라 **프로젝트 등록 시** 수행합니다. 새 등록은 0~500개소의 정수만 허용하며, 내부 프로젝트에는 적용하지 않습니다. 각 농가명에서 상세를 열어 기본정보 수정으로 이름·주소·전화번호·농장번호를 변경할 수 있습니다. 지역 기본값은 `미입력`, 번호는 중복되지 않는 임시 번호입니다.

설치·시운전·교육일은 빈 값, 구독은 미등록으로 시작합니다. 따라서 농가 수에는 포함되지만 설치 완료·구독 농가 수에는 포함되지 않습니다. 기존 프로젝트의 설치 개소 숫자 수정은 기준값만 변경하며 농가를 자동 추가·삭제하지 않습니다.

등록 요청 ID로 프로젝트 중복 생성을 방지하고, 10개소씩 원자적으로 생성하며 진행 상황을 저장합니다. 중간 실패 시 프로젝트 상세의 **남은 농가 생성**으로 이어서 처리합니다. 새로고침 후에도 미완료 안내가 유지되며, 이미 생성되거나 이후 수정된 농가 정보는 덮어쓰지 않습니다. 완료·삭제된 프로젝트에는 추가 생성이 제한됩니다. 이 동작은 로컬 모의 트랜잭션으로 검증하며 실제 운영 데이터 생성은 별도 승인 없이 수행하지 않습니다.

상태 완료 선택은 단계를 사업 마감으로, 사업 마감 단계 선택은 상태를 완료로 바꾼다. 완료에서 다른 상태로 바꾸면 마감 단계는 정산으로, 마감에서 다른 단계로 바꾸면 완료 상태는 진행 중으로 바뀐다.

저장: 신규는 project POST, 수정은 project PATCH. 신규 프로젝트와 시스템 기록, 필수서류 5개(협약·계약, 농가명단, 설치·시운전, 검수·교육, 정산증빙)를 함께 생성한다. 수정은 변경 요약 시스템 기록을 추가한다. 성공하면 해당 사업 상세를 연다.
