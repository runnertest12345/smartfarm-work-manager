# 농가 등록

열리는 경로: 공통 상단 또는 농가 관리대장의 농가 등록 버튼. 농가 기본정보와 최초 사업 참여정보를 한 폼에서 만든다. 기본 사업은 첫 진행 중 사업, 없으면 첫 사업이다.

기본정보 필드는 농장번호·농장명·연락처·지역·주소·경영체번호·농장 폴더 링크·농장 위치도 링크·특이사항이다. 저장 필수는 농장번호·농장명·지역이다. 링크 두 개는 URL 입력이며 실제 개인 정보 값은 이 문서에 포함하지 않는다.

참여 필드는 [사업 참여 추가](record-add.md)의 필드 전체와 같다. 참여 사업과 등록자는 저장 필수이다. 보증/구독은 각각 1년, 구독 상태 미등록, 갱신 0회로 시작한다. 설치일/보증기간 변경 시 설치일에 보증년수를 더한 뒤 하루를 뺀 날짜(addYears)로 보증 만료일만 자동 계산한다.

저장: farm POST로 농가·참여정보·완료된 관리 메모 업무·시스템 이력을 함께 만든다. 농장번호 중복을 저장 계층과 예약 문서로 방지하며 같은 농가/사업 연결도 검사한다. 완료 사업에 신규 농가를 연결할 수 없다. 성공하면 해당 농가 상세를 연다. 사업 선택 목록에는 완료 사업도 보일 수 있으나 저장 시 거절된다.
