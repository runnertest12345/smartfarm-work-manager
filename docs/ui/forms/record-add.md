# 사업 참여 추가

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `record_add`

열리는 경로: 농가 상세의 사업 참여 추가. 이미 참여한 사업을 제외한 첫 사업을 기본 선택한다. 남은 사업이 없으면 ‘추가할 사업이 없습니다’ 알림으로 종료한다. 목록은 완료 여부를 별도로 제외하지 않으며 완료 사업 선택은 저장 단계에서 거절된다.

| 영역      | 필드                                                                    |
| --------- | ----------------------------------------------------------------------- |
| 참여·장비 | 참여 사업, 작물, 장비 종류, 제품 종류, 장비업체, 인터넷 유형, 사업 비고 |
| 설치·교육 | 제작·세팅 완료일, 제품 설치일, 시운전 완료일, 교육 완료일               |
| 보증      | 보증기간(년), 보증 만료일                                               |
| 구독      | 구독기간(년), 구독 상태, 최초/현재 구독 만료일, 마지막 입금일, 갱신횟수 |
| 기록      | 등록자                                                                  |

참여 사업과 등록자는 저장 필수이다. 보증/구독기간은 기본 1년·화면 0~20·저장 0 이상, 갱신 기본 0·화면 min 0, 구독 상태 기본 미등록이다. 날짜/장비/작물은 빈 값으로 시작한다. 설치일이나 보증기간을 변경하면 설치일에 보증년수를 더한 뒤 하루를 뺀 날짜(addYears)로 보증 만료일을 다시 계산하며 수동 수정도 가능하다. 설치일만으로 구독 만료일을 자동 계산하지 않는다.

저장: record POST로 기존 농가에 사업 참여정보를 추가하고 완료된 관리 메모 업무와 시스템 이력을 만든다. 농가·사업 활동 정보도 갱신한다. 동일 농가의 같은 사업 중복 연결과 완료 사업 신규 연결을 거절한다. 농가 기본정보 입력 영역은 없다.
