# 농가 업무 등록

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `work_item`

열리는 경로: 농가 상세의 새 업무/업무 등록/이 사업에 업무 등록, 수신함 연결 다음 단계, 구독 관리목록의 ‘입금’. 농가에 참여정보가 있어야 열리며 참여가 여러 개인 일반 등록은 연결 사업을 직접 고른다. 입금 바로가기는 입금 유형·‘구독료 입금’ 제목·오늘 기한과 입금 체크리스트를 미리 채운다.

| 영역      | 필드·조건                                                                                                                                |
| --------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 연결·계획 | 연결 사업, 업무 유형(수신·연락/설치·교육/구독/입금/A/S/관리 메모), 현재 상태, 제목, 담당자, 기한, 우선순위, 다시 볼 날짜, 최초 대응 목표 |
| 내용      | 설명, 완료 기준, 다음 행동, 체크리스트(한 줄 1항목)                                                                                      |
| 대기일 때 | 막힘 사유·해제 책임자(required), 예상 해제일                                                                                             |
| 최초 이력 | 수신 경로, 발생 일시, 전달자·기관, 금액(원, min 0), 받은 내용, 처리 내용, 기록자, 참고 링크(URL)                                         |

기본은 수신·연락/접수/보통, 기한 +7일·검토 +3일·대응 +72시간, 수신 경로 전화다. 우선순위를 변경하면 발생일시 기준 높음 +24/보통 +72/낮음 +168시간으로 대응 목표를 다시 계산한다. 업무 유형 변경은 기존 체크리스트가 비었거나 알려진 기본 템플릿일 때 해당 유형 예시로 교체한다.

필수: 연결 참여정보·제목·담당자·기록자, 제출 함수에서는 최초 받은 내용/처리 내용 중 하나가 있어야 한다. 대기에는 사유·주체 필수. 체크리스트는 trim 후 빈 줄을 빼며 최대 30개, 항목당 1~300자이다. 완료 상태로 새 업무를 만들 때 체크리스트가 있으면 거절한다. 완료 사업 신규 업무는 거절한다.

수신함 전환에서는 경로·발생일시·전달자·받은 내용·참고 링크가 잠긴다. 저장은 work_item POST로 업무·최초 이력·체크리스트·필요 시 막힘 이력을 만든다. 수신 전환은 원문 이력과 현재시각 전환 이력을 분리하고 원 수신 항목을 converted로 바꾼다. 처리 내용이 있거나 초기 완료이면 최초 대응시각도 채운다. 완료는 다음 행동/검토일을 비운다. 입금 유형+양수 금액이면 해당 참여정보의 마지막 입금일을 더 늦은 날짜로 갱신한다. 성공 후 새 업무 상세를 연다.
