# 농장 위치도 사진 · 2026-09-09

농가 등록과 기본정보 수정에 ‘농장 위치도 사진 (선택)’을 제공한다. 사진 선택 또는 붙여넣기 영역에 Ctrl+V로 캡처를 첨부한다. 기존 농장 폴더 링크와 농장 위치도 링크는 외부 자료 바로가기이며 필수가 아니다. 기존 링크는 자동 삭제하지 않는다.

- PNG·JPG·WebP, 기존 유지 사진과 새 사진 합계 최대 3장. 원본은 장당 10MB 이하, 저장본은 장당 384KiB 이하로 압축한다. 작은 글씨가 흐려지면 필요한 부분을 따로 캡처하거나 기존 외부 링크를 사용한다.
- 저장 전 새 사진은 미리보기와 제거를 지원한다. 기존 사진은 보기·첨부 제외·제외 취소를 지원한다. 제외는 저장할 때 연결만 해제하며 불변 이미지 본문은 삭제하지 않는다.
- 농가 상세 상단의 ‘농장 위치도’에서 사진을 불러와 보고 내려받는다. 전체 농가 조회에는 이미지 ID만 포함하며 본문은 요청할 때 불러온다.
- 기존 Firebase 이미지 저장 구조를 재사용한다. 새 사진과 농가의 `locationImageIds`는 같은 트랜잭션에 저장한다. 사진은 해당 농가 연결과 활성 회원 권한을 검사하며 다른 농가·수신함의 이미지를 임의 연결할 수 없다.
- 사진 처리·저장 중에는 닫기와 중복 저장을 막는다. 처리·저장 실패 시 입력과 사진 초안을 유지한다. 다른 농가 창을 열면 초안을 초기화한다.
- 수정은 서버 최신 농가를 읽고 폼을 연 시점의 버전과 기존 사진 ID를 확인한다. 이전 클라이언트가 사진 입력 없이 저장해도 최신 사진 연결을 보존한다. 본문 수정·삭제 권한과 목록 조회 권한은 열지 않는다.

검증: `scripts/test-farm-location-images.mjs`, `scripts/test-project-image-rules.mjs`. 운영 농가를 만들거나 수정하여 테스트하지 않는다.
