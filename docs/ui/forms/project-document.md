# 제출서류 등록·수정

기준 커밋: `141faaa` · 작성일: 2026-09-07

DialogKind: `project_document`

열리는 경로: 사업 상세 제출서류 영역의 추가/수정. 신규는 협약·계약 분류, 필수서류, 미작성, 개정 1, 책임자와 현재 처리자는 사업 담당자이다.

필드: 서류명, 서류 구분(협약·계약/농가/설치·납품/검수·교육/정산/기타), 필수 여부, 상태(미작성/작성 중/제출 완료/검토 중/보완 요청/승인/반려), 개정번호, 책임자, 현재 처리자, 제출 기한, 제출일, 승인일, 증빙 링크, 메모.

서류명·책임자·현재 처리자는 저장 필수, 개정번호는 저장 검사 1 이상·화면 1~1000이다. 날짜와 링크는 입력 가능하며 이 저장 파서 자체는 승인 상태에 따른 날짜/링크 필수 검사를 추가하지 않는다.

저장: project_document POST/PATCH로 서류를 생성/수정하고 시스템 프로젝트 기록을 추가하며 프로젝트 수정시각을 갱신한다. 수정 기록은 이전 증빙 링크도 보존한다. 완료 프로젝트에서는 등록·수정을 거절한다. 개정번호를 낮출 수 없고 상태 순위를 되돌리려면 개정번호를 높여야 한다. 같은 개정에서는 이미 입력한 제출일·승인일·증빙 링크를 빈 값으로 지울 수 없다.
