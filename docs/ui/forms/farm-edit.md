열리는 경로: 농가 상세의 기본정보 수정. 선택 농가의 현재 값으로 초기화하며 등록 폼과 외곽 다이얼로그를 공유하되 기본정보 영역만 표시한다.

필드: 농장번호, 농장명, 연락처, 지역, 주소, 경영체번호, 농장 폴더 링크, 농장 위치도 링크, 특이사항. 저장 필수는 농장번호·농장명·지역, 두 링크는 URL 입력이다. 참여 사업·설치·구독·등록자 입력 영역은 표시하지 않는다.

저장: farm PATCH로 선택 농가 기본정보와 수정시각/작성자 감사를 갱신한다. 농장번호를 바꾸면 중복 예약도 갱신하며 다른 농가와 중복되면 거절한다. 참여정보·업무 상태·구독 실적을 수정하거나 완료된 감사용 업무/히스토리를 새로 만들지는 않는다.
