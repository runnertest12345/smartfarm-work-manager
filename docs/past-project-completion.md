# 과거 프로젝트 완료 상태 정정

2026-09-10 사용자 확인: 2026년 이전 프로젝트의 진행·설치·시운전·교육·서류·정산은 완료 상태이다.

`scripts/complete-past-projects.mjs inspect`는 운영 원본을 읽어 Git에서 제외된 `work/past-complete-...`에 REST 원본 백업, SHA-256, 조건부 변경 계획을 생성한다. `apply`는 검증한 계획 경로와 SHA-256을 받아 기존 문서의 updateTime 조건으로 한 번에 저장한다. 충돌 시 임의로 덮어쓰지 않으며, 응답이 불명확하면 `verify`로 확인한다.

- 연도 필드가 2026 미만인 프로젝트만 `completed / closed / closed`로 정정한다.
- 연결된 기존 제출서류는 `approved`로 정정한다. 기존 제출·승인 날짜와 증빙 링크는 보존하며, 없는 날짜나 증빙을 생성하지 않는다.
- 농가 참여의 설치·시운전·교육 날짜는 보존한다. 날짜가 없는 단계에만 `stageCompletionConfirmed`로 완료 확인을 추가한다. 확인 시각은 실제 완료일이 아니며, 화면에는 `완료 확인 · 일자 미기록`으로 표시한다.
- 계약·청구·정산·입금 금액, 구독 만료일, 보증 기간, 2026년 이후 프로젝트, 업무 및 A/S 상태는 변경하지 않는다.
- 프로젝트별 감사 이력을 추가한다. 원본 백업과 검증 결과는 공개 사이트·GitHub에 업로드하지 않는다.
- 설치 단계는 설치·시운전·교육 3단계로 표시하고 제작·세팅일은 별도 정보로 유지한다. 프로젝트 진행률은 완료 확정 사업이면 100%, 진행 사업이면 기존 단계별 증빙 평균으로 표시한다.
