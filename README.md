# 워크플로우 업무관리 프로그램

소규모 팀의 실무자와 팀장이 업무를 등록하고, 담당자·마감일·우선순위·진행 상태를 한 화면에서 관리하는 웹 기반 업무 대시보드입니다.

## 이번 MVP의 범위

- 업무 등록, 수정, 삭제
- 예정 / 진행 중 / 검토 대기 / 완료 상태 관리
- 높음 / 보통 / 낮음 우선순위 관리
- 업무명, 담당자, 분류, 설명 검색
- 상태와 우선순위 필터
- 오늘 마감 및 지연 업무 강조
- 업무 수, 진행 중 업무, 오늘 마감, 완료율 요약
- 데스크톱, 태블릿, 모바일 대응
- 서버 데이터베이스에 업무 영구 저장

## 제품 구조

- 화면: React 기반 단일 업무 대시보드
- 데이터: Cloudflare D1(SQLite) 영구 저장소
- 서버 기능: 업무 조회·등록·수정·삭제 API
- 배포: OpenAI Sites 기반 비공개 사이트

로그인과 사용자별 권한은 다음 단계에서 추가하기 좋은 구조로 남겨 두었습니다. 현재 버전은 한 팀이 공용 업무 보드로 사용하는 MVP입니다.

## 개발 실행

```bash
pnpm dev
```

데이터 구조를 변경한 뒤에는 아래 명령으로 이전 파일을 생성합니다.

```bash
pnpm db:generate
```
