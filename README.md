# 사업 워크로그

메일, 카톡, 전화, 구두, 회의 등 여러 경로로 들어오는 정보를 사업별 업무에 연결하고 처리 과정을 이어서 기록하는 웹 프로그램입니다.

## 이번 MVP의 범위

- 사업 등록 및 사업별 업무 분리
- 접수 / 진행 중 / 회신 대기 / 완료 상태 관리
- 높음 / 보통 / 낮음 우선순위 관리
- 메일 / 카톡 / 구두 / 전화 / 회의 / 기타 수신 경로 기록
- 실제 발생 일시, 전달자, 기록자, 받은 내용, 처리 내용, 참고 링크 저장
- 업무 목록에서 최신 수신 내용과 최근 처리 내용 확인
- 업무 상세에서 전체 히스토리를 최신순으로 확인
- 업무명, 담당자, 기록 내용 통합 검색과 상태 필터
- 미처리, 회신 대기, 기한 초과, 최근 업데이트 요약
- 데스크톱, 태블릿, 모바일 대응
- 서버 데이터베이스에 사업·업무·히스토리 영구 저장

## 제품 구조

- 화면: React 기반 사업별 업무 대시보드와 업무 히스토리 상세창
- 데이터: Cloudflare D1(SQLite) 영구 저장소
- 서버 기능: 사업·업무 등록, 수신·처리 히스토리 추가 API
- 배포: OpenAI Sites 기반 비공개 사이트

로그인과 사용자별 권한은 다음 단계에서 추가하기 좋은 구조로 남겨 두었습니다. 현재 버전은 한 팀이 공용 업무 보드로 사용하는 MVP입니다.

## 개발 실행

```bash
pnpm dev
```

데이터 구조를 변경한 뒤에는 아래 명령으로 이전 파일을 생성합니다.

```bash
pnpm db:generate
```
